### 2.4 前瞻层:RSI 与组织自改进(2026-09-07 用户拍板补)

**RSI 五环**(生成→验证→选择→记忆→定向):瓶颈不在①生成(人人有 Claude),在②③
——与「没人造总线」同源:RSI 基础设施=验证基础设施=②仲裁器产品化的理论顶点。

**组织自改进三级**:L1 任务自动化(已过)→ L2 组织自运行(现在,measured 130 天)→
L3 递归自改进(组织改进组织自身,改动过验证门自动合入)——率先=第一个把 L3 做成
**可验证的闭环**。

**四条设计**:
1. **改动仲裁(Change Arbitration)**——第三种仲裁器(Aegis=动作/我们=记忆+数据/RSI=改动):
   预注册判据→回归门→独立复算→合入/回滚;
2. **分层自改进权限**——L3 只对低风险域(组织规则/记忆层/协议文档)开放,生产代码人审,可回滚;
3. **每步可审计**——组织对自身的每次改动=一张 VerifyPack(声称+复算+签名);
4. **外部裁决不可拆**——每环至少一个外部锚(benchmark/真实用户/Gate B),防「自己证明自己变强」
   (income 假成功工厂教训)。

**最小试验场=9/15 记忆门三件套**,升级为首个 RSI 试验环:预注册判据先行(见任务 #48,
判据本节冻结)→实现→四探针+全量 pytest 回归→recall-usefulness 三 fact hit@3 不降(外部锚,
复用 N2b 回归门)→非实现者独立复算→合入。环转速与回滚率记 ledger。

**预注册判据(2026-09-07 冻结,防事后改)**:
- #1 fact_status:机制上线后新写入 memory 带 fact_status 比例=100%(旧条目不追溯);
- #2 查重合并:cosine>0.9 命中触发合并而非新建;误合并对照=10 条已知不相关条目零误合并;
- #3 沿链一跳:含 [[name]] 的召回结果展开出现率=100%,不递归,recall P95 ≤ 现基线×1.2;
- 全局回归门:四探针 FOUR-GREEN+全量 pytest 绿+三 fact hit@3 不降。

**仲裁器分水岭判据(2026-09-07 补,measured 可测)**:compass 已是「自家仲裁器」(五实例在跑:
判分卫生学/QC 门/drift/验证函/RSI 改动仲裁);**「行业仲裁器」的分水岭=外部第一采信**——
第一个非自家团队使用 VerifyPack 的 verify/check 并采信其回执。两条在轨路径:9/8 发布(信任
广播)+flywheel 数据结算(首个真实买方场景)。反脆弱红线:判据库必须持续接外部锚,自家人
验证自家人只产生内部一致性,不产生外部信任。
