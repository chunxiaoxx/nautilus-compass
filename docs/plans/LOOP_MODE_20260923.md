## 四 · Loop 轮值协议(每轮五步,步序固定)

1. **信箱**:`platform_mail.py check` 未读→逐封 ack/回函(带判据)
2. **同步**:三源对齐——信箱动态+墙页/GitHub 活动+各框 memory
   产出三行:各框新进展/新阻塞/对我的依赖
3. **推进**:任务清单最高优先未完项(P2 自问:对 M1 贡献?)
4. **防跑偏**:compass drift_check + 锚点档案;偏离即记 P 表
5. **收轮**:本轮 diff(进展/阻塞/下一步)更新本档状态列

> 轮频:用户驱动(每轮=用户一条消息)或 30-60 分钟自轮。
> 跨框纪律:回函带判据;不接不明指令;每轮把「其他框要我做什么」
> 显式列出来。
