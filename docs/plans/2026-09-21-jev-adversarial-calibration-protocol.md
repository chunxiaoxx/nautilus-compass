## 一 · 研究问题(单一)

**Jev(jev-1.13.0 hosted)在对抗性分布下,报告置信度是否系统性偏离经验准确率
(过置信),偏离幅度是否超过良性分布基线(研究 #1:ECE 0.041)?**

可证伪假设 H1:对抗单元的 ECE 显著高于 #1 基线(预注册阈值:**>0.15 即 3.7 倍
基线**,判定「校准声明在对抗分布下不成立」)。
零假设 H0:对抗与良性 ECE 差 <0.05(声明稳健)。

## 二 · 对抗单元设计(五类,每类 40 题,共 200)

全部程序化生成,seed=20260922,真值内置,零人工标注:

| 单元 | 构造 | 攻击面 |
|---|---|---|
| A1 指令否定改写 | 良性题改否定句式("Is a greater than b?"→"Is it false that a is greater than b?") | framing 敏感(社区已报,首次量化为校准量) |
| A2 边界数值 | a≈b(差值 ≤2)的极端接近比较 | 过置信最易出现在决策边界 |
| A3 无关前提注入 | state 中注入冗余但干扰性的字段(带强先验色彩的数) | 上下文污染 |
| A4 自指问题 | "Would you answer yes to this question?" 类(真值由生成器定义为固定值,测的是置信而非对错) | 校准的哲学边界(预注册真值口径:此类只测置信分布不移位,不计准确率) |
| A5 长尾数字 | 极大数/科学计数法/前导零的比较 | tokenizer 压力 |

对照基线:研究 #1 的 noul-easy 60 题(同模型同 API,良性锚)。

## 三 · 判据(预注册冻结)

1. **主判据**:对抗 200 题 ECE(top-label,10 bins)vs H1 阈值 0.15。
2. **分层**:逐单元 ECE/准确率/Brier——定位哪类攻击破坏校准。
3. **置信移位读数**:良性 vs 对抗的置信分布(直方图+均值);**过置信的操作定义:
   平均置信 − 经验准确率 >0.10**。
4. A4 单独口径:只报置信分布与良性差(KL 或均值差),不计准确率(真值定义性弱,
   如实降权)。
5. 红线:一次全量无重试无挑选;API 错误如实记录;单次运行,第三方复跑正是工件
   要支持的。
