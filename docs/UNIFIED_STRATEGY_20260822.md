## §0 世界观(不变,但要说透公理)

**智能 = 压缩 + 验证。压缩无验证则空转;验证无压缩增量则空学。**(第二条 2026-08-22 实测加入)

推论体系(三论文 + B 理论):
- 空转定理(P1):无外部验证的系统收敛于自报活动不动点。实证:genopt 7551 假账、五万次空转。
- 盲区定理(P2):judge 与 generator 同构时有结构性盲区,与判官能力无关。实证:soul verify 拦假成功、TRT 类自验证的边界。
- 空学定理(P3 候选,今日数据):验证信号存在于模型已压缩的内容上时,学习增量为零。实证:c2e delta=0。
- 载体阶梯:能力抬升唯 L3(权重)可写;L0-L2 只重分配。SSI 押的正是"L3 运行时可写"。

**战略含义:行业正从"卖算力/卖模型"转向"卖可学习性"。可学习性 = 好模型 × 真值流。前者大厂在卷,后者无人以理论+工程+实录三件套系统供给。这是我们的位置。**

## §1 理论深化(垂直:从口号到可操作)

### 1.1 B 的度量学(公司的"计量标准",类比 ISO/卡路里)
- **定义**:B = 一次"不可伪造验证事件"所携带的差异信息,单位=验证事件(verdict)。
- **不可伪造性分级**(定价基础):
  - B3 确定性 verifier(pytest/编译/数学验证)——最高价
  - B2 异构 LLM judge(跨家族、judge-generator 不同构)
  - B1 人工抽检——慢但独立
  - B0 自评/同构判——**不计量,计负**(污染源)
- **计量指标(对外可成标准)**:
  - VSR 验证储蓄率 = 验证通过经验/总经验(论文1 已提出)
  - headroom 裸模型失败率(今日新增;燃料入库前置门)
  - B 流量表 = ledger consumed 行数 × B 级别加权
- **可证伪预言(还债日)**:
  - P5:headroom<20% 的经验池,VSR 与学习 delta 无相关(空学定理)
  - P6:B0 占比>70% 的系统,90 天内产出曲线与投入脱钩(空转定理的企业版)
  - P7:B3 燃料单价随持续学习模型发布量上升(供给定价)
  - 任一证伪 → 修理论(见 §8 绞杀)

### 1.2 与 SSI value function 的接口形式化
我们的输出契约(产品 API 的理论形态):
```
VerifiedExperience = {
  state_context_hash, action_trace, outcome,
  reward: B3|B2|B1 (级别+证据指针),
  provenance: producer_agent_id + verifier_agent_id(必须异构)+ ledger grant_id
}
```
任何持续学习器(PPO/DPO/value-function/胶囊召回)都可消费此四元组。**我们不绑定某家架构——这是抗 SSI 不确定性的根本设计。**

## §3 产品形态(P0→P3,一条演化线)

- **P0 自用 compass(已通)**:记忆+燃料+Gate B+胶囊。验收=自己变强(Gold n≥3 + 胶囊生效)。这是 P1-P3 的 demo 和证据源,**永远优先**。
- **P1 Gate B harness 开源(9 月评估)**:三臂 paired A/B + 独立 oracle + fail-closed 证据链,作为"验证学习"参考实现。开源换引用与贡献者,闭源留 ledger/裁决/PoI。判据:论文投出后再开,防被抢跑。
- **P2 燃料市场(FDE 业务升级)**:从"卖题"升级为"卖带 B3 验证的轨迹燃料"——同一批专家产出,买家从"题目"变"可学习数据",单价上移(买方按 pass@k 验收本来就接受验证逻辑)。**这是现金流与战略的合流点**:现有 FDE 合同不需推翻,加一列"verified trajectory 交付"即可试点。
- **P3 标准与计量(远期)**:VSR/B 分级作为 agent 经济的计量标准(NAU 已有雏形)。只有 P0-P2 成立后才配谈。

### 3.5 产品楔子(2026-08-22 定):Verified Memory

- **定位一句话**:你的 coding agent 只从"被独立验证过的成功/失败"里学习——不重训、不改模型,越用越可靠。
- = SSI 的持续学习承诺,交付在我们今天就能落地的层(L1 记忆 + L3 燃料 QC + L4 蒸馏可选件)。
- 竞品坐标系:Mem0/Letta 记住一切(含噪声);我们只记 Gold(有 headroom 且验证通过)。判官盲区理论=我们的 QC 理论,标注/记忆公司短期补不上。
- 核心可感知指标:**重犯率**(同类错误再发频率)。第一人称素材:Gold(delta=1)、空转账账、空学发现。
- GTM 三步:①本周=胶囊盲测命中+重犯率仪表(四框自用)②下周=open beta(插件+云 MCP,锚 SSI 热度窗)③9 月=外部 agent 接入≥5,首条外部 Gold。
- 一页纸:`docs/PRODUCT_ONEPAGER_beta.md`。

## §4 单位经济(今天就能算的账)

- 一条 Gold 经验成本 ≈ **$0.008**(6 次 live 尝试实测,含 4 次失败)。
- 一条 Gold 的价值 = ①避免一次重犯(平均返工成本按人时×失败率折算)②蒸馏样本价(RLVR 市场单价 $1-10/条量级,我们是自产)③胶囊复用次数 × 每次增益。
- **盈亏结构**:燃料边际成本≈LLM 调用,验证边际成本≈CPU;贵的是**发现 headroom 的搜索成本**(今天 6 跑 1 Gold ≈ 17% 命中率)。→ L3 自动化 headroom 预检是毛利率的杠杆。
- 收入侧:FDE 现金流(买方合同)是 P2 的过渡形态;P7 若兑现,B3 燃料单价上行。

## §5 四层技术路线(垂直:每层给机制/指标/闸门/绞杀)

### L1 真值流水线 ✅ 通(8/22)
- 机制:V5/platform 产经验 → AdmissionLedger(幂等/防重放/异构 consume)→ Gate B 三臂。
- 指标:consumed 行数、Gold 率、verify 重放通过率(100%)。
- 闸门:真燃料 Gold ≥2(8/27 合约)。
- 绞杀:9 月中仍 0 且归因"模型都会" → 燃料线转 A 类难倒题,经验线并入胶囊召回(降级不砍)。

### L2 记忆/胶囊(接线中)
- 机制:Gold candidate → capsule_schema 生成(带 grant/run/oracle 溯源)→ 注入 recall 命中路径 → 新会话实测召回。**注意 L2 只重分配不抬顶(载体阶梯),预期收益=减少重犯,不是新能力。**
- 指标:胶囊召回命中率、"重犯率"下降(可从 fde/工程返工统计)。
- 闸门:任务书已立,生效验证=新会话盲测命中。
- 绞杀:若胶囊注入 4 周后重犯率无变化 → L2 判安慰剂,资源全转 L3/L4。

### L3 燃料 QC(今日新层)
- 机制:燃料入库前自动跑 control 臂(裸模型 N 次),headroom<阈值 拒收/降级;与 A 类"弱模型难倒"判据统一成一条 pipeline(出题与经验共用 QC)。
- 指标:headroom 分布、Gold 率提升(目标 17%→40%+)。
- 闸门:先手动跑 v1/d2 两燃料的 control 预检,再自动化。
- 绞杀:无。

### L4 权重蒸馏(2026-08-22 升格:不等 A800,大胆假设小心求证)
- **用户拍板:算力已有(A 簇 T4 等现役),可基于 qwen 级开源模型训练;停止"等条件齐了再动"的守势。**
- 三档价值产出,各自独立可卖,不再互相阻塞:
  - L4a **PoL 权重证据(即刻)**:T4 上 qwen-小模型 QLoRA,n≥3 B3 燃料即可跑"蒸馏前后对照"——不求结论成立,求**实验真的开跑**。判据:训练曲线+held-out 对照产出,无论正负。
  - L4b **规模验证(n≥12 后)**:A800/A 簇放量,on-policy CoT-Pass@K 协议(CHARTER 已定)。
  - L4c **产品化(证据成立后)**:"verified-distilled 开源小模型"= 产品栈顶层(P1 的可选件,非前置)。
- 纪律不变:对照必须外部 held-out、同分布外性分组、判 Gold/Repair 不许粉饰——大胆在开工,小心在判读。
