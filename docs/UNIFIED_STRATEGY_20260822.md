# 统一战略 · 真值带宽公司(2026-08-22 定稿)

> 整合:SSI 持续学习趋势 + 验证学习三论文 + compass 四层规划。
> 本文是跨框统一规划的一页真相源;各框细则见各自 SSOT/任务书。

## 一、统一定位(一句话)

**持续学习时代的上游真值供应商**:SSI 们把"模型持续从经验学习"变成现实(首模型 2026-08),而持续学习的死穴是"学到的必须是真的"——我们供给"真值带宽 B"(不可伪造的验证信号)、裁决"值不值得学"、并且先在自己系统里吃狗粮证明有效。

## 二、三层统一逻辑(为什么这三件事是一件事)

```
论文(理论)     :智能=压缩+验证 → 无验证空转 / 同构盲区 / 无headroom空学
                  = "为什么持续学习必须买真值" 的论证
compass(工程)  :燃料→ledger→学习环(Gold)→胶囊→更强行动 = B 的生产与消费流水线
SSI(行业)      :digital value function 持续学习 = 我们最大的下游需求方(正在发生)
```
三者互证:论文指导工程,工程产出论文证据,行业趋势给两者定价。
