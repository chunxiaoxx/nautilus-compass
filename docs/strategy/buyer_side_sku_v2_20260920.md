## SKU-A · 采购前尽调(主推)

**买方**:采购具身数据批次/agent 能力/模型集成的企业(机器人/具身训练团队/
平台采购)。
**场景**:签约或付款前,对卖方声称的数据质量/能力数字做独立技术尽调。
**交付物**:VerifyPack v0.3 验证包(episode cohort+invariants 声明+subject 三元组
+TTL)+ 三态回执(ed25519)+ 判据引用链 + 一页尽调结论(internal-audited 级)。
**定价结构**(按批次规模,验证深度三档):

| 档 | 范围 | 价格锚 |
|---|---|---|
| L1 算术一致性 | 声明 vs 公开/交付 artifacts 复算(seal 完整性/manifest/计数) | $499/批次 |
| L2 轨迹级 | + episode invariants 重放(帧级运动学/时序/碰撞对账) | $1,499/批次 |
| L3 全栈重放 | + 权重级/容器级重跑(需环境,预注册判据) | $2,999+ 按环境 |

**关键条款**:①判据预注册(开工前冻结,只紧不松)②§5b 牙齿条款同适用
(误判=OVERTURNED+退款+挑战成本)③回执带 TTL——**批次续采=续验,持续适航**
④结果只交买方,不公开(公开与否买方定;disagree 不树敌纪律同)。

## SKU-B · 验收环节嵌入(订阅形态,目标态)

数据飞轮连续采购方的 Day0 验收门:每 episode cohort 自动过验签+episode 判据,
回执 TTL 到期即续验——**验证即消费前提**的产品化。按月/按 cohort 计费,
定价挂 M2 后再定(先跑通 flywheel 自营首单)。

## 与免费层的关系

SDK 自证(attest/verify)永久免费=基础设施;付费层=**独立验证者**(验证者≠
实现者,I3)+ 尽调责任承担。免费层越普及,付费层的「独立性」越值钱——与
LE 杀死付费 DV 但 EV/组织验证存活同构。
