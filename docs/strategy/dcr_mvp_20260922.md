## 产品定义

**你给我们 20-50 条你的业务判断样本,我们还你一份 Jev 在你域上的签名校准报告。**

- 输入(三选一,隐私梯度):A 匿名模式=你描述业务模式,我们程序化生成域决策集
  (数据不出门);B 脱敏样本=字段替换后上传;C 真实样本(签 NDA)
- 处理:域决策集生成(200 题,seed 归档)→ Jev API 全量调用 → 三口径计算
  (准确率/Brier/ECE top-label+置信分层)
- 交付(48h):签名 PDF/MD 报告——①你域校准总读数 ②vs Jev 官方通用基线的偏移
  (我们研究 #1 的数据)③**使用阈值建议**(「置信打 X 折用」的操作性翻译)
  ④全部原始工件(可自复算);§5b 牙齿条款适用
