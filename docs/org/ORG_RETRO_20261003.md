## 二、核心主线提炼（278 commits 里真正的一条）

**"第三方数据有效性验证机构"的建造 = 判据 × 证据 × 机构**

- **判据**：预注册/零放宽/演进程序（v1→用户裁→审定→v2-final 全链本周实证）
- **证据**：三层标注（measured/inferred/U）+ sha 锚定 + schema v2 校验器
- **机构**：两线定价（判读免费/装订收费）+ 判例集（CASEBOOK_V1）+ 互操作协议（flywheel 会签）

其余全部是这条主线的形态：P3 判分器=机构的测量工具；paper1/2/3=机构方法论；G1/pusht/BC1=机构判例；rsi-bench 认证轨=机构被第三方采信。

**方向锚合并表述修正**：方向锚="具身采集+飞轮+验证平台"。G1（视频注入具身数据）与 pusht（机器人操作策略）本就是具身数据——判分机构判的正是"这批具身数据值不值得训练"。验证平台侧已实做；采集+飞轮侧是 flywheel/v5 的域。**主线与方向锚一致，此前"具身采集线无产出"的焦虑是叙事错位，不是工作错位。**
