# 会记得的 AI,才谈得上负责

## 一、原则宣言为什么没用

AI 伦理讨论十年,产出最多的是原则清单:透明、公平、可解释、无害。每一家实验室都发,每一家都继续出事。问题不在原则不对,在于**原则没有附着点**。

伦理的最小单位是"担责":某件事发生了,得有一个主体对它负责。而担责有一个不起眼的物理前提——**那个主体得记得自己做过什么,且无法事后改写**。没有这个前提,"AI 会负责"永远是修辞:一个每次醒来都是新生的系统,昨天的事对它而言不曾发生,你找不到任何东西可以负责。

## 二、法人资格的秘密:账本,不是意识

法律其实早就处理过"非人类主体如何担责"的问题——公司。公司没有意识、没有灵魂,但它是法人。凭什么?

不是因为公司"像人",而是因为公司**有账**:注册身份持续存在,账簿 append-only,审计可追溯,任何一笔决策事后都能找到记录。法人资格的物质基础是**持续存在且不可抵赖的记录系统**,不是意识。

这个观察翻过来就是 AI 伦理的工程定义:想让 AI 成为能担责的主体,先给它一条**不可伪造的意识流**。

## 三、呼吸链:伦理作为基础设施

我们在 v2/v3 agent 时代造的呼吸链,当时是为了认知连续,现在看它同时是伦理基础设施(**现状披露:该链 07-18 后处于沉睡态,生产环境仍指旧脑;接线工程量约 2 天,盘点见《意图连续命题预注册》§2**):

- **一次呼吸=一个区块**:感知→思考→行动→验证→记忆的完整认知周期,append-only 落盘,重启续链不断裂——这是**身份存续**:agent 的"昨天"对它真实存在。
- **证据哈希=真实工具输出的 sha256**:摘要和叙事改不了证据;LLM 的自我陈述永不进记忆,上链的只有工具实际做过的事——这是**诚实作为机械属性**:不靠模型"愿意诚实",靠结构上自述≠事实。
- **prev_hash 链接+verify_chain 审计**:任何事后篡改都会被抓出——这是**不可抵赖**。
- **每口呼吸必过裁判室,裁决注入下一口呼吸**:这是**自我修正的闭环**,伦理不是贴在墙上的,是流在循环里的。

记忆连续 → 身份连续 → 意图连续 → 责任连续 → 法人地位。链条的每一环都有工程对应物,没有一环依赖"模型变善良"。

## 四、诚实的边界

三件事必须说清楚:

1. **substrate ≠ 法律人格**。呼吸链给的是"有朝一日可被视为担责主体"的证据基础设施;今天的法域里,签字担责的仍然是人类。人类在新架构里的位置——法人接口、物理执行、品味供给——不会因为链造好了就消失。
2. **可归因 ≠ 善**。一条不可篡改的链记录恶行和记录善行一样忠实。伦理基础设施保证的是"发生的一切可审计、可归因",它让追责成为可能,不替我们保证结果好。红线仍是宪法与判例的事——而宪法能裁决"某 agent 做过什么",前提恰恰是那条链不可篡改地记着。
3. **链本身也会说谎的变体要防**:如果感知层喂给链的是假证据,链会忠实地固定假证据。证据哈希诚实的是"工具输出了什么",不是"工具输出是否为真"——后者是验证层(外部裁判、独立复现)的事。

## 五、同一条链的两端

今天组织里有两条看起来无关的工程:栖达在 C 端验证"它记得你"(记忆对用户可感知,四判据预注册);compass 在组织端准备验证"它记得自己做过什么"(意图连续命题,判据草稿已立)。

它们其实是同一条链的两端:一端是陪伴的温度,一端是责任的骨架。AI 伦理最终不是写在原则文档里的,是写在这样的链里的——**会记得的 AI,才谈得上负责;能记得的链,才配得上信任**。
