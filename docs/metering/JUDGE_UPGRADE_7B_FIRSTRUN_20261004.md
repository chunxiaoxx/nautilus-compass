## 三 · 判读发现(判官判官——对 7B 判读件本身的判读)

1. **"完成"=0 是材料分布属性,非判官缺陷** [实测]:主包 498 帧=progress 35%/80% 两档(p35/p80 帧名可数),无 100% 帧——判官须知口径下"完成"不可达。预备档"若 7B 仍零方差→任务设计层问题"条款不触发(方差已非零)。
2. **dim2 翻转的归因=7B 对"画面-进度标称一致性"严格执行** [实测+人工盲探]:盲探 3 帧(K_t00_e00_p35/p80、K_t00_e01_p80)——p80 帧目标物(字母汤罐+番茄酱)全在桌上未入篮,7B 判"未动+异常"与画面语义一致(80% 标称 vs 画面全未动);3B 全判"正常/部分"=盲从标称。**判据二义点浮出**:判官须知"画面与任务对不上→dim2=异常"中的"任务对不上"是否含 progress 标称?7B 按含执行,3B 按不含执行——**此二义恰是人类抽检标定协议(预备档 §三)要裁的第一题**,双轨互需实证。
3. **7B 修复了 3B 的 pos/neg 自相矛盾** [实测]:3B pos 全否+neg 全否(自相矛盾);7B pos 全否+neg 是 482(方向自洽)。
4. **7B 置信自评保守**(dim3 低 482/498)——与 3B(中 452)相反,是否更校准待人工标定判。
