# Embedder 对拍预注册判据档(2026-10-09 · MEMX 站2 检索底座 · R402)

> 用户令"对拍提前:今天就在 A100 起候选模型"。判据先冻结后跑,只许更严;承接 9/25 对拍纪律(自家分布实测,MTEB 账面不作数;emb-bakeoff-bge-stays)。

## 候选

| 模型 | dim | 说明 |
|---|---|---|
| **bge-m3(现役锚)** | 1024 | 在役判据:LongMemEval-S 全量 P@1 0.890 胜 mem0;不可自证弱 |

## 评测集(自家分布,三件)

- **Set A · 全库自监督**:155 条记忆正文为语料;seed42 抽 30 条,每条取正文前 200 字符为查询,金标=该条本体;指标 recall@1/@5/MRR
- **Set B · 中文切片**:Set A 中 CJK 占比>50% 的子集,同指标
- **Set C · 实弹三查询**:J4 三冻结查询(hit@3),即真实使用分布

## 判据(冻结)

- **换模型** = 候选在 Set A recall@1 **≥ 现役 +2.0pp** 且 Set B recall@1 **≥ 现役 +2.0pp** 且 Set C hit@3 不低于现役(3/3)
- 任一不满足 → bge-m3 留任,结果照发(负结果一等公民)
- 同分(±0.5pp)→ 留任(迁移成本不为零:全库重嵌+缓存版本键)
- 全部读数带 [实测] 标注;脚本与结果 JSON 入仓可复算

## 工程

- A100:模型走 modelscope(R303 pattern);eval 脚本用 transformers(与 embed_server 同栈);语料=本地 155 条 md 打包上传(仅进我方 A100,不出组织边界)
- 切换工程(若触发):全库重嵌+缓存键加 embedder 版本+外网终检回归——另立执行窗
