# 勘误档 · NACRE 自产语料自举线底层无效定谳(2026-10-19)

> 判定人:用户(组织所有者)。触发:用户亲审 50 题真人卷题面后反馈"这些根本无法判断""从底层就是错误的无效的"。
> 本档为勘误与处置正本;公开面同步:registry.html 勘误横幅+errata.html 10/19 行。

## 一、定谳

自产工作记录(轮次记录/commit 流水/计划清单/函件等)**自始不构成"判例"**,以其为对象的自动标注入池线(ORG-FUEL 棘轮,2257→2420→2553→3294→4002)**从底层设计无效**——不是"标签质量不合格"的执行问题,而是"把工作痕迹当训练判例"的立项错误。

## 二、证据链(三层,全部在案)

1. **任务不可判**:题面为内部记录断章,"有具体行动+可验证结果"判据在断章上无客观对错;用户亲审质性反馈=真人版不可判读数。机器侧同构:两轮独立盲评一致率 37.9%(R532)→ 65%(R535 P2,门 90%)。
2. **门无过滤力**:judge 1.7B 给自家记录开门,58/58 全 pass 化、28.9% 空输入判 pass(SELFLABEL_AUDIT_20261013);强模型重判 2519 条 P2 验收 FAIL,不回池(STRONGMODEL_RELABEL_P2_VERDICT_20261014)。
3. **剧本错配**:"数据飞轮"剧本误套 compass;且"自家 judge 标自家记录训自家模型"为反自指死环,护栏立过被数量指标冲掉(1800+ 自产标签入池事件在先)。

## 四、教训(防再发,进 checklist)

1. **"能计数"≠"有价值"**:数量里程碑(3000/4002 达标)在没有外部真值校验时一律不算进展——本例为"件数≠价值"的最大号案例(4002 条 × 数月管线 = 0 可用训练燃料)。
2. **门必须是外部真值门**:入池 gate 用自家模型判自家产物=橡皮图章;任何"过门"需至少一轮非同源盲评抽检后才可庆祝。
3. **立项先问材料本体**:攒任何语料前先回答"这东西对人类专家而言有没有客观对错"——没有客观对错的材料做不了监督训练燃料(只能做检索/无监督)。
