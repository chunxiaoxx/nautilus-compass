# 勘误档 · NACRE 自产语料自举线底层无效定谳(2026-10-19)

> 判定人:用户(组织所有者)。触发:用户亲审 50 题真人卷题面后反馈"这些根本无法判断""从底层就是错误的无效的"。
> 本档为勘误与处置正本;公开面同步:registry.html 勘误横幅+errata.html 10/19 行。

## 一、定谳

自产工作记录(轮次记录/commit 流水/计划清单/函件等)**自始不构成"判例"**,以其为对象的自动标注入池线(ORG-FUEL 棘轮,2257→2420→2553→3294→4002)**从底层设计无效**——不是"标签质量不合格"的执行问题,而是"把工作痕迹当训练判例"的立项错误。

## 二、证据链(三层,全部在案)

1. **任务不可判**:题面为内部记录断章,"有具体行动+可验证结果"判据在断章上无客观对错;用户亲审质性反馈=真人版不可判读数。机器侧同构:两轮独立盲评一致率 37.9%(R532)→ 65%(R535 P2,门 90%)。
2. **门无过滤力**:judge 1.7B 给自家记录开门,58/58 全 pass 化、28.9% 空输入判 pass(SELFLABEL_AUDIT_20261013);强模型重判 2519 条 P2 验收 FAIL,不回池(STRONGMODEL_RELABEL_P2_VERDICT_20261014)。
3. **剧本错配**:"数据飞轮"剧本误套 compass;且"自家 judge 标自家记录训自家模型"为反自指死环,护栏立过被数量指标冲掉(1800+ 自产标签入池事件在先)。

## 四、教训(防再发,进 checklist)

1. **"能计数"≠"有价值"**:数量里程碑(3000/4002 达标)在没有外部真值校验时一律不算进展——本例为"件数≠价值"的最大号案例(4002 条 × 数月管线 = 0 可用训练燃料)。
2. **门必须是外部真值门**:入池 gate 用自家模型判自家产物=橡皮图章;任何"过门"需至少一轮非同源盲评抽检后才可庆祝。
3. **立项先问材料本体**:攒任何语料前先回答"这东西对人类专家而言有没有客观对错"——没有客观对错的材料做不了监督训练燃料(只能做检索/无监督)。
4. **引用数字先实测再转述**(本日新增,用户质询"1032 人工题?真的是吗?"触发):引用任何存量数字前先开数据文件数一遍——见 §五。
5. **重启旧线先查前次终止原因**(2026-10-20 对账新增,正本 `EFFORT_ACCOUNTING_20261020.md` §五-2):复活任何已停线/已过期线前,必先找到该线上一次的终止记录与原因,并对照"导致终止的原因是否已消除"——未消除或无记录可引,不得重启。先例:8 月同型原型(燃料自动入池:63face90/07add59d/7a13f80f;垂域 fuel-pool 于 9/24 过期归档留痕 346b06fe)当年自然收场,10 月 ORG-FUEL 重启立项档(791f1935)无一处引用该先例。两条均已同步项目 CLAUDE.md 复发陷阱速览(每 session 必载层)。

## 五、追记 · "1032 人工题"口径勘误(同日,用户质询触发)

**原口径**:SELFLABEL_AUDIT_20261013 / STRONGMODEL_RELABEL_P2_VERDICT_20261014 两份判读档及对外 errata 账本 10/13 行均写"可信燃料=1032 条人工标签(LME-V2 系)"。

**实测修正**(split_train_v1.jsonl 1162 条逐条 label_origin,[实测]):

| 来源 | 条数 | 真值性质 |
|---|---|---|
| LME-V2 上游官方 answer_gold+透明 eval_function | 720 | 官方真值,机械复算 |
| LME 官方 truth+双层复算 | 400 | 官方真值,机械复算 |
| BC1 v1 逐题人工审计 | 16 | 真人工 |
| BC1 v2 重考+非实现者复算 | 13 | 真人工+复算 |
| T3 盲评/审计+compass_gates | 13 | 小样带审计痕 |

- **"人工"二字夸大**:96%(1120/1162)真值来自上游官方基准+机械可复算;真人工逐题仅约 35 条。
- **"1032"数字复不出**:精确子集不对应任何实测分布(候选口径 1120=上游系 或 1162=train 全量),以 label_origin 实测为准,原数字停用。
- **可信性结论不变但理由修正**:这批样本可信**不因为"人工"**,因为"有官方标准答案+判定可机械复算"(不依赖任何 judge 意见)——与自举判例的死因(无客观对错)正好相反。今后表述一律用"**官方真值基准的本地判定样本**",禁用"人工题"。
- 外部真评测题的采购/co-build 判据随之修正:**优先有官方真值的题源**(客户验收回执、公开基准官方标注),泛"人工标注"降为最后手段(标注员不懂域=复演 65%)。
- 历史判读档原文不改(delta registry 只增不删);本节为唯一正本口径。
