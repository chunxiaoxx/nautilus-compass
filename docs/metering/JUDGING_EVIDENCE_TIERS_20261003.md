# 判分证据分层纪律 v1(2026-10-03 · 用户拍板)

> 源起:G1 双臂判分(10/3)初判把数学推断写成断言发出,用户质疑后补实测(‖act−state‖=3.5e-5~7.4e-5 直读数据集)才坐实。
> 本档=判分/复算/验收类报告的**输出纪律**:每条结论性陈述必须标注证据层,推断不冒充实测。

## 三层定义

| 层 | 标注 | 定义 | 判分效力 |
|---|---|---|---|
| **实测** | `[实测]` | 我方直接运行/读取/重放得到的一手读数(附命令与工件 sha) | 可作判分依据 |
| **推断** | `[推断]` | 由实测数据经数学/逻辑推导的结论(写明推导依据;推断可被后续实测坐实或推翻) | 可作判分依据但须标注;升级为实测时勘误补强 |
| **不可验** | `[不可验]` | 材料不含验证所需信息(如过程性事实、单方陈述) | 不作判分依据,单列披露 |

## 输出模板(verdict/回执/报告通用)

```json
{
  "finding": "陈述",
  "evidence_tier": "measured | inferred | unverifiable",
  "basis": "实测:命令+sha / 推断:依据链 / 不可验:缺什么",
  "upgrade_path": "推断→实测的验证方法(可写 null)"
}
```

## 判分规则

1. **三态判定(PASS/FAIL/U)与证据层独立标注**:U 态可由实测得出(材料缺陷实测坐实),PASS/FAIL 不可仅凭推断链过长的一环。
2. **推断发布即带 upgrade_path**:发推断时就写明怎么验,不留给读者猜。
3. **初判缺口不粉饰**:材料未目检全、字段未核对的,在报告"coverage"段如实记(如"目检 3/16 帧")。
4. 判绩账双向:评委(我方)输出同样接受复算——本档纪律对内对外同标。

## 首案示例(G1 双臂 10/3)

- `[实测]` dir_rate=1.0 双臂,J2 带宽 0/16 帧,ratio 中位 4162/4257(材料 jsonl 逐帧读)
- `[实测]` ‖act−state‖=3.5e-5~7.4e-5 ep0 前 8 帧双臂一致(直读数据集)→ 静止段帧坐实
- `[推断→已升级实测]` ratio 数千倍因分母趋零(先由 pred≈act+ratio 反推,后实测坐实)
- `[推断]` 视频注入未传导到预测(双臂 pred 同形态;upgrade_path:注入帧与干净帧的 pred 逐帧对比)
- `[不可验]` 材料侧采样过程性陈述(8/40 帧是否 ep_ranges bug)
