# 预注册 · 14B QLoRA 判读器 smoke(2026-10-04 立项,用户拍)

> 依据:报数纪律(docs/soul/proposal_preregistered_recompute_20260914.md)——对外报数任务开工先落预注册判据档,判据只许更严;非实现者复算适用。

## 立项背景

- 判官现役 = Qwen3-1.7B QLoRA(P2v2,verdict-judge 88.51%,J1/J2/J7 三门绿)。
- 14B 升格路线的唯一务实入口:14B dense QLoRA 在 A100 40G 单卡的管线可行性(smoke)。
- 前提事实:14B=提取器非训练基座(P1 检索头 BGE 82.94% 胜出 14B 67.74%),故本立项仅探判读器升格,不动检索头;2026 旗舰 MoE 化,单 40G 卡大模型在线更新无解。
- 基座:Qwen3-14B(在库 28G,模型库存档 runtime/model_inventory.md);Turbo 重下完成后可作对照,不设门槛不计判据。

## smoke 判据(预注册,只许更严;全部 [实测] 层)

| # | 判据 | 门 |
|---|---|---|
| S1 | 训练完成:200 步 QLoRA 零 OOM、零崩溃、正常退出并落 adapter | 必须 |
| S2 | 显存峰值:torch.cuda.max_memory_allocated < 36G(40G 卡留 10% 余量) | 必须 |
| S3 | 收敛信号:train loss 末 20 步均值 < 首 20 步均值(非发散) | 必须 |
| S4 | 判读格式:训毕 adapter 加载,对 judge 语料抽 20 题推理,JSON 判读输出合规 20/20(复用现役 verdict-judge 输出 schema) | 必须 |
| S5 | 读数申报:同 20 题对 gold 一致率**如实入档**;smoke 级不设准确率门槛(small-n 不做升格依据),读数仅供参考 | 申报 |

- **升格决策不在本 smoke 判据内**——smoke 只回答"管线可跑否";若 S1-S4 全绿且拟升格,另立预注册(全量语料+判别力判据)再跑。
- 训练数据:judge 语料(qid 分组防泄漏版)抽 ≤500 条;标签=已固化人工/外部标签;**反自指护栏:判官自产标签不入训练**。
- 时窗:A100 空窗执行——跑前 nvidia-smi 实测无训练进程(B 臂 rollout 在跑即顺延);执行读数时间戳从 probe/服务器头抄。
- 复算:收工走非实现者复算(新鲜会话,只信判据与自测);交接只给坐标与命令,不给预期读数。
