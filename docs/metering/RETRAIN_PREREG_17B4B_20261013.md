# 现役线重训预注册档:1.7B-v2 重训臂 + 4B 观察臂(2026-10-13 · R530 · 用户令)

> 定位:4002 版语料(触发池严化 2843)对**现役线**的重训——与 8B 触发对拍同池/同切分/同配方,
> 读数横向可比。判分线,开工落判据(报数纪律);本档数字在出数前冻结。

## 一、臂位

| 臂 | 基模 | 配方 | 定位 |
|---|---|---|---|
| **1.7B-v2(重训臂)** | Qwen3-1.7B | LoRA r16/α32/dropout 0.05/AdamW 1e-4/**1 epoch**(与 8B 触发对拍同配方,单变量=数据量) | 冠军候选:过门则替换现役 champion(自举标签质量随 judge 升级,飞轮正循环) |
| **4B(观察臂)** | Qwen3-4B | 同上 | 只评测不入役:成本效益数据点(8B +1.0pp 的中间档参照) |

## 二、数据(与 8B 触发对拍完全同集)

- 触发池 sha16 `5045ff1235e345e6`(源池 c1aac9d8b47064a1==manifest);train 2543 / holdout 300
- qid 交集 0 [实测];自举标签 1811/2843(63.7%)——**自举回声风险知情披露**:重训臂在 judge 自判标签上训练,存在强化自身偏差的可能;对冲=对照臂同集对拍(读数为相对增益)

## 三、预注册判据(冻结,2026-10-13)

| 门 | 判据 | 口径 |
|---|---|---|
| **G1 不劣门** | 候选 acc ≥ 对照 acc(同 holdout 300) | 沿 R513/U5 结构 |
| **G2 显著门** | 候选 acc ≥ 对照 + **1.0pp** | 沿 R513/U6 结构取其半(同尺寸重训非跨尺寸升格,margin 减半;**禁出数后放宽**) |
| G3 精度门 | 若 1.7B-v2 升格:bf16 vs fp16 一致率 ≥99%(PRECOR 纪律) | 300 案同集;未过则升格冻结,记 upgrade_path |
| G4 披露 | 全部门读数+自举占比+配置如实入 report | 负结果照报 |

**裁定**:1.7B-v2 过 G1+G2+G3 → 升格 champion v2(轻量线现役,原 adapter 保留回滚锚);
仅过 G1 → 数据留档不切换;G1 不过 → 负结果归因(标签噪声/容量/数据量三归因)。
4B 臂只出读数,不参与裁定。

## 四、执行序列

1. A100 下载 Qwen3-4B(modelscope,~8GB);
2. 训练脚本参数化(--model/--tag),两臂串行 nohup;
3. 四门评测出判定表 → 升格或负结果归因;
4. 复算坐标(report+逐例+adapter 路径)随卡发布。
