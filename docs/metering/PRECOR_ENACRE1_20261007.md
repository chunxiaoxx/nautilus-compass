# PRECOR E-NACRE-1 · registry 条件化技能片路由实验(预注册判据档 2026-10-07)

> 承路线图 V0 §一(用户批准启动)。被测假设:**域路由技能片(基座+域 LoRA 热挂)判读能力 ≥ 单一大 LoRA(现役)**,且域内 acc 提升——成立则"原生动态权重 v0"成立。

## 一、设计

- **数据**:verdict 语料(去重 1453)按 artifact domain 分片;取样本量前 3 的域为 D1/D2/D3,其余并入 D-rest。分片清单与计数随档冻结(sha16)。
- **臂**:
  - A(现役基线):单一大 LoRA(best_lora,dbcbab6fd1ff5821)判全部 291 题(bf16-greedy)——直接复用 PRECOR B/C 已有读数(acc=0.8797)不重跑;
  - B(路由片):每域片 Di 用"该域 train 切片(合并锚回放 10-15%)”训练域 LoRA(底座同 Qwen3-1.7B,r=16 同 champion);推理按 domain 路由挂载(vLLM `--lora-modules` 多片);
- **对照公平性**:A 与 B 见过的训练数据量对齐(B 各域片训练量=对应域 train 计数,总 token 量差 <20% 披露);
- **评测集**:各域 test/dev 切片(训练前冻结),qid 全局防泄漏。

## 二、判门(冻结,只许更严)

1. **主门**:B 的全域加权判读 acc ≥ A(acc=0.8797)且 **Δacc ≥ +1.5pp**——路由复杂度必须换来可测增益,否则判"路由无增益坐实"(负结果照报);
2. **不回退门**:B 在每个单域上 acc ≥ A 在该域的 acc(不允许靠牺牲某域换均分);
3. **稳定门**:B 各片对各自 bf16 基线的一致率 ≥99%(PRECOR 制式复用);
4. 全部不过线=结论"路由无增益坐实",负结果照报入 NACRE §3.6。

## 三、执行与复算

- 环境:A100(同 B/C 栈);训练用共享卡空闲窗(与 groot 批任务共存,显存预算 8G 内,r16 小片可行);
- 时长预算:3 片训练(200 步级)≈2-4h+评测 30min;超 8h 中断报告;
- 收数:matrix CSV 行级写(v2 教训已吸收);非实现者新鲜会话按本档复算;
- 负结果与正结果均入 NACRE 白皮书 §3.6。
