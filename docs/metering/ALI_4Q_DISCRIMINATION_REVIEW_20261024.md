## 三、C 批每题自检阈值(判读层提炼,候平台/用户采认)

1. 区分度:国内组平均分(可得腿均值)须比 SOTA 组最低腿低 ≥20pp;任一组缺腿 ≥2 → 该题标 UNVERIFIED 不入交付 [推断,基于本轮单腿教训]。
2. 趋势一致:平均分最高者 passrate 不得低于平均分最低者(同向校验)。
3. 金标上界:任意模型组二值平均分=1.0(全员满分)→ 区分度信号为零,题回炉加难。
4. 五模型四轮=20 轮/题,覆盖率 <20/20 的题区分度结论只能带 coverage 脚注出。
