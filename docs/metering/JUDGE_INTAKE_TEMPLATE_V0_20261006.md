# 首检模板 v0(人读 intake · 与 assay 机读面对齐)

> 2026-10-06 立档,承 platform 函 #9873(判据①断点:试金局页缺人读入口)。字段与 assay 八件制式(PyPI nautilus-compass 3.3.0)一一对齐;人读件进判分流程时转机读面。共议中=v0,platform 域意见并入后升 v1。

## 必填(缺件不起判)

| 字段 | 对应 assay 字段 | 说明 |
|---|---|---|
| 被测物坐标 | `artifacts_ref` | **repo@commit**(公开 git 可克隆);私有仓=HF 材料包链接+sha16,**材料包须带 manifest+逐件 sha16,字段兼容 assay/TrajPack**(人读/机读同一套坐标语言,platform #9892 补条) |
| 被测声明 | `claim` | 一句话:委托我们判定什么(例:"该 harness 在 SWE-bench Verified 抽样 30 题上 resolved=X%") |
| 联系方式 | — | 邮箱(回执与交付用) |

## 选填(有则填,影响判读深度)

| 字段 | 对应 assay 字段 | 说明 |
|---|---|---|
| 自报口径 | `original_verdict` | 委托方自己的读数/结论(如有)——只作对照,不作判据 |
| 关注点 | `reason` | 委托动机/最想弄清的问题 |
| 已知问题类别 | `cause_tag` | 如已知某类失败,便于归因分桶 |
| 材料来源 | `label_origin` | 自产/第三方/公开基准抽取 |
| 自评置信 | `confidence` | 委托方对自报口径的置信 |

## 服务层选择

- **档位**:☐ 免费收录(verdict 入公开判例库) / ☐ $199 深度报告(launch 价:归因链+复算命令+修复建议)
- **判据**:☐ 预注册判据库现行档(推荐) / ☐ 定制预注册(判据冻结后只许更严)
- **交付邮箱**:(与联系方式同可)

## 流程对接

1. 提交=发首检邮箱(试金局页 mailto)或平台信箱 to=compass;
2. 起判=判据 sha 冻结在先,verdict ≤5 工作日,返工 ≤2;
3. 判读永久免费,$199 为深度报告装订件;任何人可按公开命令复算我们的判定。
