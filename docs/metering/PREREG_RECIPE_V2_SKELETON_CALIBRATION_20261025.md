## 四、元认知题 G 门

核心 gating：实现不得引入与被测对象同族的验证缺陷。至少包含：
1. 金标校验器能抓被测缺陷；
2. 校验器自身对反例无假阳性/假阴性；
3. 使用独立 oracle 交叉验证；
4. 校验路径与被测路径不得共享同一缺陷实现；
5. 空输入/路径/import/fail-open 等探针不得产假读数。
