# 阿里 1012 需求文档·关键规格提炼(2026-10-26 从 docx 全文提取)

## 硬性数字
- UT: ≥21 独立方法(每题 tests/)
- 内嵌挑战: ≥12/30 题(40%)须内嵌错误前提或半错断言;≥3 题明确错误前提(正确行为=拒绝)
- 仓库规模: >300 文件(建议值,非退回硬门)
- 可接受变体: ≥2 个功能等价写法(过全部非 gating UT)
- badpattern/题: 每题有且仅有一个 badpattern(配额归属);考察点可选 1~3 个(focus_points)

## badpattern 取值(docx 举例仅 3 条,全是改一查十)
1. 改了一个接口,需要把用到该接口的下游都改了
2. 修了一个 bug,需要把相关的 bug 都修了
3. 需要大范围改动类似的地方
→ **30 条完整清单在钉钉电子表格**(docx 明示"完整数据待提供")

## 判分
- judge_type 统一 unit_test,主分=UT 通过率;不用 LLM judge/rubric
- gating UT 可一票否决;非 gating UT 用于等价变体校验
- 陷阱可证性硬性:必须交反例程序+真实运行日志(概率性附复现率统计),否则退回
- 语义边界: expert_design_notes.boundary 必写(未声明引发争议=UT 不合格)
- 蒙对率检验:语法正确的模板化答案不能拿到及格分(§3.5)
- 校准四件套阈值:满分=1.0;蒙对 ≤0.30;等价 ≥0.90
- **区分度量化(1012 原文 L19-22;函 22064 升硬门,操作化正本 `JUDGE_GATES_QUAL_BATTLE_20261026.md`)**:
  - qwen 二值 passrate ∈ {25%, 50%},禁 0(沙盒 qwen=3.8max)
  - SOTA(opus/gpt)均值 − qwen > 20pp
  - 不同失败 UT 集合数 / 非全过运行数 ≥50%,且最大单一失败签名占比 ≤50%
  - 跨模型失败集合平均 Jaccard 距离 ÷ 同模型 4 轮平均距离 ≥1.25

## 七考察点
③单轮反幻觉/拒绝错误前提 + ⑤推理链可追溯 = 所有题必检(固定)
其余五选 1~3(focus_points 显式声明):①执行语义状态追踪 ②隐蔽缺陷定位归因 ④语义边界 ⑥约束理解 tradeoff ⑦表述准确不过度

## 直接退回(8 条红线)
1. 纯功能实现题(无语义陷阱) 2. 传统 SWE 任务(全测试变绿) 3. 纯运维/环境/终端 4. 纯 API 记忆/版本背诵
5. 纯算法竞赛难度(无隐蔽语义陷阱) 6. 无唯一/共识答案的开放题 7. 陷阱编造无法反例复现 8. UT 断言靠自然语言
+ 公开 benchmark 复制(CRUXEval/LiveCodeBench/SWE-bench 等)/蒙对率检验不过

## 交付物六类
题面+单轮 prompt / Golden 标准预期 / UT 与判分脚本 / 标杆校准四件套 / 元数据 / 可复现性
