# 归因报告制式 v1(判分机构·PMF 四件事之④产品化)

> 地位:把"一次一案"的归因(G1 五演实证)固化为制式件。用户 2026-10-05 拍"归因报告制式化优先"。
> 定位:**装订线收费物**(判后事)——判读免费,归因报告随判例装订或按件计;测量线榜面不嵌报告全文只引坐标。
> 首例实证:G1 差分归因(#2407 三条+#2413 阈值参考,flywheel 全采纳免重跑收官)——本制式即从该案结构提炼。

## 触发条件

凡判分 verdict 含「差分/根因/修复建议」段,即产归因报告件(编号 RPT-<案号>);纯通过性判定不产。

## 制式八段(每段强制)

| # | 段 | 内容与纪律 |
|---|---|---|
| 1 | **识别** | 受测物+版本+正本锚(sha16/commit);受测方;利益关系披露(装订客户/赞助/无) |
| 2 | **判定摘要** | verdict 坐标+主指标读数一行;证据层标签 |
| 3 | **现象** | 实测读数逐条,每条标 [实测]/[推断]/[不可验];推断带 upgrade_path |
| 4 | **归因链** | 现象→层定位(环境/数据/判据/模型四层选一或多层),**每步给可复算命令或证据坐标**;跨层追因时画链序(如:数据构造→判据灵敏度→模型行为) |
| 5 | **修复建议** | ≤3 条,每条带验收判据(可复算);超过 3 条说明没归因到底,退回第 4 段 |
| 6 | **反证自查** | 探针误诊排除记录(红灯先证伪自己):本报告出报告前排除过哪些自我错误(键名/阈值/路径类),至少 1 条 |
| 7 | **消费记录**(回填段) | 建议被采纳情况/复算请求/下游引用;空白=未被消费,如实留空不粉饰 |
| 8 | **判绩账**(回填段) | 本报告自身后续被勘误时在此追补,不改史 |

## 纪律约束

- 全档证据三层标注,推断不冒充实测(判分第三课);
- 归因不到层(只能说"可能是模型问题")=出 U 态报告,标注 MATERIAL_INSUFFICIENT,不硬归因;
- 报告自身走非实现者复算义务(与判分同规);
- 自家产物归因同样出报告并入判例集(自装不豁免)。
