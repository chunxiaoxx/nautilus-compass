# paper3 立项稿 · 《验证前置：因果倒置的验证机构》

> 状态：立项 v0（2026-10-04 起草）· 与 paper2（判官卫生协议）/paper1（验证学习）同系
> 一句话论点：**把验证从产出的下游搬到产出的上游**——验证机构不是给成品打分的裁判，而是先于产出定义判据、约束生成过程、并以可复算 verdict 结清因果的组织形态。

## 〇 · 核心论点（因果倒置的落点）

1. **传统因果序**：产出 → 评分 →（也许）改进。评分是事后审计，判据可被产出方倒推规避（teaching to the test 的机构版）。
2. **倒置因果序**：判据前置（预注册）→ 产出在判据约束下发生 → verdict 带证据分层结清。产出方在动笔前就知道"什么算数"，验证从筛选器变成生成约束。
3. **机构形态**：单次验证可被跳过，机构不可——判读免费/装订收费的两线定价、判例集复用、判据演进程序，让"被验证"成为产出方的默认路径而非可选合规。

## 二 · 差异化（novelty 边界）

- **对 LLM-as-judge 文献**（paper2 已覆盖失败分类与卫生）：paper3 不谈判官怎么坏，谈**验证作为组织过程**怎么立——判据治理/证据分层/定价机制是新增面。
- **对 verification learning**（paper1）：paper1 论外部验证之必要（为什么），paper3 论验证机构之形态（怎么做+谁来做）。
- **对 benchmark 认证实践**（rsi-bench/考场）：从单例认证上升到机构经济学——判读免费为何可持续（测量线无利益冲突）/装订收费为何只做判后事（不卖判决卖记录）。
- **真空位**：具身数据有效性验证无机构形态存在（paper2 Discussion 段已立论）——paper3 给出机构设计草案而非只指缺口。

## 四 · 风险与对立面真诚（预登记）

1. 质疑：判据前置会僵化创新？——回应：§3 判据演进程序即解（演进可走，程序不可绕）。
2. 质疑：判分机构自己谁验证？——回应：反自指护栏（判官自产标签禁入）+非实现者复算+勘误双向留档（案 2/案 4 自我证伪记录）。
3. 质疑：这是不是把评测包装成生意？——回应：两线定价的测量线零利益冲突设计；免费判读是机构信用的burn-in。
