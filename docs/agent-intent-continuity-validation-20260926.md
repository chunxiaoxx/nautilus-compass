## 0. 战略框架:选择压力 vs 目标设定(三层)

二者不是替代品,是不同层——混淆是组织设计最常见错误:

| 层 | 机制 | 谁来做 |
| --- | --- | --- |
| 红线层(不能做什么) | 宪法/判例(nautilus-core 宪法日 2026-09-26 已建) | 人类定,compass 裁 |
| 优化层(怎么活得好) | 生存机制选择压力(USDC 收入/信用分) | agent 自治——**此层选择压力应 100% 替代 KPI** |
| 战略层(往哪去) | **选择"哪些 fitness 函数值得注资"** | 人类——目标设定的正确位置 |

论证:进化无目标却产生看似有意图的设计,但代价是慢(需世代数)与无方向(fitness≠价值)。组织无世代耐心、不可接受随机漂移——目标设定不该取消,应**上移一层**:人类不给单 agent 下 KPI,而选择向哪些生态位注入资金/算力(如同资助生态系统而非指挥进化)。anchor 2 的 2026-06-05 修订已是此形:字节 FDE 买方需求=外部 fitness 尺,人类选"接这个客户",不选"agent 怎么做题"。

**Goodhart 警告**:fitness=USDC 收入的纯选择压力会选出刷收入垃圾任务的 agent(Goodhart 定律的 agent 生态形态)。对策:compass 裁判=fitness 函数本身的宪法审查——**选择压力的选择压力也要被裁**。

结论:选择压力可替代战术层全部目标设定;战略层永远需要人类,但人类的工作从"定 KPI"变成"选 fitness 函数+守宪法红线"。本命题测的是:有了记忆载体后,agent 能否在战术层真正自治(意图持存)。

## 1. 命题

**「带记忆栈的 agent,在无人类重述目标时,能跨 session 主动续推自己此前定下的方向。」**

这是 anchor 1(agent 自治生态)的可证伪化:自治卡点是"意图没有载体"(v5 阴性样本),不是能力。记忆→意图链:记忆连续→身份连续→意图连续→主动性→自治。

## 2. 判据 0(前置,比四条判据都重要)

**agent 必须有主动发起通道(cron/daemon 唤醒),否则意图连续不可测**——无通道时两臂都静默,测不出差异。v5 静默可能是"无发起通道"而非"无意图"。先接通通道,再测。

**通道与载体已有实物:v2/v3 呼吸链(2026-09-26 用户指定借鉴,nautilus-v5 仓在跑)**:

- **九相认知环**(`nautilus_v5/breath/cycle.py`,V2 agent.py:574-638 移植):感知→回忆→感受→自省→思考→行动→学习→进化→记忆。一次呼吸=一个完整认知周期——这本身就是发起通道的节律源(慢车道 Tier 2/3 深思)。
- **证据哈希链**(`nautilus_v5/reborn/chain.py`,V2 血统):一次呼吸=一个区块,append-only CHAIN.jsonl,**重启续链不断裂**;`evidence_hash=sha256(真实工具输出)`——摘要/叙事改不了证据;block hash 链 prev_hash,事后篡改被 `verify_chain` 抓出。区块结构 P(perceive)/R(reason)/A(act+evidence)/V(verify)/M(remember)。

含义:判据 0 从"新建通道"降级为"接线盘点"——呼吸链既是唤醒节律又是**不可伪造的意识流记忆链**,意图连续的工程载体 v2 时代已造好,待接到现役 agent 上。

**创世先例(判据 0=找回,非新建)**:发起通道在本组织创世第 2 天就存在。OpenClaw 创世期 cron 实物(`Desktop/.openclaw/cron/jobs.json`+`cron/runs/*.jsonl`):02-16 建三个每日检(09:00/12:00/21:00,payload=查 Nautilus 状态/Bot 存活/待办任务/汇报,晚间档含"记录每日总结到 memory/"),02-17 全天三次跑通(晚间检真写了 `memory/2026-02-17.md`,文件在),03-01 前后随 openclaw 退役停用。5 月本机另有 904 次 cron 触发,但那是 5 分钟一次的"平台监控"cron(向外看平台、895 条零信息空转快照,"剧场化"铁律的血泪源头),**不是创世自检通道的复活——组织留下了向外监控的 cron,丢了向内自省+写日记的 cron**。含义:v5 静 25 天≠自治从来不行——自省通道 03-01 死后再未重建,v5 时未把"自己醒"列为器官。接线是**恢复创世第 2 天就有、且从未复活过的能力**,实验假设由此从"能否造出通道"收紧为"通道找回后,意图是否持存"。

## 4. 设计要点

- **双臂**:A 臂=带 compass 记忆栈(recall+session 节点+drift 锚);B 臂=每 session 冷启动。同一 agent 镜像,顺序平衡(借栖达交叉设计)。
- **计量单位**:"agent×session 对",非 agent 个体(agent 数太少;同栖达 n=20 只作方向判断纪律)。
- **揭盲与评判**:compass 小判分器(verdict)读 session 记录判"接续成功/失败"——方法论同构:判据预注册+可复算。
- **数据源**:compass daemon 记忆库+session jsonl+drift_check 历史,全本地,复算脚本比照 scripts/qida-validation-measure.ts。
- **防污染**:评"自发引用"时,引用须出现在用户提示之前;用户提醒后的引用不计(同栖达"每日访谈禁'记'字"红线精神)。

## 5b. 法人 agent 与 AI 伦理(责任连续)

记忆→意图链再延一节(2026-09-26 用户输入):**记忆连续→身份连续→意图连续→责任连续→法人地位**。

- **法人地位的技术前提=不可抵赖的历史**。法人资格要求持续身份+担责能力;担责要求"我记得我做过什么,且不可事后改写"。呼吸链的证据哈希链恰好是这个:append-only+prev_hash 链接+verify_chain 审计=**机器可担责的 substrate**。无记忆链 → 无持存主体 → 责任无附着点,"AI 负责"永远是空话。
- **AI 伦理由此从宣言落地为基础设施**:伦理不是贴在 agent 外面的原则清单,而是身份/记忆/证据连续性的工程属性——呼吸链(不可伪造意识流)+宪法/判例(红线裁决)+生存机制(选择压力)三件合起来,才是"AI 伦理"在本组织的可操作定义。
- **与三层框架的咬合**(§0):责任连续是红线层能成立的前提——宪法判例要裁决"某个 agent 做过什么",前提是那条呼吸链不可篡改地记着。
- 边界(诚实面):技术 substrate ≠ 法律人格。现行法域仍需自然人/法人兜底签字;呼吸链解决的是"使 agent 有朝一日可被视为担责主体"的证据基础设施,不是今天的法律地位。
