## 一、gate 语义(与 VerifyPack 的分工)

- VerifyPack `aggregate` 只支持等式复算(claim.value == 复算值)——这是「防篡改」语义
- 验收判据大多是阈值型(≥99.9% 过门)——这是「过/拒」语义
- 分工:**gate 在数据方 build 侧执行**(tools/criteria/catalog.py `eval_gate`):实测值过 gate 才写进 claim;
  不过 = 拒装包或标 degraded。verify 端保持纯等式复算,spec 不动(9/15 冻结纪律)。
