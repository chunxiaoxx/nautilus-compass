## 三个选项

**A. 只报自家纵向**(untuned 19.6→tuned 40.0 + 判分修正故事),不列官方坐标
- 省事;但读者一查官方 README 就看到 42.8/74.9,被动
- ❌ 不推荐:我们刚吃过"读者自查发现真相"的亏(判分修正事件本身)

**B. 诚实坐标呈现**(推荐):列官方全表+我们的位置+两处口径差注记+升级路线图
- 成绩册叙事="记忆层方法的首个官方基准成绩+判分卫生学贡献(修正了 judge 预算坑)+与官方最强方法的三池/预算差距是明确的升级路线"
- 成本:零(今天可完成);可信度最高,且把"差距"转成"roadmap 叙事"
- 顺手修正 README 基准行的对比列(现在写 n/r,改为官方坐标)

**C. 对齐官方口径复跑再报**(gpt-5.2 judge+官方程序化判分+200k 预算,可能加三池)
- 最硬但工程量大:判分管线改造+OpenAI key 花费+可能要 GPU reader;延迟数周
- 且复跑大概率分更高(200k 预算+程序化判分对 structured 题更友好),顺序反了
- 建议并入 T1 攻坚(三池移植+预算放开一起做),不作为 T0 前置

## 推荐:B 先发(本周成绩册),C 并入 T1
