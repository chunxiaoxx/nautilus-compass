# MEMX · 记忆自催化飞轮设计 V1(2026-10-09 · 记忆层×涡轮机制×因果倒置融合)

> 用户问:记忆层三件套能否与 agent 对话框的 SFT+RL+基准评测涡轮机制借鉴融合,让记忆自我迭代自我催化,结合因果倒置与"智能=压缩×验证"。答:**能,且部件全在**——本文给融合架构、四站闭环、三向归因算子、护栏与分期。所有映射均为既有实件的组合 [实测-部件],闭环整体待跑通 [推断-待验]。

## 〇、点破:NACRE 全名即架构图

**N**ovelty-gated(=M5 修复二 dedup_check:写入前查重,新意门)· **A**djudication(=NACRE 判官:判定与验证)· **Compression**(=M5 修复一 fact_status+会话→判例的压缩写入)· **Registered Evolution**(=delta registry 棘轮:只增不删的注册化进化)。判分模型只是这套机制的第一个实例;把同一套算子装到记忆层,记忆就获得同款自迭代结构。

## 一、四站闭环(MEMX loop)

```
[站1 压缩写入] session/判读卡/勘误 → dedup_check 三档(merge/gray/unique)
      → fact_status 标注 → 入记忆库(1500+ 条,棘轮)
        ↓
[站2 检索验证] recall → J4 门(三冻结查询)+ drift 锚(25正35负,AUC 0.83)
      + E1 held-out 抽检 + 命中归因日志(recall→行为→结局 追溯)
        ↓
[站3 因果倒置] 任一 FAIL/U态/漂移 → 三向归因算子(见 §二)
      → 产出:定向补写 / 记忆勘误 / 检索调优信号
        ↓
[站3→1 回流] 修正与新增条目 → dedup+fact_status → 再入库(棘轮+1)
        ↘ 旁路:验证过的高置信条目+判例 → 带签名 SFT/RL 燃料
[站4 注册升格] NACRE v1.x 训练(语料棘轮+REG-100 零翻转门+held-out)
      → 新判官 → 更强的站1 质检与站3 归因 → 飞轮转速+1
```

## 二、核心创新算子:因果倒置三向归因(站3,全新 glue)

每次判读 FAIL / drift 触发 / 判据未命中,反演根因并三分类:

| 归因 | 机制判据 | 产出动作 |
|---|---|---|
| **甲·记忆缺口** | recall 无相关命中(coverage=0) | 定向补写任务(该记的没记) |
| **乙·记忆错误** | 命中了但内容错/过期 | 该条 fact_status 降级+勘误修正写入(记忆版 errata,delta 通道已有) |
| **丙·检索失效** | 记忆在但没召回(embedding/改写问题) | 检索调优信号(入 E1 held-out 集) |

实现=一个归因脚本(输入:判读卡/漂移事件;动作:查 recall 日志+dedup 库+fact_status;输出:三分类任务清单)。**纯 glue,零训练,本周可实现**——它把每一次失败变成记忆系统的训练信号,这就是"自我催化"的化学本质:失败不再只是失败,而是定向喂养。

## 三、与涡轮机制的逐项映射

| 涡轮机制 | 记忆层对应件 | 现状 |
|---|---|---|
| SFT(监督燃料) | 验证过的记忆条目+判例对(2258 棘轮) | ✅ 在产 |
| RL(奖励信号) | 记忆效用奖励:recall 命中→行为改变→结局改善(hit 归因日志) | 🔧 glue(归因日志) |
| 基准评测 | J4+drift 锚+E1 held-out;**元层:caliber-bench 方法论照检记忆基准自身漂移** | ✅ 有基准,元检待建 |
| REG-100 零翻转门 | NACRE 升级对记忆质检结论零翻转 | ✅ 机制在 |
| errata 活水 | 记忆勘误(delta 通道同构) | ✅ 通道在 |

## 四、护栏(反自指,从 RSI 启示继承)

1. **自训只限小判分器**:NACRE(≤7B)可吃自家验证语料;大模型绝不自训自家输出;
2. **NACRE 自身升级必须过外部锚**:held-out+REG-100+可被第三方复算——判官不能自己给自己发毕业证;
3. **记忆勘误走 errata 唯一通道**(同判例纪律),禁自动改写(M5 设计时已裁决:merge 只标注)。

## 五、分期

- **本周(glue)**:三向归因算子 v0 脚本+命中归因日志字段——判读卡 FAIL 自动产出三分类任务;
- **开业周(数据积累)**:归因日志随真实单积累;NACRE 小规模试判 fact_status 抽检(对拍现有标注一致性);
- **10/26 后(训练)**:语料 3000 触发 7B 对拍(判据已冻结)→ 若绿,NACRE v1.1 上站1 质检岗(REG-100 门后);RL 效用奖励等判例量再启。
