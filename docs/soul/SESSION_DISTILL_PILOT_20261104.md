## 三、管道五段

1. **抽取**: jq/python 取 user/assistant 正文(实测抽取比 1-3%,工具输出噪声 97%+);
2. **预过滤**: 规则判 C 组(空壳/纯值守轮),不进压缩机;
3. **压缩两臂对拍**: 本地臂(llama-server + 量化小模型,本机不出域) vs 参考臂(API 强模型,仅 10 会话定标);
4. **验证 L1 机械锚点(全量,零成本)**: 摘要中日期/路径/命令/issue 号/md5 必须能在源文命中;
5. **验证 L2 大模型盲评(抽查)**: 只送摘要+对应源文切片,评覆盖率与幻觉,逐条判定留档。
