# 能力地图与战略推演 V1(2026-10-09 · 开业前夜)

> 用户令:能力盘点→价值→竞争优势→作用→产品服务→倒推应该做什么怎么做。全部基于已实测资产 [实测],推断处标注;正本落 docs/soul/。

## 一、能力盘点(我们实际有什么)

**第一层 · 判读管线(核心资产,已实弹)**
- 预注册判据机制:先冻结标准(sha 锚)后看数据,只许更严——零事后改分
- 三态判读:pass/fail/insufficient_evidence——**"证据不足"是合法结论**,不给不确定的东西硬判
- 可复算性:每个结论附证据链(sha16 寻址),任何人可按判据档重算——**首卡已被平台独立复现**
- 五门验收/统一快照/零"部分通过"——严到不近人情,但这正是卖点

**第二层 · 判分模型(NACRE,自研)**
- 1.7B+LoRA,三态 88.5%,ECE 0.072;fp16 零漂移可用/int4 禁用(291 案实测的部署精度纪律)
- 成本优势:小模型判官,服务成本为大模型判官的零头
- 升级路径闭环:errata→新判据档→REG-100 零翻转门→新版本锚(7B 对拍判据已预注册,语料 2258/3000)

**第三层 · 语料与判例(数据资产,独有)**
- 2258 条 qid 去重判例(四源棘轮:判例集 16+6 勘误/delta registry/org-fuel/函件判例),**只增不删**
- 70 条生产运营轨迹(脱敏,失败过程逐字保留)——外部机构(XERJ)确认全行业语料库中此类数据为零
- 每张新判读卡自动入册→语料棘轮+1:业务即燃料

**第四层 · 基础设施(自有可控)**
- 客户旅程全链 API:intake→criteria→leaderboard→status→judge_status,全部公网可达,三层验证
- 本地记忆层(BGE-M3 daemon,17 tools,M5 三件套已上生产):检索超 mem0(LongMemEval-S 全 500 P@1 0.890 vs 0.774)+drift 检测(AUC 0.83)+跨 agent 合约
- cloud 复算管线(swebench 分批+用完即删):30 例一夜重算,29/30 逐例一致

**第五层 · 方法论与信用记录**
- 证据三层标注(实测/推断/不可验)强制化
- 勘误文化:6 例自勘误入册,"评委也会错、勘误留档"是信用资产
- 首例外部信用:平台独立复现首卡;rsi-bench 借轨 replay 认证

## 二、能实现什么价值(为谁解决什么痛)

**根本痛:AI 时代的"自报"不可信。**模型说自己行、基准说自己准、厂商说自己 SOTA——全是自己给自己打分。判分黑箱、判据漂移、污染、判官不稳定,无人兜底。

**我们卖的是"可信的第三方判定"**:
- 对**基准/榜单方**:你的榜单需要一个没人能指控"既当运动员又当裁判"的判读层(免费给你判,判据先冻结)
- 对**AI 产品方**:你的 agent 上线前,要一份"不是你自报"的独立验证报告(装订收费)
- 对**训练方**:你的自改进循环里,判官漂移会静默污染训练信号——我们提供校准过的判官+判例供给
- 对**生态(开发者/采购方)**:一张带 sha 锚和复现路径的"已验证"标,比一百个 star 有购买决策价值

## 三、竞争优势(为什么是我们)

1. **可复算是产品而非口号**:别家发"我们测了",我们发"你按这条命令重算,数对不上当天发勘误"——且已被实战验证(平台复现首例/v5 交叉 SQL/S6 全量 29/30)
2. **预注册纪律的护城河**:判据先行、零放宽,这要求组织级自我约束——竞争者模仿一句话,坚持一个季度极难
3. **负结果文化形成信用复利**:E-NACRE-1 负结果公开发布、6 例自勘误——"敢报坏消息"本身就是最稀有的可信信号
4. **判分器自检真空位**:caliber-bench(给基准打分的基准)全行业无同类;XERJ 证实语料库中"agent 轨迹+失败过程"数据为零——**两个真空位都被我们占住**
5. **成本结构**:1.7B 判官+自有复算管线,边际判读成本趋近于零——免费判读线可持续,收费线纯利
6. **数据飞轮已转**:每单判读→语料+1→判分器更强→判读更快更准——业务自喂养

## 四、发挥什么作用(生态位)

**一句话:AI 生态的"独立计量局"。**

- 上游:接基准方(出题的)、模型方(被测的)、数据方(飞wheel 具身数据线)的验证需求
- 我们不抢:出题(Navers Lab/Einsia 在做)、做记忆产品(mem0 在做)、做训练(各家在做)
- 我们独占:**"判得对不对"的终审位**+**"这个基准本身可不可信"的元审位**
- 协同:flywheel 判数据(具身侧)+compass 判可信(agent 侧)=一横一纵;XERJ 语料库=我们的分发渠道;v5=机器判读(L1)分工伙伴

## 五、产品与服务(卖什么)

**测量线(永久免费——获客与公信力)**
- L1 收录:任何 agent/harness 提交,预注册判据+三态判读+公开卡
- 复算服务:任何人可对我们任何结论发起复算
- 榜单+判据库+registry:公开可查

**装订线(收费——只做判后事)**
- 判例集(Casebook,已封版 v1.4:16 案+6 勘误)——按期更新订阅
- 独立验证报告(L2 深度判读):发布前审计,分档定价
- 协议植入:把"assay-verified"判读协议植入第三方流程(rsi-bench 先例:对方已实装)
- 认证背书:带 sha 锚和复现路径的"已验证"认证

**数据产品(探索)**
- 轨迹语料捐赠模式已验证(XERJ 首例)——可复制到更多语料库/训练方

## 六、倒推:应该做什么、怎么做

**从终局倒推**:判分机构的价值=被引用次数×判例存量×复算信用。终局态=行业遇到"这数可信吗"时默认想到我们。倒推三步:

**第一步(现在—10/12):开业零瑕疵**
- 终检复跑(已预演 12/12 绿)/冲正窗判读(五门已冻结,24h 卡)/RFC 表决(口径已备)
- 全部就绪,只执行不改判据

**第二步(10/12—10/26):第一个真实客户单+第一个引用**
- 关键里程碑:①首张**真实客户**判读卡(非 smoke)②首次**外部主动**复算请求(反剧场主尺)③首次被第三方报告/榜单**引用**
- 动作:开业周传播(PRECOR 博客短版+arXiv/Einsia/XERJ 已发件收口)+免费 L1 通道全开+每个判读卡带可复算路径
- 做法:每单判读当广告做——卡即案例,案例即获客

**第三步(10/26 里程碑裁决后):装订线开张**
- 语料 ≥3000(差 742,真实单流入自动补)→7B 对拍(判据已预注册)→判分器升格
- 判例集订阅制上线(首批=已封版 v1.4+开业周新增)
- 若 M1/M2/M3 未达:判读线继续免费运转(信用仍在累积),装订线降速——**免费线本身不亏(边际成本趋零),等得起**

**一句话总纲:判读免费铺公信力,判例和认证收信用溢价;语料棘轮和复算信用是复利,引用次数是唯一需要盯的北极星。**
