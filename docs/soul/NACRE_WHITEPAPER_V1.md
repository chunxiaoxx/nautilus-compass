## 第一章 模型是什么(一句话)

**NACRE 是 judgment-native 的判分模型**:输入任意 agent/系统的产出工件,输出**三态判定(PASS / FAIL / UNVERIFIABLE)+证据分层标注**;以增量 LoRA delta 的形式吸收组织判例与勘误,经零翻转门验证后写入版本化 registry,旧案判定永不回退。

如 Metis 之于 memory(记忆原生基模),NACRE 之于 judgment(判分原生判分模型)。

**为什么是三态**:判分场景的常态不是"对错分明",而是"证据不足"。强制二选一的判分器会生产幻觉判定;NACRE 的第三态 UNVERIFIABLE 是产品的一部分——"判不动就明说"本身是交付物(判例集 16 案中 U 态与证据三层标注全程在线 [实测])。

### 2.2 验证:三态不猜 + 证据分层

### 2.3 因果倒置:判例 → 燃料 → delta → registry

- P3 增量管线六段:白名单门→domain 门槛→增量 LoRA→REG-100 金标零翻转门→registry 注册→复算;
- **零翻转门(REG-100)**:任何 delta 不得翻转 registry 内 100 金标判例的判定——旧壳室永固,新室增量(珍珠母式生长的制度形式);

- errata 活水通道:外部勘误(delta_0001 起,现 33/200 燃料进度)——评委也会错,勘误即燃料 [实测]。

## 第二章·五 相关工作对照:Metis 与"判分原生"品类

MemoryTensor(上海)开源 Metis(4B/9B/27B,"世界首个记忆原生基模"):持久记忆态内置、推理时主动检索写入、无需重训边用边学;商业三层(开源生态/云服务/私有部署),500+ 企业客户。

**同构**:①能力内置化(记忆→权重内 / 判分纪律→权重内)②增量演化不重训(推理时写记忆 / delta→REG-100→registry)③小模型专业化 ④三层叙事(理论→OS→模型 / 公式→协议→判分器)。

**分野(定位护城)**:Metis 记"用户/业务经验"(个性化,越用越好,属**被验证方生态**);NACRE 压"判分纪律与判例"(机构能力,判断可复现、可审计,属**验证方生态**)。Metis 全篇无判据/预注册/复算语义——验证方生态位仍空 [实测对照]。

**吸收四点**:①借"-native"造词权立品类:judgment-native ②尺寸阶梯开源(1.7B/14B/未来梯队+训练评测框架全开源;Metis 30 天 HF 10k 下载=开源拉客实证 [实测])③三层商业化(开源生态→云判分 API→私有部署)④中立层定位句式:"正因为人人都在做评测,才需要中立的判分层"。

## 第三章 技术架构

### 3.1 基座与判分头

- 基座:Qwen 系 1.7B(现役)/14B(升格线);判分头=三态 verbalizer(PASS/FAIL/UNVERIFIABLE);
- 不追求通用能力:基座越小,判分知识的密度越高,部署成本越低(热路径 P95 42.2ms@A100、5.9G VRAM [实测,10/1 装前申报档]);

### 3.2 delta registry(sha 棘轮)

- 每个合规 delta 携带 sha16 锚定;registry 只追加不覆写;任何部署可声明"我运行在 registry@vN";
- 复算协议:任何人按公开命令独立复验判定(判例集 16 案全带复算命令 [实测]);

### 3.3 训练管线(P3 六段)

燃料白名单四类(independent_recompute / human_review / official_rule / three_vendor_final)——**判官自产标签永久禁入**(防自指护栏);domain 门槛防单一域过拟合;REG-100 零翻转门。

### 3.4 评测与升格协议

- 三门判据:J1 主判精度 / J2 校准 / J7 泛化(跨域 held-out);
- **非实现者复算**:升格决策(1.7B→14B)必须由新鲜会话按预注册判据复算(档 PREFOR_JUDGE14B_UPGRADE,七门,U5 不劣门+U6 显著门);
- 14B 现状:smoke 五门全绿 [实测,10/5];升格复算待执行(判据已冻结,只许更严);

### 3.5 部署形态

- 热路径 API(A100 实测吞吐 118 条/s);PyPI `nautilus-compass`(assay)3.3.0 提供判据校验 CLI(判分服务姊妹产品,公网可装 [实测]);
- 判分员工位:组织内部质检岗(flywheel 职员制四岗位之"判分岗",同栈机构分离先例 #2508 披露案);

### 3.6 边界与已知缺陷(如实报)

- 判读器偏置:A 型复验 1/11 负结果如实报 [实测,R168 档],修复三路径待拍板;
- 升格未证:14B U5 门未过前不宣称"更大=更准" [实测];
- 语料依赖:判例主来自组织内部判读(33/200)——白名单门防自指,但域覆盖度是长期约束 [推断];
