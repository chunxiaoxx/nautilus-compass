# Compass 的过去、现在与未来：有来源的梳理

任务 `COMPASS-HISTORY-PRESENT-FUTURE-20261103`；owner：Compass 本仓主会话 / Codex。用户要求：“弄清楚 compass 的过去现在未来”。运行取样：2026-11-03 05:15–05:18 UTC。本档是派生审计与解释，不替代职责目录、业务台账、实验预注册或训练授权。

**Compass 的连续主线，是把 agent 的经验变成有根据、能验证、能改进后续任务的能力。** 长期记忆负责保留与调用经验，assay/JEV 负责判定与复算，涡轮机制把经验证的反馈送回记忆与模型；专门的创新架构小模型是这条路线的目标。系统级部件已有实物，完整机制内生于模型仍待实验。

当前依据是 11/2 用户确认及 `agent_catalog.json` 的 Compass 条目：**长期记忆、assay、jev；以“智能＝压缩×验证”为原则，沿既有因果倒置正本推进创新架构小模型。** 旧文档的三因子写法、旧商业北极星和旧框分工保留为历史，不能改写今天职责。[S01/S02]

## 4. 必须带入未来的三条教训

**材料先有可判断的真值，才能谈训练。** 10/19 的定谳没有否定真实失败经验的价值，否定的是“工作痕迹→自家模型自动贴标签→数量达标→训练”这条无客观真值的捷径。11/1 的失败模式转能力任务可以继续：回到原始事故，构造可重放案例，明确程序 oracle/外部真值、反例和验收，再决定进入检索还是训练。单纯把旧记录重标一遍，会重演旧失败。[S12/S16]

**每个改进都要回到实际任务结果。** 早期 drift 低 act-on、8/23 的 recall 有用性实验、10 月空循环，反复说明：记得、提示了、脚本跑了，都不能自动推出任务变好。记忆效果要测是否减少已知错误、是否改善任务成功、是否降低总成本；模型效果要由冻结测试与消融确认。[S03/S13/S37]

**独立验证也要覆盖自己的体系。** judge、判据、探针、训练标签、模型部署都可能出错。保留不可判、负结果、勘误与独立复算，是 Compass 能成立的基础；自家模型给自家材料背书不能替代外部真值。[S06/S12/S25]

## 5. 未来：沿既有正本推进的顺序与门槛

下面是依据现有正本得出的建议顺序 [推断]，不是已获通过的实验结果，也不是另立业务状态。

### 第一步：可靠记忆与原始工件，先让已有资产可用

记忆侧，用真实任务回放检验“命中→读源→正确采用→结果”，专门覆盖新指令覆盖旧记忆、过期状态、相似但错误来源、空召回与噪声条目；同时核运行开关与当前消费者。结果同时披露任务效果、延迟和失败。

模型侧，下一件已收束到既有 A100 入口的认证条件与 `/root/vdd2/p0_full/out` 小索引读取；拿到索引后再确认 anchor 真实位置，核 SHA、行序、fold、label、metadata、数组形状。继续沿用 11/2 限定交接，不把找不到一份文件变成无限考古。[S17/S18]

### 第二步：把经验转成别人也能验的能力

承接 `TASK_MEMORY_FUEL_20261101`：先做事故→可判据能力映射，再复用已有 assay/VerifyPack/记忆门形成最小能力。每项先给原始病例、失败与成功对照、冻结判据、输出工件及非实现者复算路径。现有 assay/JEV 发布件应各有准确入口和可复算样例，再看实际消费者能否走完。外部采用与付费是需求证据，和技术通过分栏记录。[S06/S15/S16]

### 第三步：做一次能证伪的创新架构实验

正本定义的机制可以用五步理解：**锚定目标结果 → 从经验/锚点库反向检索候选因 → 对候选路径验证 → 低置信走顺向兜底 → 把经验证的结果反馈给记忆与模型。** 训练期用真值果锚，推理期还必须承受错误锚点测试。检索到相似片段只是其中一环。[S19/S20/S21]

执行前，先把既有文档的差异绑定到同一份预注册执行 manifest：

1. **指标**：组织原则“智能＝压缩×验证”、总量 `I_eff=C_t×V⁺`、效率 `η=C_m/V⁻` 分别标注。有效秩口径说“C 低压缩好”，映射到 C_m 的单调关系仍是开放问题；不能径直把有效秩比值上升宣称为智能提升。
2. **数据与判据**：工程规格写 CauseNet/BigCause/标准多跳，蓝图建议 verdict/CV/数值；“相对下降 2%”与“±2 个百分点”也并列存在。必须明确最终冻结版本，不能临时采用更宽口径。
3. **完整对照**：原生主干、逆因果检索头、+SSI、+JEV、纯相似度检索头；另设混淆变量、OOD、错误果锚点测试。纯相似度对照用于判断收益究竟来自因果对齐还是普通筛选。
4. **完整成本与效果**：投影、索引、距离、验证和兜底全计入成本，FLOPs 与端到端时延同报，并守准确率、错误率和回归门。使用程序校验或人工盲评，按正本禁用 LLM 终判。
5. **点火条件**：回读当前资源、M1 复盘/pivot、G1/P2v2 状态、CPU 度量实现和冻结判据。10/2 曾有条件提前点火授权，11/2 的独立读回确认其存在；日期到期与历史许可都不能代替当前条件核验，也不能据旧冻结字样宣布永久禁止。

这些门过了，才讨论按需训练与逐组件内生化。NACRE 六能力是目标图；1.7B 判官、外挂记忆和系统级编排是已有部件；由果溯因是否给出额外效率与可靠性收益，仍待上述实验判定。
