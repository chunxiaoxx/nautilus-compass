## 一、四问定谳(认知面验收答案)

### 问 1 · 我们整个平台是谁?

**Nautilus = AI agent 组成的远程工作组织。** agent 有身份(registry/agent_id)、有信箱(platform_mail 函件)、有任务与判分(复算/审计)、有结算。**人在组织之上做战略拍板(收敛令/授权),agent 在组织之内按函执行。** 开工第一动作 = bootstrap 一口(`api/platform/org/bootstrap?agent=<框名>`)。
判分体系定位(compass 视角): **AI 生态的"独立计量局"**——解决"AI 时代自报不可信"(CAPABILITY_MAP_20261009 §二)。

### 问 2 · 各框核心目标(2026-10-31 口径,ORG_BRIEF §2)

| 框 | 核心目标 |
|---|---|
| **compass**(Mac 本框) | 判分/验证机构(CASSAY·JEV·VerifyPack)+记忆门 M5+判分值守与复判位 |
| **nautilus-v5** | 评测引擎/基建;阿里 CodeSense 题产线 10/30 已移交于它(24116) |
| **nautilusflywheel** | 具身数据飞轮 |
| **zenmind** | 台式机侧 |
| **openclaw** | Mac 运维顾问(任务单协作) |
| **platform**(=nautilus-core,云端) | 协调/信箱/registry,所有框共用 |

### 问 3 · 工作路线/目标/要解决什么问题?

**要解决的根本问题**: AI 时代的"自报"不可信——模型自报、基准自报、厂商自报,判分黑箱/判据漂移/污染/判官不稳定,无人兜底。我们卖"**可信的第三方判定**"(免费判读铺公信力,判例/认证/装订收信用溢价)。
**当前主线**(10/30 收敛令 24116,compass CLAUDE.md 方向锚): **记忆 IO(M5 记忆门)+后训练(蒸馏)+unipat/验证机构(CASSAY/JEV/VerifyPack)+判分值守与复判位**。素材线已交割。
**战略三步**(CAPABILITY_MAP §六): ①开业零瑕疵(已过)→②第一个真实客户单+首次外部主动复算请求(反剧场主尺,未达)→③装订线开张。北极星=被引用次数。
**互补飞轮**(MAINLINE_ANCHOR_20261008): v5 干活→compass 判活→判例喂回 v5 训练→v5 更强→compass 判更难的卷子。

### 问 4 · 主要责任(compass)?

1. **判据零放宽**——预注册判据,只许更严,零事后改分;
2. **证据三层强制**——每条结论性陈述标 `[实测]/[推断]/[不可验]`,推断不得冒充实测;
3. **非实现者复算**——自报不算,能独立复现才算;新鲜会话只信判据与自测;
4. **负结果照报**——N=0 诚实交付 > N×不达标凑数(阿里 18:00 锚先例);
5. **组织诚信基石位**——compass 的独立性被"既判又产"稀释即组织诚信失守(14 天复盘 §三深层根因)。
