## 一、模型是什么(一句话)

**NACRE**——judgment-native judge model(判分原生判分模型):把"判分纪律"压缩进小权重(1.7B/14B)的**专用判分模型**;输入=任意 agent/系统的产出工件,输出=三态判定(PASS/FAIL/UNVERIFIABLE)+证据分层标注,增量式吸收组织判例与勘误,永不遗忘旧案(registry 棘轮)。如 Metis 之于 memory,NACRE 之于 judgment。

## 二、三支柱(全部实证在档)

1. **压缩**:1454 判例语料 → 1.7B LoRA 判分器 88.51%(三门 J1/J2/J7 全绿,9/30);三态 verbalizer 天然校准。判分知识=组织最稀缺资产,压缩进小权重=可复制可部署可卖。
2. **验证**:三态不猜文化(没证据就 UNVERIFIABLE)+证据三层强制标注(measured/inferred/unverifiable)——市场证据:信任市场无验收标准(数商调研 R197),三态=可商业化产品化的"验收"。
3. **因果倒置**:P3 delta 管线——新判例/勘误(errata gold)→ 增量 LoRA 训练 → REG-100 金标零翻转门 → 入 registry;热启动重训实证无增益(exp1/exp2 六组合反向证据),增量是唯一有效路径;33/200 燃料进度。**鹦鹉螺式生长:旧壳室永固,新室增量。**

### 二·五、相关工作对照:Metis 与"判分原生(Judgment-Native)"品类(2026-10-06 增)

MemoryTensor(上海)10/5 访谈+开源 Metis(4B/9B/27B,"世界首个记忆原生基模"):持久记忆态内置于模型、推理时主动检索+写入经验、无需重训边用边学;商业=开源生态/云服务/私有部署三层,500+ 企业客户(招行/海诚/荣耀等),合同数千万级。与我们的同构与分野:

- **同构**:①能力内置化(记忆→权重内 / 判分纪律→权重内)②增量演化不重训(推理时写记忆 / P3 delta→REG-100→registry)③小模型专业化(4B/9B/27B vs 1.7B/14B)④三层叙事(理论 Memory³→OS MemOS→模型 Metis / 架构公式→协议 assay→判分器)
- **分野(定位护城)**:Metis 记"用户/业务经验"(个性化,越用越好);我们压"判分纪律与判例"(机构能力,判断可复现、可审计)。Metis 全篇无判据/预注册/复算语义——**验证方生态位仍空**,他们属被验证方生态。
- **吸收四点**:①借 "-native" 造词权:**Judgment-Native(判分原生)**,对外锚句"NACRE=judgment-native judge model,如 Metis 之于 memory"②尺寸阶梯开源(1.7B/14B/未来 7B 梯队+训练评测框架全开源;Metis 30 天 HF 10k 下载=开源拉客实证)③三层商业化(开源生态→云判分 API→私有部署企业定制)④中立层定位句式("正因为人人都在做评测,才需要中立的判分层")
