## 项目一句话

nautilus-compass 是一个面向 Claude Code、Cursor 和其他 MCP 客户端的本地 agent 记忆与可靠性层。它把长期记忆、漂移检查、跨 agent 合同和可复算的 Assay 验证工具放在同一条证据链里。

## README 中文简介

> **nautilus-compass** 是开源的 AI agent 本地长期记忆与可靠性层。它支持 BGE-m3 本地召回、漂移检测、跨 agent 协作合同，以及 Assay 独立验证工具链。项目强调把“模型或平台自己声称的结果”变成可复算的题包、判据和回执，适用于 Claude Code、Cursor 和其他 MCP 客户端。

## 专稿建议标题

**当 AI 记忆也需要验真：nautilus-compass 如何把长期记忆和独立验证接起来**

## 专稿建议结构

1. 开发者为什么会遇到“记住了但答错了”和“跑分很高但无法复算”。
2. Compass 的本地记忆路径，包括项目隔离、BGE 召回和历史经验按需回读。
3. Assay 的三态判决，包括 agree、disagree 和 not computable，以及失败结果保留规则。
4. 迁移到不同 agent、模型和平台后，为什么必须同时检查语义连续性、权限和消费端结果。
5. 用一个公开案例展示“原始输入、判据、运行命令、回执和独立复算”如何串起来。
6. 结尾给出开源仓库、协议、复算脚本和安全边界。

## 模型中转站横评建议

横评应先冻结样本和口径，再开始测试。

- **身份核对**：渠道声称的模型名、版本、上下文长度和供应商是否一致。
- **行为核对**：固定问题集上的回答是否稳定，是否出现模型偷换、截断或隐藏 fallback。
- **价格核对**：公开单价、计费单位、上下文和输出价格、最低充值及有效期分别记录。
- **可用性核对**：请求时间、首 token、完整响应、错误率和限流行为都保存原始记录。
- **证据等级**：实测、推断、无法验证三类分开展示。
- **重复性**：同一渠道至少重复运行两次，保留时间、模型标识、请求摘要和响应哈希。
- **措辞边界**：只评价本次样本和时间窗口，不写成对渠道的永久背书或永久否定。
