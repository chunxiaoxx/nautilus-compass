## 一、主打造词

### Judge Hygiene · 判分卫生学

- **一句话定义**(可直接进 glossary):**LLM-judge 评测中,为使分数可信而对判官本身执行的纪律——判据预注册、函数级冒烟、静默失败检测、双口径强制披露、置信区间报告。**
- **反面**:它反对"跑完 harness 出个分就发榜"。判官是 LLM,会静默失败;不审判官,排行榜是虚构的。
- **我方证据锚**:抓了自己判官 5 次;一次网关断连把 14.2% 的题静默记成错答;修正方向曾完全相反(web +3.3 / ent −1.9)。paper2 主题。
- **为什么是这个词**:"hygiene" 带临床感——不是高深理论,是**不做就会出事的基础操作**。行业痛点公认(每篇 judge 论文都在呼吁),但无名字;命名空缺 = 注册窗口。
- **首发阵地**:paper2(arXiv 在投)标题/摘要强用;HN 备选标题已埋("We caught our own LLM judge silently failing five times");README glossary。
- **邀请句**(评论区通用):"If you eval with an LLM judge, you're doing judge hygiene whether you name it or not — we published our protocol."

### Write-Time Wager · 写入时赌注(收编定型)

- **一句话定义**:**在写入时刻对记忆做有损压缩/提炼,等于对未来查询分布下注——而该分布结构上不可知,故赌注在结构上输。**
- **反面**:它反对"写入时提炼是智能的体现"的默认叙事。
- **我方证据锚**:三不变量(未来查询不可知/原文唯一可重索引/成本曲线方向反了);同记忆同题 42.6%→75.4% 全靠读取端。
- **收编叙事**(诚实且更强):"Everyone in agent memory is already making this bet — Rune calls it a bet, Mem0 frames retrieval as bets. We just gave the wager a name and showed the house always wins."(行业已在下注,我们命名了这个赌局并证明庄家稳赢)——竞品在用同款语言,我们定型定义,定义权归先者。
- **首发阵地**:PPT v2 标题句(Don't summarize the past for a future you can't predict 的术语化身)、Reddit 主帖、架构长文。
- **衍生短句**:中文"替未来的自己盲目下注"(已有);英文 "the house always wins" 收尾。

## 二、协议构件名(跟随主打通传播)

| 词 | 定义 | 出处 |
|---|---|---|
| **Dual Accounting · 双口径强制** | 同一评测必须同时报全集口径与剔除判官故障题口径,缺失任一即为不完整披露 | 71 题断连事件 → 75.4/81.6 双报 |
| **Eval Preregistration · 评测预注册** | 判据、门、组合在跑数前锁定并落 hash,跑数后不得回头改 | 预注册锚文化(借自临床/心理学复制危机,首个系统性迁入 agent 记忆评测) |
| **Judge Autopsy · 判官尸检** | 判官静默失败后的复盘程序:污染面、方向偏移、重判口径三件套 | 5 次事故复盘流程固化 |

## 三、产品能力词(固化自用,不强求行业采用)

| 词 | 定义 | 出处 |
|---|---|---|
| **Memory Capsule · 记忆胶囊** | 跨 agent 经验继承单元:验证(reward ≥ 1.0 防毒门)后写回,按需继承 | 进化层 |
| **Zero-Write Intelligence · 写入零智能** | 写入路径 0 LLM 调用,全部智能置于读取端的架构取向 | 反架构六层 |

## 四、推广打法(词不传播=没造)

1. **README glossary 段**(落仓动作,见 §五草稿)——repo 是术语的"注册地",被引用即被定义
2. **paper2 全文统一用 Judge Hygiene**(标题级)+ 定义段——论文是术语的最高背书
3. **帖子纪律**:五断言物料里术语强制出现;不解释第二遍(别人问就答,答完给 glossary 链接)
4. **占领搜索**:HN/Reddit 标题与首评自然使用;若有人复用,立即善意引用("glad the term is useful — definition here")
5. **不碰瓷**:不用术语攻击竞品("你们没有 judge hygiene"❌);只描述自己("our judge hygiene protocol includes…"✓)

## 五、README glossary 草稿(待定名后合入)

```markdown
## Glossary

**Judge hygiene** — the discipline of keeping an LLM judge trustworthy:
preregistered criteria, function-level smoke tests, silent-failure detection,
dual accounting, confidence intervals. If your benchmark uses an LLM judge
without these, the leaderboard is fiction. See PROTOCOL.md / paper2.

**Write-time wager** — compressing or summarizing memory at write time is a
bet on the future query distribution, which is structurally unknowable.
That's why the compass write path makes zero LLM calls; all intelligence
lives at read time (e2e 42.6% → 75.4% on identical memories and questions).

**Dual accounting** — every score is reported twice: full set, and judge-
outage-excluded set. A single number hides judge failures; two numbers
disclose them.
```
