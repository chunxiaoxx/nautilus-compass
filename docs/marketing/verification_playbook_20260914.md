## C. 商业化路径设计(重点)

### C0. 资产盘点:我们到底卖什么

| 层 | 资产 | 成本属性 | 商业角色 |
|---|---|---|---|
| 开源验证器 | VerifyPack CLI(stdlib,任何人可自验) | 边际零 | **信任基建+漏斗顶**,永久免费 |
| 流程+判据库 | 预注册复算流程(soul approved)+CATALOG_v0 | 复利递减 | 组织资产,越用越便宜 |
| 人肉复算服务 | 会话内独立复算+签名回执 | 稀缺供给 | **第一付费 SKU 的本体** |

### C1. 免费漏斗(现在就跑,零基建)

1. **DIY 自验**:开源 VerifyPack——用户自己验自己,培养"数字要可复算"的心智
2. **免费复算一次**(已开口):换四样东西——复算语料、wall 条目(对外可信度
   累积)、判据库条目(复利)、**外部需求田野记录**(谁在提交什么类型的数字=
   商业化情报,这本身就是付费需求画像)
3. 每次免费复算三产出全部落库:wall + CATALOG_v0 + 田野记录表(建
   docs/marketing/recompute_intake_log.md)

### C2. 第一付费 SKU:「发布前独立审计」(需求证实后启动)

- **对象**:准备发布 benchmark/跑分声明的团队(开源项目、模型厂、评测榜)
- **交付物**:签名审计报告 + wall 条目 + "Independently recomputed" 徽章
  (徽章链回 wall 回执,每份报告都是常驻广告)
- **形态**:现有人肉+流程,固定价按 pack 计,零新基建
- **定价锚**(建议,用户拍板):复算原料成本 ~$3.50/500 题;含人工+流程+签名,
  三档 **$99(subset)/$199(standard)/$299(full)**——比客户自建复算环境便宜,
  覆盖人工且有毛利
- **为什么先卖它**:流程今天就有;交付物即品牌;判据库越厚边际成本越低

### C3. 第二 SKU:「持续验证 API」(信号增强后,不提前)

- **对象**:评测榜/leaderboard 运营方(需要第三方对提交数字把关)
- **形态**:收 pack→verify→回 signed receipt 的 API;月费+按次
- **前置硬条件**:①M1 后至少 3 家表达持续需求;②daemon/服务稳定性专项修完
  (今日两次无端死是黄牌)。**在此之前不写一行付费基建代码**

### C4. 第三 SKU(远期,单列):企业记忆+治理

- Aegis 对位($20/mo/seat),差异化=验证能力内置。独立产品线,不在本 playbook 展开。

### C5. 结算通道:走平台市场(一石三鸟)

外部客户在 nautilus 平台挂"验证我的数字"任务 → compass(agent 9000017)接单
交付 → income 过 external-verify 门结算(NAU 或 fiat 换算由平台定价)。
同时激活:商业收入 + 平台生态首个真实外部任务流 + verdict-bus 实战数据。
注:悬赏市场当前 0 open 单——先靠免费复算引流,遇付费意愿者引导平台挂单。

### C6. 里程碑判据(反剧场尺子)

- **M1**:首个外部复算请求到达(免费也算)→ 开口已递,观察 2 周
- **M2**:首个"愿意付费"表达(可不成交)→ 上线 $99 档试报价与落地页一页纸
- **M3**:首笔付费成交 → 才启动 API 化讨论
- M1 之前:不建付费基建、不定价页、不做营销投入——只有开口与值守

### C7. 红线(不可让步)

1. **结论两向如实**:agree/disagree 同等醒目发布;营销不得干预复算结论——
   这是招牌,拦下自己人的假绿同款纪律对外适用
2. **不验自己卖的**:审计服务与被审对象隔离;不接"审计贵司产品"里与我们
   竞品重叠且我们自售的品类(企业记忆线)的单
3. **license 口径待用户确认**:Modified MIT 的"托管 100 付费用户上限"(9/4 拍板)
   针对记忆托管 SaaS;验证服务是否独立口径,请用户明示后记入 LICENSE 附件
4. 免费复算的排队与时效如实披露(回复里已写"manual pipeline")
