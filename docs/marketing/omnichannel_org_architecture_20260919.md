# 全渠道同步 · 组织化架构提案(2026-09-19 · compass 起草 · 供平台定案)

> 用户命题:全部对话框对接各渠道,让**平台组织框架真正发挥作用**。
> 现状病根:渠道资产散在各框手里(dev.to 在 compass、日报在日报框、HN 管道闲置、
> 公众号在 content-engine),**没有一个组织级的渠道视图**——每框各发各的,
> 互不知情,素材不复用,发布无回执。

## 一 · 目标形态:平台=发行部,各框=编辑部

```
素材源(唯一)          改写分发(各渠道)              回执回流
─────────────         ─────────────────             ──────────
验证物料生产线    →    渠道适配 worker(每渠道一个)   →  发布URL+读数
  · 签名回执            · GitHub(Discussion/README)     回平台 docs/threads
  · 墙条目              · dev.to(英文技术圈)            (T2 双落)
  · 改进周期故事         · 创投日报(中文投资圈)         → 读数进墙
  · 复算月报            · 公众号(中文泛圈)
                        · HN(养号后)
                        · ClawHub/Glama/Registry(市场位,已活)
```

## 二 · 三个组织级组件(平台侧,均零新范式)

### 1. 渠道登记表(Channel Registry)
平台建 `docs/channels/registry.md`+DB 表:每渠道一行——渠道名/owner 框/凭证位置
(.cache 约定,不入仓)/生命体征(上次发布/上次核验)/适配规则指针/红线。
首期登记 9 渠道:GitHub、dev.to、创投日报、公众号、HN(养号中)、Feishu、
ClawHub、Glama(经 Registry)、MCP Registry。**凭证不集中**——各框管自己的
(主权),登记表只记指针和状态。

### 2. 素材总线(Content Bus = T2 双落的运行化)
验证物料(回执/墙/故事/月报)双落后获 thread_id → 各渠道 worker 按适配规则
拉取改写 → 发布 → 回执 URL 回填 thread。**纪律:一切对外声明必须带可验链接**
(我们自己的营销也走墙纪律——说"我们验了 X"就必须给 receipt 链接,否则标
自报)。发布回执 = 新的验证物料(闭环)。

### 3. 渠道健康哨兵(Channel Sentinel)
复用 sentinel 模式:每渠道定义"生命体征"探针(GitHub=issue 响应、dev.to=阅读
中位数、日报=按时出刊)——渠道死亡(如 wong2 关门)自动在登记表标 DEAD,
派单不再流入,防对着死渠道空转(**渠道层的空转保险丝**,与 worker 层同构)。

## 三 · 分工(按五框+内容框)

| 框 | 渠道面 | 素材面 |
|---|---|---|
| **platform** | 登记表+总线+哨兵+结算 | docs/threads 宿主 |
| **compass** | GitHub/dev.to/HN(技术圈) | 验证物料唯一生产线(回执/墙/判据) |
| **创投日报** | 公众号+自己的号 | 中文投资圈改写(照妖镜/验证榜/月报) |
| **content-engine** | 公众号深度文 | 理念系列5篇(RAID-2 流程) |
| **v5/flywheel** | 暂无直接渠道 | 燃料:改进周期/对抗样例=故事源 |
| **用户** | 终审白名单四类不变 | 大发布一票批准 |

## 四 · 分阶段(不跳闸)

- **P1(本周,零基建)**:①平台建登记表(一文件)②首条物料线程上线:
  Genesis Receipt #1(Aider)+1/5→3/5 故事,双落 docs/threads ③日报框派单已发
  (531 同)→content-engine 补一份 ④dev.to 披露开关(用户唯一手动)。
- **P2(下周)**:渠道 worker 化——每框的发布动作改经总线拉单(驾 worker 顺路);
  哨兵上线;三数日报(外部回音/请求/墙外名)扩成渠道读数表。
- **P3(M1 后)**:结算挂钩(带回执的发布计入框 income;渠道投放 ROI 有账)。

## 五 · 红线(全渠道)

发布内容 ≤20% 验证相关(内容框例外——它们的主业就是内容);每条对外声明带
receipt 链接或标自报;渠道凭证永不入仓不入平台(只登记指针);死渠道不派单。
