## 二、话语权抓手:把做法变成公共品

引领话语权不靠嗓门,靠**别人不得不用你的东西**。我们开放四件公共品:

1. **判分协议**(PROTOCOL.md):预注册锚 · 函数级冒烟 · 双口径强制 · Wilson CI ——任何人评测记忆系统都可引用
2. **复现成本锚点**:同题同判据对打 ≈$3.50 GPU 时,脚本开源 ——把"不可验证的自报"变成"一杯咖啡钱的重跑"
3. **负结果清单**:rerank 有害(−2pt)/ K=50 无增益 / LoRA 路线关闭 / abstention gate 拒收 ——预注册文化,否决自己也是产出
4. **成绩册口径本身**:双口径强制披露(75.4 / 81.6)——"把瑕疵报出来"成为差异化卖点

第二帖(paper2 判分卫生)是话语权主攻:**给全行业递镜子**,不点名踩任何人;
竞品的分数我们只说"口径不同不可比",标准答案见 launch_plan §6。
