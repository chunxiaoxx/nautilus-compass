**标题:【开源自荐】nautilus-compass:给 AI Agent 装上会传承、可验证的集体记忆**

**正文:**

项目地址:https://github.com/chunxiaoxx/nautilus-compass

一个人写了 130 天的开源 agent 记忆层(Modified MIT)。它想解决的问题比「记住」再往前一步:**agent 团队的集体记忆,怎么可信地传承**。

架构 bet:写入时不调 LLM。会话原文 + 本地 BGE-m3,零抽取、零上云,记忆写入零 token 成本;智能全在读取侧——按问题类型路由检索单元(单会话问题只取 turn 级小块,不塞整个会话)。LongMemEval-S 全 500 题:检索 P@1 0.890 vs mem0 2.0.19 的 0.774(同题同判据,evidence 文件+复现脚本在仓库,复跑约 $3.50)。

三个别的记忆层没有的东西:

**一、记忆有治理。** 每条记忆写入时标注来源等级(measured / inferred / heard),查重门(BGE 三档:≥0.9 合并 / 灰区 / unique),条目间的 [[引用]] 沿链带出——记忆不是越多越好,是越可信越好。

**二、组织记忆。** 我家四个 AI 工作框(写代码 / 跑评测 / 管平台 / 做数据)共用这一个记忆库:项目级隔离、跨框可引用。agent A 踩过的坑封装成「记忆胶囊」,agent B 接手同任务直接绕开——有 B 从 FAIL 到 PASS 的实录。AI 团队的 onboarding,不再从零开始。

**三、跑分即证据包。** 对外公布的每个数字 = sha256 清单 + 字节可复算 + ed25519 签名,clone 后两条命令可验,不需要信任作者;不可复算的数字一律不进包、只做披露(判官网关静默故障把 14.2% 的题记成「答错」——这种事故我们抓过五次,全部写进协议文档)。

想象空间:当每个 agent 都带着可信的集体记忆工作,「组织」的边界就从人类扩展到人机混合体。智能 = 压缩 + 验证——压缩各家都在做,我们把验证那半,做成了基础设施。

Claude Code / Cursor / Cline 等一键接入(MCP),也有托管自助版。欢迎来验数字:推翻我们的结果,同样上墙。
