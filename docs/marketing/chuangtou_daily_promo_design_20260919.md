# 创投日报 × Nautilus Assay 宣发设计(2026-09-19 · 持续化方案)

> 原则:日报是读者的资产,不是我们的广告位。宣发=给日报加一个**别人做不了的
> 独家栏目**,而不是塞软文。读者是投资人/创业者——所有文案面向**买方视角**
> ("你投的公司数字是真的吗"),不是开发者视角。

## 一 · 核心创新:三个别人没有的栏目

### 1.「AI 数字照妖镜」(每期固定小栏目,3-5 行)
日报日常报道里出现 AI 声明(某公司"准确率 99%"、某产品"效率提升 3 倍")时,
编辑部加一行标注:**【自报数字,无第三方验证】**——就像广告必须标"广告"。
- 这是我们理念(默认态反转)的**媒体层落地**:日报自己先实践"AI 数字分两种"
- 零成本、可持续、天然引发读者好奇("什么是第三方验证?")
- 立场安全:不评判真假,只标验证状态——中立是生命线

### 2.「本周验证榜」(每周一期,占日报一个板块)
从我们墙上的复算活动自动生成:本周验了谁、结果三态(可复算/不可复算/无法判定)、
签名回执链接。素材源=我们的 wall + 创世十家 campaign——**墙就是内容 IP**。
- 独家性:全球没有第二个号能出这个栏目(数据长在我们的管线上)
- 自动化:墙数据 JSON 化后,此栏目可程序化生成(接日报现有 pipeline)

### 3.「月度信任报告」(每月一篇,原创数据报告)
"本月我们复算了 N 个公开发布的 AI 声明:X% 可复算,Y% 无法验证"——
**这是行业会引用的原创数据**,像 PitchBook 出行业报告一样立品牌。每月一篇,
数据从 verdict 语料自动聚合。

## 二 · 理念传播系列(每周/双周一篇深度,用创投圈语言)

已写成一半的框架直接翻译,标题即钩子:
1. 《AI 时代的柠檬市场:当所有数字都是自己报的》(Akerlof→AI 跑分)
2. 《你看的 AI 跑分,一个都别信——除非它带签名》(HTTPS 类比+试金局)
3. 《我们给自己的 AI 组织办了场考试:第一次只对了 1/5》(1/5→3/5 完整故事,
   创投圈最爱听方法论可信度,这个故事天然带反转和签名实证)
4. 《为什么说"验证"是 agent 经济的下一次基础设施机会》(Coase 交易费用坍缩)
5. 《EU AI Act 已生效:你投的 AI 公司准备好"可验证"了吗》(合规钩子,募资场景)

节奏纪律:**验证相关内容 ≤ 每期 20% 篇幅**——日报主业务(创投情报)不动,
读者无感损失,品牌有增益。

## 三 · 固定尾签(每期一行,不动)

> 「AI 数字分两种:带签名可验的,和自报的。试金局(Nautilus Assay)本周复算
> N 个声明 → [墙链接] | 开发者?pip install assay-verify」

## 四 · 自动化接线(接日报现有 pipeline)

1. 我方墙出只读 JSON(条目:被测方/声明/三态/日期/回执链接)——一次性接口;
2. 日报 pipeline 拉该 JSON → 「本周验证榜」板块自动渲染;
3. 照妖镜标注=日报编辑规则一条(prompt 层加一条规则即可),无需新工具;
4. 月度报告=verdict 语料聚合脚本(我方出数,日报出文)。

## 五 · 度量与红线

- 看三个数:验证栏目带来的公众号打开率差/墙链接点击/后台"复算"咨询数;
- 红线:不点评未复算的具体公司(照妖镜只标状态不定性);不吹自家未验数字;
  日报读者关系 > 短期引流——杀鸡取卵的软文一篇都不发。
