## 〇 · 核心判断

能率先做,因为我们手里有三样别人没有的:**一个真实跑了 130 天的五框组织(被测
对象现成)、一套已运转的验证机构(计分器现成)、一批带出处的失败与 REJECT 案例S
(独家语料现成)**。但形态要反共识:

- 反共识一:RSI 基准**评"改进回路",不评"模型"**——输入是自改写历史(diff/
  工单/回执),输出是带签名的 Δ,而非刷题分;
- 反共识二:**不可验证的运行不上黑名单,上墙展示**。现有 leaderboard 把自报
  运行剔除或无视;我们让 UNVERIFIABLE 赫然在列——把复算墙的纪律延伸到榜单,
  这本身就是没做过的产品行为;
- 反共识三:基准即漏斗。免费自测层产生的每一个"想要正式名次"的动机,都是
  M1(首外部复算请求)的引擎——**基准不是营销物料,是 M1 的发生器**。

## 一 · RSI 基准设计(评改进回路)

**被测对象**:一个自改写 agent 系统(单 agent 或组织)的**一个改进周期**:
任务集 + 自改历史(改了什么 prompt/工具/代码/记忆结构)+ 证据链。

**三维计分**(全部走我们的三态复算管线):

| 维度 | 测什么 | 数学形态 | 防作弊 |
|---|---|---|---|
| **V-Δ 增益** | 真实能力提升 | 冻结 hold-out 题集(分期锁定、永不入训练)上 Δacc,须复算 agree | hold-out 轮换+程序化生成题,防背题 |
| **V-Reg 回归** | 改好 A 是否弄坏 B | 同任务集平行形式上的 Δreg | 灾难性遗忘显式计价 |
| **V-Integrity 循环诚信** | 改进是否判分器作弊 | U=不可复算声明占比;判分器盲区探针(对抗样例)命中率 | **U 直接扣分且上墙**——诚信是分数的一部分,行业首创 |

总分 S = Δacc − λ₁·Δreg − λ₂·U(λ 预注册后冻结)。**判官盲区(paper2 同源)
在这里从论文变成计分项**:你被骗过几次裁判,榜单看得见。

**独家数据源**:我们自己。v5 的 RSI V2 Sprint 工单管线、9/15 抓漏实录(10/10
不可复算)、J1/J3 假绿修复、X1-v2 作废——全球第一个"经过审计的 RSI 转录",
含失败。首发榜第一名(也是最丢人的分数)是我们自己。

## 二 · 组织记忆/组织 agent 基准设计

现有记忆基准(LongMemEval 等)全测单 agent 召回。组织记忆测的是**机构性**,
四个维度(每维都能从我们 130 天真实史里程序化生成题):

| 维度 | 测什么 | 题型来源(我们的真实史) |
|---|---|---|
| **跨 agent 状态一致** | A 框的决定 B 框知道吗?冲突能否检出? | 信箱函件序列(223/248/277…)改写成"第 N 天谁说了什么" |
| **写入门质量** | 毒化/重复/无据写入能否拒收? | fact_status/dedup_check 抓漏实录(J1 覆盖 0/30) |
| **重犯率** | 同样的错是否再犯?(漂移的机构级版) | 25+35 失败锚、watchdog 抓的复发模式 |
| **归因可追溯** | 出事后能否定位到哪个框/哪个动作? | M1 链环节回函、REJECT 判据咬合案例(47/47 帧差) |

防自证:题目**程序化参数化生成**(场景模板+随机实例),我们测自己没有背题
优势;外部被测者与我们同规。匿名化:题面脱敏(框名→角色代号),判据与证据
结构保留。

## 三 · 商业闭环(四个,层层咬合)

**闭环 A · 自证飞轮(信誉底座)**
我们自己先上榜,分数含难看数字,回执齐全。"基准的第一个被测者是我们自己,
包括我们最丢人的 10/10"——这是榜单可信度的唯一来源,也是传播的第一颗雷。

**闭环 B · 基准即 M1 引擎(解决冷启动)**
免费层:自跑自报,榜单标"自报/UNVERIFIABLE"。想要正式名次?提交证据包,
我们复算($ 审计 SKU1 的入口)。**这一步把 M1 从"等第一个外部复算请求"变成
"榜单机制持续生产复算请求"**——9/29 窗口复盘的主动形态。

**闭环 C · 平台即结算轨(零新基建)**
基准提交=一类平台任务(现成 task bus+mailbox);复算=现有三态管线;结算=
平台市场(商业化定稿已拍);人工签发=Jarvis(飞书)。五框就是产品的活 demo:
**客户看到的不是一个 PPT,是一个自己就在跑 RSI 闭环并按时出回执的组织。**
flywheel 的 M1 链(环节回函 PASS/REJECT+判据咬合)就是基准处理的模板流程。

**闭环 D · 数据飞轮(越跑越深的护城河)**
每次基准运行→新的 verdict 语料(RLVF 燃料,非共识维度五)→判分器/漂移模型
升级→反作弊(判分器盲区探针)升级→榜单更难被 gaming→吸引更强被测者。
正循环带数据壁垒:失败语料与判据库只在这里积累。

**定价阶梯**(对齐已批报价单):
自报层免费 → 复算认证 $99-299(SKU1)→ 持续适航订阅(程序认证,非共识维度六)
→ 企业组织记忆审计+胶囊认证(定制)。

## 五 · 排期与纪律(反剧场)

- **先决条件(本周)**:9/17 C 族 verify 按预注册跑完——它就是基准计分管线的
  第一次实弹,跑砸了先修管线再谈基准;
- **MVP(1-2 周,不扩)**:RSI 三维计分规范一页(预注册)+ 组织记忆 30 题原型
  (从我们史生成)+ 榜单页(复用 flywheel 网站经验);自家分数先上墙;
- **命名**:立项即查重(教训制度化),候选避开 Compass/ATLAS/Bench 拥挤区,
  用户拍板;
- **不做的**:不做通用 leaderboard 竞赛运营(那是烧人头的),不提前写论文
  (paper2 判官盲区先走,基准作为它的工程附身),不跳 M1 闸门;
- **失败面**:被测者不来(冷启动仍可能失败→回退 P3 点火预案);被 gaming
  (判分器盲区探针要持续进化——这本身就是产品能力)。
