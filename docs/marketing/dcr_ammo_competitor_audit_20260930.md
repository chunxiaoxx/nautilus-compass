## 弹药 A · "The proof link that isn't there"(主力 · TypeSafe)

**事实**(typesafe.ai 首页 2026-09-30 实抓+HTML 直检):
- Headline:"193.6x Faster, 444.6x Cheaper *based on workflows for System One tasks (proof)*"
- "(proof)" 是纯文字——**无链接目标**(HTML 里 grep 不到任何 proof/benchmark/eval href;typesafe.ai/pricing 404)
- 同页 demo 数字复算:$0.013880 / $0.000081 = **171x**;8.566s / 0.114s = **75x**——撑不起 headline 的 193.6x/444.6x
- 可反算锚点(自洽):$42/B input tokens × 238x = $10/M ≈ Claude Fable 5.1 输入价 ✅

**对外叙事**(英文草稿):
> We tried to click the "(proof)". It's not a link. The same page's own demo numbers
> compute to 171x cost / 75x speed — not the advertised 193.6x / 444.6x.
> Maybe both are true for different comparisons. That's exactly the problem:
> you can't tell, because the methodology page doesn't exist.
> Calibration claims need receipts. That's what a reproducible verification report is.

**定位**:calibration-claim-verify-v1 第一活靶战果——核验动作本身就是市场动作。
