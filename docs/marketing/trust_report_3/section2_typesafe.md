# §2 TypeSafe 四轮复算:一个 "(proof)" 的解剖

> Trust Report #3 第二节。所有发现来自 typesafe.ai 公开页面直抓(2026-09-26/30 两轮,HTML 直检),方法=calibration-claim-verify 流程;对外文本不指名(称 "an AI lab"),本报告仓内版保留坐标。

## 事情从一个点击开始

首页宣称 "193.6x Faster, 444.6x Cheaper — based on workflows for System One tasks **(proof)**"。"有 proof"——那我们点它。

**第一轮发现:点不开。** "(proof)" 是样式文本,不是链接:HTML 直检无 href,站内无 /benchmarks、无 methodology 页,/pricing 404。这不是我们抢先下结论——**是不可验证本身成为发现**。

**第二轮发现:同一页有两套数。** 页内 demo 微件可复算:$0.013880 → $0.000081 = **171x**,8.566s → 0.114s = **75x**。都是好数字——都不是 headline 的 444.6x/193.6x。同页双口径,无披露。

**第三轮发现:有一个声明是可验的。** "$42 per billion input tokens, 238x cheaper than [frontier model]"——42 × 238 ≈ $10/M,与公开牌价吻合。算术自洽。

**第四轮(结论):不是欺诈,是不可验证。** 两组倍数可能各自真实——对照集不同、口径不同、方法学不公开。买方无法在购买前复算任何一个 headline 数字。我们的定性:unverifiable(不可验证),不是 false(虚假)。

## 我们做了什么(动作留痕)

1. X 长文公开分析(2026-10-01,status/2105296550117458093)——只述事实,全部可溯源,不指名不推断动机
2. 邮件回应权(hello@typesafe.ai,官网一手邮箱):公开分析知会+完整回应邀请——**他们若有 methodology 文档,我们以同等可见度更正**
3. 免费独立复算 offer:判据冻结+全工件归档+失败样本逐条公开+报告共署+90 天挑战窗

## 这个案例对外说明什么

- **倍数的分母是商业决策,不是技术常数**。444.6x 对谁?哪个模型?什么任务分布?买得越贵,倍数越好看——"倍数-对照曲线"才是信息,单个倍数是营销
- **品类缺位**:整个 agent-memory/决策模型层(mem0/Zep/Letta 亦然,§4 详)运行在自报数字上。有资本、有叙事、有治理口号——没有一个可独立复算的数
- **验证机构的姿势**:先给回应权再公开(我们反过来了:公开后 24h 内补函回应权——次序教训已记),只述可复算事实,方法全公开
