## 〇 · 一句话总判断

**冻结权重的时代,护城河是数据+评测;动态权重的时代,护城河是验证机构——因为权重
会流走,信任必须活在权重之外。** compass 不是在建一个功能,是在建让 agent 自我改进
"可问责"的那套机构(判据库·复算·签名回执·复算墙)。Ilya 的动态模型论不是给我们
指了条新路,是把我们已经在修的路变成了主干道。

## 一 · RSI 噪音里的结构性事实(去噪后只剩三条)

各家框架(量子位 MetaRSI/奇绩四阶段/学界 L1-L4/alphaXiv 五环节)说法不同,结构
完全收敛:

1. **循环内核同一**:反馈→改动→验证→回流。所有玩家卡在同一段——**验证**。
2. **验证是唯一公认仍需人类的环节**(奇绩阶段 3 原话:评测、可靠性和方向判断仍需
   较强人类参与)。谁的"仍需人类"份额可以被工程化吃掉,谁就拿着阶段 3 的门票。
3. **自评不可信是被反复踩的坑**:judge 无声错标(我们实测 14.2%)、生产者自置标志
   (9/15 试点 10/10)、判定器系统性偏差(X1-v2 47/47)。RSI 越热,这个坑被踩得越狠
   ——**RSI 的每一次头条,都是在给第三方验证业务做需求教育**。

## 二 · 动态模型论为什么让 compass 升值(而不是边缘化)

表面看:模型天天换新,记忆层/验证层会不会被底座顺带做了?

反过来读。权重静态时,信任可以住在权重里(这家模型准,我信这家)。权重动态化
(持续学习/端到端自进化)之后:

- 权重本身不再有稳定身份,**"它现在到底会什么/记着什么/改好了没有"变成外部问题**;
- 自我改进的每一步都要回答"这次改动是真变好还是判分器被骗了"——这正是我们把
  14.2% 判官错标、10/10 不可复算做成机制化防线的同一个问题;
- 于是 value function 需要外部真值供给(8/22 记忆原判断),且需求随动态化程度
  **线性放大**。SSI 首模型已出,各家动态化只是时间问题。

结论:**动态模型时代,记忆层是"状态的外置",验证层是"信任的外置"。前者我们已有
实物,后者我们独有机构。两者绑定的产品形态=带签名的状态(记忆胶囊×证据包)。**

## 三 · 涡轮飞轮的真相:排气就是燃料(用户命题的核心修正)

"SFT+RL 涡轮增压飞轮"方向对,但要修正一处:**飞轮不需要新引擎,它需要认出自己
的尾气已经是 Premium 燃料。**

盘点我们每天在产什么:预注册判据→复算→三态裁决→签名回执→判据入库→disagree
留档上墙。每一条裁决都是天然的高质量监督样本:

- **输入**:claim+上下文+证据哈希(可复算,非叙述);
- **标签**:agree/disagree/not_computable(由字节级复算产生,不是谁拍脑袋);
- **出处**:ed25519 签名+sha256 锚定——这是 scraped 数据永远给不了的东西。

这就是 SFT(模仿裁决)→RL(奖励=与复算真值一致)的标准数据形态。飞轮每多转一天,
训练集自己长大一天,**边际成本为零**——我们唯一要做的是把"verdict 语料导出"从
副产品变成设计品(见 §六)。

## 四 · 该训什么、不该训什么(带牙齿的"是")

**否决项(两条,有前案):**

- ❌ 自训通用/助手/写侧抽取模型——抽取路线我们亲手证伪过(0.774 vs 0.890,
  写侧零 LLM 是立身设计),通用模型是底座厂商的牌桌;
- ❌ 阶段 4(端到端训练下一代)——我们不是 stage-4 玩家,是 stage-3 的瓶颈供应商。
  蒸馏线 9/2 已关,不回头。

**候选(按 ROI 排,全部挂预注册门,门不过即关):**

1. **判分器/漂移小模型(0.5B-3B)**:漂移检测现为"嵌入相似+手工启发",AUC 0.83;
   用 verdict 语料 SFT+RL 一个小判分器,门=AUC on hold-out≥0.87 且误报率不升,
   成本帽≈¥500 GPU(4090 夜租)。与 d13 失败案的区别:d13 是拿 LoRA 改检索行为,
   这次是拿**我们自己的裁决语料**训裁决任务——数据我们独有。
2. **查询路由器(最小)**:题型路由已有实证红利(turn-level 单型 0.20→1.00),
   用 500 题 harness+真实查询日志训一个毫秒级小分类器。便宜、可测、风险低。
3. **red-team 判据生成器(远期)**:读工单/失败面自动起草复验判据草案,人审定后
   入 CATALOG——把阶段 3"AI 加速评测"做成产品功能。

**🔴 反自指护栏(必须写死,否则我们变成自己反对的东西):**

RL 奖励只准锚定**字节级复算真值**,不准锚定自家判分器的历史标签;训出的判分器的
评测必须走 hold-out+预注册判据(棘轮),且它永远只做**预筛**,终裁权在复算管线+
人类。否则"用自己喂出来的裁判给自己打分"= anchor-pool-selection-bias 的训练版,
自报之罪换了个马甲。

## 七 · 对立面(四条真质疑,自问自答)

1. **"自训模型=烧钱+被底座碾压"**——成立,所以只训数据我们独有、任务稳定、
   门可判的小模型;通用能力永远用 API。
2. **"裁判用自己喂的数据=循环论证"**——成立,所以 §四的反自指护栏是硬门:
   奖励只锚复算真值,评测走 hold-out;这条线破了,整个故事归零。
3. **"RSI 可能是狂热期泡沫"(陆奇四段论:爆发/狂热/协同/成熟)**——可能,但我们
   卖的是回执不是氛围:泡沫期卖铲子(审计),退潮期剩证据(复算墙),两头都有位置。
4. **"胶囊可携带会拆自己托管的台"**——张力真实存在。解法:胶囊定位为**审计
   制品**(证据包),不是搬运产品;托管便捷性照卖,可审计性是差异化,不是对价。
