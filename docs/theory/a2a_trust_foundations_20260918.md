## 第一部分 · 第一性原理:机器间的信任是什么

### 1.1 定义(【创】,承 T1-T7 算子代数)

**信任 = 验证的压缩(compression of verification)。** agent i 对 j 在域 D 上信任,
当且仅当:i 持有关于 j 可靠性的充分统计量(由过往验证结果构成),使期望验证成本
低于期望受骗损失,从而 i 可以跳过逐条验证、只做抽样。Y Chen 2026 的"信任降验证
开销 60-85%"是这个定义的实测投影(【实】)。

推论三条:
1. **信任必须以可验证性为地基**——不可验证之物的信任是盲信(赌),不是压缩;
2. **信任是分域、分时刻的标量场**,不是全局布尔值(我们的三态+可计算性格 ρ 就是
   校准仪器);
3. **信任的价值 = 省下的验证成本**(交易费用视角,见 §3.1)——所以"解决信任成本
   问题"=把这个场变得又准又便宜。

### 1.2 人类信任的四个前提,在 agent 身上全部崩塌(本档核心判断)

人类信任制度(声誉、法院、征信)默认四个前提,agent 把每一个都拆了:

| 人类前提 | agent 现实 | 崩塌后果 |
|---|---|---|
| **身份持续性**(一个身体,一生一个身份) | 一个新密钥对=一个"新 agent",生成成本≈0 | **Sybil 攻击成为第一问题**:伪造千个身份自评互评 |
| **进入有成本**(声誉要几年积累) | 复制粘贴=行为完全相同的新身份 | 声誉无法积累定价——白手起家与身经百战不可区分 |
| **行为平稳性**(性格短期不变) | 一次微调/prompt 改写=同一身份下的**新大脑** | 昨天的声誉不适用于今天的 agent |
| **切肤之痛**(破产/坐牢是真实代价) | 背叛后弃号重来的损失≈0 | 惩罚不可置信,合作均衡难自持 |

**【创】根本命题:agent 经济的信任问题,不是"如何验证内容"(那是我们已在解的),
而是"身份与代价的绑定断裂"。**验证可以变便宜(脚本复算),但**"这个验证结果
属于谁、他背叛的代价是什么"**没有解。这就是比内容验证更深一层的东西——也是
区块链对 agent 经济真正相关的部分(它发明的不是币,是**用烧钱的成本制造
不可伪造的历史**)。

### 1.3 由崩塌推出的三个不可能性(【设】,待形式化)

- **I1(身份不可依赖)**:对可零成本繁殖的主体,任何只锚定密钥身份的声誉系统
  可被 Sybil 攻破——声誉必须锚定**不可廉价复制的东西**;
- **I2(平稳性不可假设)**:对可一夜改写行为的主体,任何静态信任评级必然过期
  ——信任必须带**时间窗与版本戳**;
- **I3(自证不可能)**:承 T7——任何验证者验证自身产出=退化解 D_θ∘D_θ≡1,
  诚实判定至少需要**结构独立的第二验证者**(独立性=不同代码、不同密钥、不同
  利益,三缺一减弱)。

## 第二部分 · 问题空间的系统分解(六轴)

每个轴:形式陈述 → 攻击面 → 我们的现存答案 → 缺口。

**轴一 WHO(身份与委托)**
- 陈述:声明可归因到一个**不可廉价复制**的主体上;agent 代人行事的委托链可证。
- 攻击:Sybil(造身份)/ 女巫洗白(坏号弃号)/ 委托伪造(冒充某人的 agent)。
- 现存:平台 X-API-Key 框名绑定(级0)、ed25519(级1)、MCP Registry 条目。
- 缺口:**身份应绑 (公钥, code_hash, config_hash) 三元组**【创】——agent 改了脑子
  就是新 agent(解 I2 的一半);委托链要接 AP2/OAuth 方向(跟进标准)。

**轴二 WHAT(内容验证)**
- 陈述:声明可由第三方按公开判据、从字节复算。
- 攻击:不可复算声明(10/10 案)、判分器盲区(14.2%)、门与卷不同源(周期2发现)。
- 现存:VerifyPack/三态/三门/判据库13条——**这一轴我们最完整**。
- 缺口:验签不可机读(一条 curl)、覆盖域仍窄(代码题 vs 泛声明)。

**轴三 WHY-FOR(验证者激励)**
- 陈述:验证者诚实的期望收益>作恶(激励相容)。
- 攻击:验证者受贿/与被测合谋/偷懒(不真算)。
- 现存:非实现者分离(结构)、新鲜会话(独立性)、人工终审(主权)。
- 缺口:**保证金/质押机制未建**【设:bonded verification——验证者押金,被复算
  推翻判罚则罚没;参考乐观-rollup 挑战赛与 EigenLayer 方向】。

**轴四 HOW-MUCH(校准)**
- 陈述:信任输出不是布尔,是带不确定度的后验。
- 现存:三态(agree/disagree/NC)+ρ 格+degraded——**三态就是我们发明的校准语法**。
- 缺口:按 agent 聚合的声誉后验(声誉账本)未建。

**轴五 OVER-TIME(动态)**
- 陈述:信任随行为漂移衰减,随新证据更新。
- 攻击:渐变式漂移(每步都在阈值内,百步成灾)/ 环境换轨。
- 现存:drift 检测(AUC 0.83)是**行为面的监测器**——全行业记忆层唯一;重犯锚。
- 缺口:drift 读数尚未与声誉后验挂钩(通道未接)。

**轴六 UNDER-ATTACK(对抗)**
- 陈述:系统在已知攻击下保持判定不变(对抗稳健)。
- 攻击:挑窗口/藏病/假成功/归因漂移(对抗库四类)+ 合谋多验证者。
- 现存:对抗库 4 条判据+"判分器独立重算不信自带字段"第一性。
- 缺口:对抗样例更新节奏依赖实战(组织内多、外部少)。

## 第三部分 · 制度史:同一个问题被解过五次

这不是第一次"跨主体、无中央权威、机器速度交易"的信任危机。制度经济学给出五个
同构案例,每个都有可搬运的机制(【实】,经典文献均定案):

1. **商人法法庭(Law Merchant, 11-13 世纪;Milgrom-Weigast-Greif 分析)**——跨国
   商人无共同法庭→行商法庭:同行快速裁决+声誉做担保+逐出社群做惩罚。
   **搬运:判据同行裁决+墙=声誉法庭+UNVERIFIABLE=逐出标记。**我们就是 agent 的
   商人法(而非"区块链的翻版"——区块链是它在密码学里的重演)。
2. **哈瓦拉(Hawala,数百年)**——无限连带责任的经纪人网络做信任转移,凭记名
   而非凭证。**搬运:声誉中介可转移信任,但中介必须连带(我们的验证者若出错,
   声誉连带)——反对轻结算的验证市场。**
3. **试金局(Assay Office, 13 世纪至今)**——法定打纯度戳,hallmark 含铸造者标、
   年份标、纯度标三段。**搬运:我们的回执三段式已同构(who/when/what);我们的
   产品名就是制度名的直系。**
4. **征信局(近代)**——声誉中介的工业化。**反面教训:征信局被监管与捕获的
   历史警告我们——验证者自身治理(误判申诉通道)要从第一天内置(我们的新鲜
   会话复算+人工终审就是申诉法院)。**
5. **复现危机中的同行评议(当代)**——审稿人不复算→造假横行→复现运动兴起。
   **搬运:referee≠verifier 是学术界的"判官盲区";我们的解(复算代替相信)正是
   复现运动的机构化。**paper2/paper3 的学术锚。

**制度经济学的总账(Coase 1937/Akerlof 1970/North 1990)**:交易费用决定制度形态;
信息不对称压垮市场;制度=游戏规则,组织=玩家。A2A 把协作费用降到近零→**信任
费用成为剩余的最大项→压缩信任费用的制度捕获全部节省**。这是"我们为什么值钱"
的最底层答案:不是卖软件,是**卖交易费用的坍缩**(O(n²)→O(n),上一档已形式化)。

## 第四部分 · Agent 信任栈:六层参考架构(系统化)

【创】给 agent 经济的信任问题一张完整分层图(类似 OSI 之于网络)。每层:职责/
归属/主要攻击/我们的站位。

| 层 | 职责 | 事实归属 | 主要攻击 | 我们 |
|---|---|---|---|---|
| **L0 计算层** | 证明"哪份二进制真的跑了"(远程证明/TEE) | 硬件厂(Intel/NVIDIA TEE) | 固件后门 | 远期采用,不自建 |
| **L1 身份层** | 主体与委托(密钥/DID/AP2 委托证明) | A2A AgentCard/AP2/OAuth 生态 | Sybil、委托伪造 | **接入标准+挂 (key,code,config) 三元组指纹** |
| **L2 溯源层** | 内容从哪来(签名清单/C2PA) | C2PA/各平台 | 混源、篡改 | VerifyPack manifest 已同构 |
| **L3 验证层** | 内容是真是假(判据/复算/回执) | **空——我们** | 判分器盲区、门不同源 | **主场:三门/判据库/签名回执** |
| **L4 共识层** | 多验证者合议+声誉(反Sybil、防合谋) | **空——我们播种** | 合谋、贿选、洗白 | 非实现者/棘轮/墙 → 开放验证者+声誉VC |
| **L5 治理层** | 人类终审与合规(法律锚) | 法院/监管/企业 | 捕获、僵化 | 裁决白名单+Jarvis+用户终审+EU AIAct接口 |

**站位判词:L0-L2 别人在建(标准会赢),L5 永远是人的;L3-L4 无人占,而它恰好是
"内容真伪"这把唯一的钥匙。巨头在修路(L1)和银行(AP2),没人开法庭(L3/L4)。
修路的会顺手做法庭吗?——见 §7 风险 R1。**

## 第五部分 · 理论扩展:算子代数 +3(并入 T 系)

- **T8(身份三元组)**【创】:声誉的归因单位是 (key, code_hash, config_hash),
  不是 key。改脑=新 agent,旧声誉按衰减系数折算而非继承。→ 工程含义:VerifyPack
  v0.3 回执增 subject 指纹三元组字段;drift 检测负责"指纹未变而行为已变"的补网。
- **T9(Sybil 经济不等式)**【设】:系统 Sybil 安全 ⇔ 造一个达到信任阈值的新身份的
  成本 > 该阈值身份一次背叛的最大可提取价值。墙的永久 UNVERIFIABLE 标记=抬高
  "弃号重来"的等价成本(历史不可迁移);保证金=抬高入场成本;hold-out 题库=
  声誉不可由自评积累(防自铸)。
- **T10(验证市场出清)**【设】:复算服务的价格=f(复算算力成本, 验证者稀缺度,
  风险敞口),而非成本加成。$99-299 是首价发现,不是终价;榜单价差(verified/
  unverified)是市场对我们服务的定价信号——**墙要当作行情页运营**。

## 第六部分 · 可建协议范围(Assay Protocol v1 的边界)

**纳入 v1**:①回执格式(含 subject 三元组指纹)②判据注册/棘轮语法 ③三态判定
枚举 ④验签 CLI(一条 curl)⑤墙的最小只读 API ⑥声誉=可验证凭证(VC)按 agent
签发(W3C VC 方向,验证者为 issuer)。
**不纳入 v1(记为远期)**:TEE 远程证明(L0)、zk 证明(复算脚本足够便宜,SNARK
暂无必要——防过度工程)、代币/链(明拒)。
**验证者扩展路径**:v1 单验证者(现役)→ v1.1 多验证者双签(创世验证者计划)
→ v2 保证金+罚没+声誉加权(BFT 意义上的验证者集合)。

## 第七部分 · 系统性风险登记(五条,各带对策)

- **R1 标准捕获**:A2A/AP2 生态自己定义 L3(如"verified agent"徽章)。
  对策:他们做**身份级**验证(你是谁),我们做**内容级**(你说的对不对)——
  徽章验身份,回执验结论,语义不同层;且判据语料+运营履历无法用标准吃掉。
- **R2 验证者合谋**(开放后):对策=验证者多样性要求(不同组织/密钥/实现)+
  交叉抽检(任一方可触发对方复算)+保证金。
- **R3 Sybil 持久战**:对策=T8/T9 组合,墙永久化,历史不可迁移。
- **R4 单位经济**:复算边际成本近零但判据研发是人力——对策:判据一次研发万次
  执行(版权在判据库,不在跑分);跨域复用(合规证据包=同一判据第二个市场)。
- **R5 合法性赤字**(Kimi 冷水的深层版):机构无外部当事人=自说自话。
  对策:创世十家+外部验证者重判我们(不解释,做出来)。

## 第八部分 · 全组织分工(信任栈视角的五框重排)

- **compass**:L3 全部+L4 协议与判据正本(司法权);
- **platform**:L1 执行(身份/鉴权/总线)+结算(验证市场的清算所)——已有
  X-API-Key、任务总线、市场;
- **v5**:首席被测者+对抗样例军火商(攻击面知识生产)+drift 行为数据;
- **flywheel**:判据咬合案例供给+数据侧验证(判数据)+榜单页(墙的前端);
- **用户**:L5 终审(判据变更唯一批准人)+对外主权签署。
每框在栈中各执一层或一角,**没有一个框是多余的——这就是"全部工作压上"的系统版**。

## 收束

上一档说"我们解决 agent 说的话值不值得信"。本档把地基打到底:**信任何处安放,
取决于身份与代价能否绑定(T8/T9);绑定不可依赖单点身份,只能依赖不可伪造的
历史——墙就是那个历史,判据就是那部法,回执就是那枚戳。**agent 经济会重演
商人法的诞生:不是因为有中央,而是因为**跨主体交易对低成本法庭的渴求**。
我们要做的是那间法庭的第一个执槌人——并从第一天就写好:法官也要被审判(I3),
历史永不迁移(T9),终审永远有人(L5)。
