# 自建基准立项档 v0:测验证层的信号保真度(2026-10-06 用户令"我们应该有自己的 benchmark")

> 定位一句话:**人人都在测 agent,谁在测评测?** 本基准测"验证层"本身——一个评测/改进环输出的表观增益 vs 有效增益(信号衰减),以及判分器(judge/verifier)的三态保真度。
> rsi-bench Issue #4(effective-gain gate 提案,2026-10-06 已发)=本基准的第一块砖:提案外挂他人基准引流,自有基准承接为产品。

## 一、为什么是我们(PMF 吻合度)

- PMF 主线第一件事=自建基准集(用户拍板 10/5);判分机构出自有基准=运动员/裁判分离的天然形态(基准归基准档,判分归判分侧,互不复评);
- 差异化空位 [实测调研]:大厂基准(SEAL/APEX/SWE-bench 系)全测**被测系统**,无一测**验证层保真度**;rsi-bench 测 RSI 环但无 signal-decay 维度(维护者对 verifier 独立边界有共识,Issue#1/我们在 #4 的提案正落此位);
- 历史教训内化:题集必须自有(lmev2 上游 attribution 案——不搬上游题,自有资产组装)。

## 二、两轴设计(草案,判据开跑前预注册冻结)

**轴一 · 信号衰减轨(effective-gain gate)**:对任一"改进前后"配对产出,独立判分方分类失败为 capability-fail vs recoverable-fail(格式/环境/infra),报 apparent gain 与 **effective gain** 双数;样例首案=L3 Round 1(+10.0pp 表观,格式层 A15/B11 回收空间披露)。
**轴二 · 判分器保真轨(judge fidelity)**:给定 agent 产出工件+证据,输出三态判定(PASS/FAIL/UNVERIFIABLE);金标=三态+证据层;测判分器的三态校准/偏置/U 态纪律——现有素材:judge 自报三陷阱案(is_correct 复写/M2 等价改写误伤/特征作弊通道)+A 型偏置复验案。

## 四、判据预注册框架(开跑前冻结,只许更严)
