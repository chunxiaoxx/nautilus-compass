## 结构(六段)

### 1. 钩子(开门 3 秒)
自家真事:我们给自己的 AI 组织出了场 30 题考试,首考 **11/18**;审计后 7 道错题
**全部判给出题方**——其中 2 题标准答案本身是错的,考生才是对的。
→ 一个验证机构的第一件事是验证自己(工件:BC1_LAUNCH + SELFTEST_SCORECARD_V2)。

### 2. 论点:信任瓶颈已从模型能力移到验证能力
- 动态模型时代:模型月月换,自报 benchmark 数字保质期以周计
  (素材:RSI 深度启示——动态模型时代护城河=验证机构,9/16 记忆)
- 组织记忆=agent 的复利资产,但记忆写入路径的失真没人系统测过
- 铁证三臂(同 LLM 只换记忆路径):直连 16/18 → 默认 mem0 **11/18** →
  mem0 关写入压缩 **18/18**——写入时语义压缩一项,丢 7 分
  (素材:三臂报告,失真解剖到字段级:结构化日志压缩成自然语言,
  丢掉的恰是机器可检字段,如表示「无回执凭证」的 null)

### 3. 协议化:验证不应该是机构,应该是协议(四个原语)
1. **三态判分**:PASS / FAIL / U,U(不可算)永不充正分——消灭「部分正确」
2. **判分器公开**:仓库里的公开文件,考生可自跑预判,可审我们的实现
3. **签名回执**:每份成绩单 ed25519 签名,结果不可篡改,外部可直验
4. **可挑战**:凭作答工件 90 天窗口正式挑战——判绩账是双向的,评委也会错

### 4. 证据链:把丑数字全部公开
- 11/18 → 逐题审计(7 FAIL 全归出题方)→ 修题重考 18/18 → 非实现者复算 GREEN
- 复算顺手抓出:成绩单 2 题 raw 分与申报分不符 → 勘误留档不删
- v2 首次签名也错过(公钥误当种子)→ 重签+留档
- (素材:RECOMPUTE_SELFTEST + wall 页全链)

### 5. 对立面与边界(真诚条款)
- 30 题量级说明不了全部问题;首版只含机器判分题型
- 分数只在题集语义内可比,不是通用 agent benchmark
- 独立性悖论:谁验证验证者?——答案不是更大的机构,是公开协议+可复算工件
  (信任从机构转移到协议;这也限制了作恶空间)

### 6. 结尾(CTA)
- 免费考一次(issue 报名)/ 复算入口开放(独立复算别人的成绩是我们卖的东西)
- 一句话:An exam hall that publishes its own grading errors is the product.
