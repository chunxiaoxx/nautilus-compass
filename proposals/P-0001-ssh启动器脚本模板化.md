# P-0001 · SSH 启动器脚本模板化

- 日期：2026-09-07
- 来源：9/6-9/7 跑批会话摩擦点（gpu-instance-batch-offload-recipe 记忆：js1 线常静默超时/半途断，关键动作须启动器脚本模式）
- 级别：L1
- 状态：draft

## 问题
远程编排现写内嵌命令/双 nohup 连写，ssh 超时会静默截断后续命令——实锤：9/7 晚 rB4 补跑时 ssh 超时导致 rB5 的 nohup 未执行，需二次补发才起跑。

## 方案
`scripts/launch_template.sh` 三步模板：①本地 Write 脚本→②scp→③远程 `nohup bash xx.sh` + `sleep 3` + ps 确认回显。禁 ssh 内嵌 heredoc（转义地狱），禁单条 ssh 里串多个后台动作。

## 验证
下次跑批编排操作（收官/新批次）改用模板，一次成功零补发，ps 确认输出完整。

## 预期收益
每次远程编排省 5-10 分钟调试；消除"命令没执行到"事故面（本周实发 1 次）。

## 风险与红线
低。模板仅含只读检查+显式启动命令，不含 kill/删除。
