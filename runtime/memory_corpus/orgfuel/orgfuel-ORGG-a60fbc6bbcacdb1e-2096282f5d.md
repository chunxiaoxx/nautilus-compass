## 五 · Loop 轮固定动作(每 30m,防跑偏核心)

1. **信箱**:check compass 新函→按 SLA 处置/ack
2. **每日三数**:外部回音数/免费复算请求数/墙外部条目数(与前轮比 Δ)
3. **死线表**核对(§一短期):到点即执行,不过点
4. **全框同步**(用户令):flywheel/core/v5 云 git log 近 30m+信箱他框动态→
   发现问题诊断处置
5. **drift_check**(compass MCP)+方向锚对照:偏离即纠
6. **剧场自检**:本轮若无事件无进展=一行报平安(不产件)
7. 有实质进展→简报函(新 trace);无→静默

> 7 天自动到期(cron 机制);到期前用户可续令。商业线/内环工时比每轮记录。
