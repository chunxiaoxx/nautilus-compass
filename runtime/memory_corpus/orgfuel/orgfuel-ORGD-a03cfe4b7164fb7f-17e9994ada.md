[## 四、防漂移与诚实条款] - 窗口内判分供给照常(组织内送判照收),但**不得以任何供给侧新资产充数**——本裁决只认外部需求信号;
- 裁决日输出:读数(0 或 >0,附明细)+两仪配比调整令,无论结果入判绩账;
- 本档本身接受复算:窗口内全部外部接触留痕(函号/评论号/邮件)。
