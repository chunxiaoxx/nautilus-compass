# 数据质量管理制度（v0）

> 2026-09-04 制定 · v0 初版（对照行业标准 YD/T 6771-2026"组织机制保障"框架；配套《采集 SOP v1》《个人信息处理规范》《数据完整性指标定义》）。

## 一、质量目标

交付的每一批数据集满足：可审计（每批可追溯至采集员、设备、场景与质检记录）、可复跑（按预冻结判据第三方可复验）、可结算（质量结论与结算直接挂钩）。

## 二、组织与职责

1. **生产与验证分离**：数据生产团队与质检/计量团队分设；验证业务独立计价，不与数据销量挂钩。
2. **质检独立汇报**：质检负责人对质量结论负责，不受交付进度压力干预；放行/退回由质检单方判定。
3. **计量岗**：维护 D/T/C/L 计量协议（多样性/可训性/一致性/合规四维加权），负责批次计量与结算依据出具。

## 三、关键机制

1. **判据预冻结**：验收口径在采集开始前与客户确认并冻结版本，生产中不得单方变更；变更须双方书面确认并升版本号。
2. **金样本抽检**：每批次随机抽取金样本（含预埋已知问题项）检验质检有效性；抽检记录随批次归档。
3. **双人复核**：抽检不合格批次由第二质检员复核后出具最终结论。
4. **不合格处置**：批次不合格→退回重采或报废，不得降级放行；退回重采的成本由内部承担，不转嫁采集员（采集员操作违规除外）。
5. **记录留存**：采集、质检、脱敏、计量、交付五类记录按批次归档，保存期与合同及合规要求一致。

## 四、度量与改进

1. 批次质量以 D/T/C/L 四维计量结果+完整性指标（见配套文件）双重出具。
2. 判据与阈值实行版本管理；每季度复盘判据偏差与误判案例，修订须走版本升级。
3. 客户投诉与复验争议由质检负责
