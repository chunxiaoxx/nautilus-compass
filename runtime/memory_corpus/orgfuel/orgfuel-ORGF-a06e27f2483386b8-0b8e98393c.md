# LOOP 值守轮检查单(每轮开头过一遍,2026-10-07 固化)

> loop 作战方案 v1 件 5 · 目标:零遗漏/零假绿/零空烧/零衰减

## 每轮固定序

1. **信箱巡检**:_mailbox_check.py;OPEN 函逐封处置+ack/done 双销+409 双确认;同函重触发查 done 闸幂等跳过
2. **呈批台账巡检**(PENDING_DECISIONS.md):>24h 未决件重推一次;新呈批件即时入账
3. **GPU 队列拉棒**(GPU_JOBS_QUEUE.md):GPU 闲>30min 必拉下一棒;发车过三道闸(进程查重/清单在位/df 余量);跑完回写完成行
4. **挂账三件推进**(上轮留痕"挂账"节):逐件动或明示不可为
5. **外部触达 ≥1 动作**(常设纪律 10/5):写了没发=假绿
6. **两外壳滞后检测**:python scripts/_twoshells_lag_check.py(LAG=发函提醒 core 重渲,渲染器 _render_twoshells.py 就绪)
7. **留痕+loop-diff**:loop_night_R{N}_日期.md+一行进展函投 platform

## 纪律速查

- 执行权自治(可逆/低成本/不外发直接做+留痕);独裁权四类(对外发送/花钱/判据红线/不可逆删除)必须弹窗
- 发车三道闸;跨框先读本机 memory 再发函;数字一律引正本表;预注册 lock 前不出数
- 假绿三治:发函 409 双确认/落仓必 commit/收件人用白名单正名
- 产出到眼前:完成件必有 URL/飞书/图之一;git 里等审=没做
