## 合作框架(有条件开放)

**1. 现金赞助 + 展示位**
- 形式:README Sponsors 区中性列表(logo+一行描述+链接),不使用"官方合作/推荐供应商"等背书性表述
- 周期:首期 3 个月(季度续),价格请贵司按此规格报价

**2. API 使用资源(我们更看重这项的工程价值)**
- 我们的评测与判分业务需要多模型供给,接受额度赞助
- **顺序条款**:额度到位后我们先做 30 天实测(延迟/响应一致性/稳定性),实测数据作为集成教程的事实基础——若数据不佳,教程不发布,该项合作终止且不退不换、如实告知

**3. 配置教程/集成示例共建**
- 可做,以实测数据为底,并随附独立性声明(见下)

**4. 独立性条款(接受后合作生效)**
- Assay 的评测对象覆盖各模型供应商及 API 服务方,评测结论与赞助关系完全隔离,包括可能发布对贵司服务不利的实测数据,贵司确认知悉且不以此为合作撤回条件
- 赞助展示不构成对贵司服务质量、合规性、资金安全的任何担保,README 将注明"展示不代表推荐"
