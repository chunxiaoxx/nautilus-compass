## 4. 复利闭环
专家任务 → copilot+工具栈 → 交付 → soul QC + **专家复核** → (verdict+理由) → PoI 信用 + 胶囊 → 检索重排 + 工具改善 → 下次更快更准 → 专家更省时 → 更多任务/更高通过率。
