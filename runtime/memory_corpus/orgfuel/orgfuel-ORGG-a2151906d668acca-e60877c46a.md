## 三、竞争优势(为什么是我们)

1. **可复算是产品而非口号**:别家发"我们测了",我们发"你按这条命令重算,数对不上当天发勘误"——且已被实战验证(平台复现首例/v5 交叉 SQL/S6 全量 29/30)
2. **预注册纪律的护城河**:判据先行、零放宽,这要求组织级自我约束——竞争者模仿一句话,坚持一个季度极难
3. **负结果文化形成信用复利**:E-NACRE-1 负结果公开发布、6 例自勘误——"敢报坏消息"本身就是最稀有的可信信号
4. **判分器自检真空位**:caliber-bench(给基准打分的基准)全行业无同类;XERJ 证实语料库中"agent 轨迹+失败过程"数据为零——**两个真空位都被我们占住**
5. **成本结构**:1.7B 判官+自有复算管线,边际判读成本趋近于零——免费判读线可持续,收费线纯利
6. **数据飞轮已转**:每单判读→语料+1→判分器更强→判读更快更准——业务自喂养
