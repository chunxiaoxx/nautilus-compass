[### L3 燃料 QC(今日新层)] - 机制:燃料入库前自动跑 control 臂(裸模型 N 次),headroom<阈值 拒收/降级;与 A 类"弱模型难倒"判据统一成一条 pipeline(出题与经验共用 QC)。
- 指标:headroom 分布、Gold 率提升(目标 17%→40%+)。
- 闸门:先手动跑 v1/d2 两燃料的 control 预检,再自动化。
- 绞杀:无。
