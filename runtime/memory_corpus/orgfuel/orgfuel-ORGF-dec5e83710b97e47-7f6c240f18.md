# 采集员认证规范 v0

> 2026-09-04 · v0。与《采集员培训教材 v0》结业测试、《验收判据母版 v0》D 层质量分配套；平台（console_app）实现时按本规范。
> 数字纪律：累计时长与质量分阈值为 v0 暂定，首单后按实测分布校准；单价权益按平台公告，不在本规范写死。

## 一、认证通道（三级）

| 级别 | 认证条件 | 权益 |
|---|---|---|
| L1 认证采集员 | 培训教材结业测试 10 题全对 + 首条试验收通过 | 上岗领任务资格；设备免押借用 |
| L2 数据采集师 | 累计合格时长 ≥100 小时 + 近 30 天批次合格率 ≥90% + 零合规违规 | 高价值任务领取权；单价按平台公告上浮；设备升级优先 |
| L3 实训教官 | 带教新采集员 ≥10 人且被带教者结业 + 本人零违规记录 | 带教津贴；任务卡评审参与权；区域培训组织权 |

## 二、认证流程（平台自动化为主）

1. **L1**：H5 完成结业测试（自动判分）→ 上传首条试验收（自动验收）→ 双过自动升级，记录留档。
2. **L2**：平台按记账数据自动核算（合格时长/合格率/违规记录），达标自动升级并通知；争议人工复核（质检负责人）。
3. **L3**：带教关系在 H5 师徒绑定（教官邀请码）；被带教者结业自动计入教官带教数；人工年度复核一次。

## 三、降级与退出

- 连续 30 天无合格产出：L2/L3 保留级不降，活跃度标记（任务派发权重降低）。
- 合规违规（数据造假/涉密场所拍摄/未经同意拍摄他人）：一次即降 L1 并冻结派单，复查后视情节恢复或清退——**质量红线不设二次机会**。
- 设备损坏赔付未结清：暂停领任务，不影响已记账结算。
