判读档判例 RPT-G1-2407 · 4. 归因链(现象→层定位,每步给证据坐标)
## 4. 归因链(现象→层定位,每步给证据坐标)

```
P1(ratio 数千倍)
  → 数据层:ep0 存在静止段,‖act−state‖≈5e-5,幅度比分母近零
     证据:直读 parquet 双臂 ep0 前 8 帧逐帧核算 [实测](P3)
  → 判据层:J2 原判据对零增量帧无定义(任何 pred 都会爆表)
     证据:‖pred−state‖(~0.1-0.3 量级)÷ 5e-5 = 数千倍,纯算术后果 [实测]
  → dir 同理:点积 ≈0.1×5e-5×cos,符号几乎由 14 维随机夹角决定,8 帧全 1 不可区分于巧合 [推断]
链序定谳:数据构造(静止段)→ 判据灵敏度(零增量帧)→ 模型层无证据指向损伤
```

- 层定位:**数据层为主,判据层联动**;未归因到模型层。
- ep0 集中现象(P2)指向 ep0 数据本身或预热,材料侧归因需逐 ep 对照重跑,未做,如实标注不硬归因。
