2026-09-04 用户拍板 nautilus-compass 对外传播顺序:
① 先面向业界的技术架构 + 创新性解决方案(英文为主,求全球专业领域影响与广泛传播)
→ ② 中文版进中文圈
→ ③ 论文筹备(并行轨)
→ ④ 之后才面向市场需求
→ ⑤ 最后才是大众营销贴(禅心 AI/佛陀 agent 起源、量子纠缠等故事素材属最末层)。

**Why**:影响力从专业圈向下辐射(专业信任→市场→大众);先发故事营销会把产品定格成"故事"而非"基础设施"。

**How to apply**:对外材料按层归类投放,新素材先问"属于第几层";第一优先产出=英文架构立论长文;launch_post_v3(证据帖)只是第一层轻量件;"大胆自信"调门适用于各层,但第一层靠架构主张+证据,不靠故事。关联 [[paper-roadmap-history-20260904]] [[benchmark-naming-licensing-20260902]]。
