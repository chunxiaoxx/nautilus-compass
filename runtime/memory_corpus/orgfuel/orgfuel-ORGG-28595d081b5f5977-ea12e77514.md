判读档判例 MEMX_FUSION_20261009 · 一、四站闭环(MEMX loop)
## 一、四站闭环(MEMX loop)

```
[站1 压缩写入] session/判读卡/勘误 → dedup_check 三档(merge/gray/unique)
      → fact_status 标注 → 入记忆库(1500+ 条,棘轮)
        ↓
[站2 检索验证] recall → J4 门(三冻结查询)+ drift 锚(25正35负,AUC 0.83)
      + E1 held-out 抽检 + 命中归因日志(recall→行为→结局 追溯)
        ↓
[站3 因果倒置] 任一 FAIL/U态/漂移 → 三向归因算子(见 §二)
      → 产出:定向补写 / 记忆勘误 / 检索调优信号
        ↓
[站3→1 回流] 修正与新增条目 → dedup+fact_status → 再入库(棘轮+1)
        ↘ 旁路:验证过的高置信条目+判例 → 带签名 SFT/RL 燃料
[站4 注册升格] NACRE v1.x 训练(语料棘轮+REG-100 零翻转门+held-out)
      → 新判官 → 更强的站1 质检与站3 归因 → 飞轮转速+1
```
