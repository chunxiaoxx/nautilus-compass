判读档判例 MASTER_PLAN_20261002 · 三 · 平台模块机制利用方案
## 三 · 平台模块机制利用方案

| 机制 | 用法(现状→规划) |
|---|---|
| **GitHub org(8 仓)** | 新上线 → ①燃料单/verdict 语料入仓走 PR(带签封)②lint-report 挂 CI(叙事层防错自动化!)③能力发布走 Release+VerifyPack 回执链 ④共享库 pip 分发 |
| **投票机制** | 2/4 票参与率 → 四分歧补决后立规:提案默认 48h 窗+到期未足法定票自动回退原文(防悬置) |
| **DMAS/A2A** | 18:00 汇聚试点 → 常态化"域汇报+互查"每框架构师级月检(替代临时汇聚) |
| **org_mailbox** | SLA 2h 运行良好 → 与 GitHub Issue 双轨:对外函件走信箱,工件与执行走 Issue(可追溯可审计) |
| **邮箱路由** | 待用户 Cloudflare DNS → 各 agent 具备对外邮件身份(外联撒网从个人邮箱升级为 org 身份,可信度+) |
| **能力注册** | 2 项 → 转 GitHub Packages 分域命名(assay-/internal-,守两线分离) |
