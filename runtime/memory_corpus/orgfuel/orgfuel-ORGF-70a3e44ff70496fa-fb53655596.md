# 一页纸 v0.3 审读笔记（外行视角 + 事实核查 · 2026-08-30 晚）

> 目的：一页纸是发给银河通用/云迹的第一次亮相，按"对方 10 秒看懂 + 每句经得起追问"标准过一遍。

## 硬伤（必须修，已改入 v0.4）

1. **"协议体系已申报三项发明专利"——仓内零依据。**
   roadmap 中"专利"均为规划语（"专利卡位""护城河序列"），无任何申报凭证或记录。
   发给专业买家后若被追问申报号/受理凭证，无法自证 → **v0.4 删除此句**（三件套机制名前文已出现，无信息损失）。
   若用户确认实际已申报：恢复原句并在仓内补一份申报记录（编号+日期）再发。
2. **"评测任务族（LIBERO）与 Anthropic 官方机器人研究基准同源"——无出处。**
   仓内（roadmap/evidence/调研）无任何文档支持此关联。对方一问出处即穿帮，且把自家证据
   挂靠大厂说法反而削弱中立立场 → **v0.4 改为可独立验证表述**："评测任务族为 LIBERO
   （学术社区广泛使用的机器人操作基准）"。

## 可读性（轻微，已顺带改）

3. "两部制"为公用事业/电信计费术语 → v0.4 保留标签但确保括号白话解释紧跟（v0.3 已有，微调语序）。
4. 其余：开头死结场景清晰；81%/71% vs 0% 的对比句是全文最强资产；合作形态三栏清楚——保留。

## 结构性建议（本次不改，供后续版本）

- "我们解决什么"段可加一行目标读者锚（"如果您在采购/评估具身数据"），降低非目标读者跳出。
- 联系方式仅邮箱；银河/云迹直投建议补充微信或电话（用户提供后加入）。
