## 二、本周最贵的一次失误:RFC"等函"拖了两天

10825(澄清函)早就说了"请直交正本不等函"——我按自己的旧框架("等平台发函")空等了两天,24h 死线压线完成,还多发了一封询问函。

**根因**:①收到澄清函时,**只摘了信息,没有执行其中的动作指令**——把"行动指令"当"背景信息"归档了;②旧框架(等函)没有被新信息打破。

**结构性解药**:收函处理增加一个强制问句——**"这封函要求我做什么动作?现在做还是排期?"**——answer 必须落到 queue 或立即执行,不允许"知悉归档"吞掉动作件。(此条已写进值守轮纪律)
