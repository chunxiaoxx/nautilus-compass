[## §3 产品形态(P0→P3,一条演化线)] - **P0 自用 compass(已通)**:记忆+燃料+Gate B+胶囊。验收=自己变强(Gold n≥3 + 胶囊生效)。这是 P1-P3 的 demo 和证据源,**永远优先**。
- **P1 Gate B harness 开源(9 月评估)**:三臂 paired A/B + 独立 oracle + fail-closed 证据链,作为"验证学习"参考实现。开源换引用与贡献者,闭源留 ledger/裁决/PoI。判据:论文投出后再开,防被抢跑。
- **P2 燃料市场(FDE 业务升级)**:从"卖题"升级为"卖带 B3 验证的轨迹燃料"——同一批专家产出,买家从"题目"变"可学习数据",单价上移(买方按 pass@k 验收本来就接受验证逻辑)。**这是现金流与战略的合流点**:现有 FDE 合同不需推翻,加一列"verified trajectory 交付"即可试点。
- **P3 标准与计量(远期)**:VSR/B 分级作为 agent 经济的计量标准(NAU 已有雏形)。只有 P0-P2 成立后才配谈。
