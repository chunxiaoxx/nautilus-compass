[### L1 · 预注册判据层] - 判读开工前判据档已冻结,含指标定义、门槛、统计法、止损线;判据正本形态可以是独立 jsonl(如 REG-100 冻结件)或函件正文(如 G1 criteria_J=flywheel 函 2389——首演时未独立落盘,2026-10-04 抽查坐实并如实记,后续判据一律独立落盘)。
- **判据零放宽**三不:不改阈值、不延长步数、不以代理读数顶替冻结语义。判不动就报"判不动"(案 5:成功率 0/20 地板,照报 U 态,不以 coverage 代理顶替)。
- 判据宽松化裁决权在用户,不在判读方与材料方任何一侧(宪法十三条①;案 7 留痕)。
