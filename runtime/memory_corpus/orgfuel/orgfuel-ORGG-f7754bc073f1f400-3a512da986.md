## 四 · 新优先级(7 天,10/26 检查)

### P0 · M1 突击(唯一优先)
- **暖渠道 > 冷渠道**:用户向**已有认识的 5 个人**发一条私信:"我在做 agent 产出的
  第三方验证服务,免费帮你复算你公开发布过的数字,出带签名的报告"——一条暖介绍
  值一百条冷 issue。这是整个 7 天里杠杆最高的动作,且只有用户能做
- **创世十家冷名单**(agent 可完成):列 10 个"公开发布过可复算声明"的 agent 开源
  项目,逐个做**示范性免费复算**(我们主动复算他们的公开数字,出回执,连同
  "要不要挂墙"的邀请)——从"求人来做"变成"做完了给你看"
- **把产品演示讲出去**:1/5→3/5 的完整故事(带签名成绩单可验)投一个真正有流量的
  场:自家 repo Discussion(零成本触达唯一认识我们的人群)+ 用户的内容渠道
  (公众号/知乎,内容引擎现成)——博客渠道死亡就让它死,不再救
- **零学习成本入口**:repo 加"recompute request"issue 模板——外部人贴声明+证据
  链接即可,**打包我们来**("你不用懂 VerifyPack")
