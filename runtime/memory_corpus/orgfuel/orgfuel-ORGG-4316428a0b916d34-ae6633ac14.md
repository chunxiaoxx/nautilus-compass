## 八、收益模型(2026-09-30 用户拍板:对接合作=我们的收益点之一)

计量不止是尽调,是一条三层收入路径的入口:

| 层 | 产品 | 定价锚 | 触发条件 |
|---|---|---|---|
| L1 计量报告 | 30 天 J1-J7 终报(含失败样本+独立性声明) | 赞助额度抵(本次);对外同类 $499-999 | 30 天跑完即有 |
| L2 认证上墙 | "Assay Verified Gateway" 徽章+报告链接,UNVERIFIED→VERIFIED 转正 | 认证订阅 SKU1 实例化 $99-299/版本 | 读数 PASS 才发 |
| L3 复检订阅 | 网关模型/路由/价格变更触发复检(版本触发模式) | 按次 $99 或年订 | 对方迭代即触发 |

- **L2 是关键跃迁**:这是总纲 GTM 四级漏斗中"认证订阅"的第一个真实客户实例——从计量(一次性)升级为认证(持续关系),验证"版本更新触发"的付费场景是否成立
- **独立性红线不变**:判据预注册不可放宽;FAIL 保发布权;徽章只在 PASS 发——**认证的可信度本身就是商品**,不因收入来源妥协
- 若读数 FAIL:无 L2/L3,但 L1 报告的失败样本+方法学=Assay 公开方法学资产,仍具获客价值(展示"我们怎么测")
- 对接话术锚点:对方要"展示位+教程共创",我们给"第三方实测背书"——价值互换对等;他们的 API 网关若通过计量,等于在 Jev/LLM 生态里多一个"被独立验证过的供给",这对他们获客有实际价值
