## 三、防污染护栏(自指与信号衰减问题——用户核心关切)

1. **anchor_level 分层(理论基础档 §一落地)**:每条判例标阻抗等级——L0(物理执行/用户拍板/外部复算)直接入池;L1(专家/跨框互认)入池带标;L2(模型判)只作参考层不进训练集;**L3(纯自说自话)永不入池**;
2. **训练用途定向**:组织历史判例训练的是 judge 的**元判读能力**(识别"什么判断模式会失败"),不是教模型"组织说过什么"(那是记忆层职责)——两条线不混,防自指;
3. **原始文本不入池**:只入结构化判例(隐私+噪声双重理由);
4. **判例也要被判断**:机制本身产出的每批判例抽样 10% 人工复检(判绩账双向)——自动化不等于无监督。
