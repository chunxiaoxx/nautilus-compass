# 资质证照盘点 v0（数据业务合规清单）

> 2026-09-04 · v0 纸面盘点。用途：政府线/平台入驻/客户尽调必问"你有没有资质"；本清单=先知道要办什么。
> 诚实纪律：标注"待核对"项不臆断集团现有证照；与集团行政核对后更新。

## 一、逐项清单

| 资质/制度 | 用途 | 状态 | 备注 |
|---|---|---|---|
| 营业执照经营范围含"数据处理/人工智能" | 承接数据业务的前提 | 🟡待核对 | 国曙人工智能科技经营范围是否覆盖数据加工与销售，核对后必要时增项 |
| 增值电信业务经营许可证（ICP/EDI） | 自营线上平台（H5 派单+结算）对外运营 | ⬜未办 | 平台迭代二（对外运营）前确认是否触发许可条件；仅内部工具不触发 |
| 人力资源服务许可/劳务派遣资质 | 采集员招募与灵活用工 | 🟡集团应已有 | 待核对集团现有资质与适用主体 |
| 个人信息保护影响评估（PIA）报告 | 采集涉及人脸/个人信息的合规证据 | 🟡制度已备 | 《个人信息处理规范 v0》为基础，PIA 成文待首采前完成 |
| 数据出境备案 | 涉外数据交付 | ⬜不适用 | 现阶段不出境；触发时走备案通道（港区方案已预留） |
| 数据交易机构挂牌资质/备案 | 上海数交所等挂牌数据产品 | ⬜远期 | 首批成品数据集后评估；上海线（DOME/数交所）接触时问清口径 |
| 采集设备入网认证 | 设备合规 | ⬜不适用 | 用消费级成品设备，无自研入网需求 |
| YD/T 6771-2026 符合性 | 标准符合证据 | ✅自查完成 | 自查表在档；无认证机制，表述为"对照生产" |
