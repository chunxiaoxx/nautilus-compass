## 一、compass 是什么(正本定义)

**compass + assay + jev = 三位一体判断体系**(记忆+验证工具+判据)；
**NACRE 创新模型** = 压缩×验证 + 因果倒置 + assay + jev + 原生记忆 + 技能内化的垂直创新模型；
**评测、燃料、判分** = 全部 compass 业务。

一句话：**compass 是组织的判断体系——用记忆存经验、用 assay 验真伪、用 jev 定标准、用 NACRE 压缩成模型、用评测输出结果。**
