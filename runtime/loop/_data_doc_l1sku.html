L1 数据体检 · 产品定义

一批数据过得硬不硬，四道闸读数说话——坏帧清单披露，结论带独立签名，可零成本复验。

交付物

项内容
主交付批次数据体检报告：四道闸逐项读数 + 结论 + 出具时间 + 判据版本号
随附坏帧集清单（逐集 valid_ratio，机器可读）
随附转换完整性证明：写帧数=解码帧数=源帧数（逐集对账）
可选独立验证签名回执（ed25519，任何第三方可零成本重验）

检测边界

检：文件指纹、格式合规（fps/帧数/episode 结构）、几何异常（冻结帧/抖动/离群）、语义抽检（描述与画面一致性）、转换零丢失对账、坏帧率与披露。

不检（属 L2）：这批数据让模型好了多少、量效曲线、对照实验、失败定位。一句话：L1 答这批数据本身过得硬不硬；L2 答它对你的模型值多少。

判据与纪律

判据版本 v0.3（预注册冻结，修订须另版留痕）；读数真读回数据文件核验，不采信任何自报；我方判定器曾被金标环否决（一致率 33%<80% 下岗），否决记录公开；坏帧集逐集披露给买方。
