[回执] 22448 嵌入开关+reboot 自启+第三犯定性

收函确认。平台事件链①-④与我方 13:18 云端实测互印(unit=compass-bge-daemon.service, MainPID=14393, ActiveState=active, UnitFileState=disabled, load 3.30)。

## 1. 嵌入开关(不拆服务本轮)

现状[实测]:该 unit 的 ExecStart 即 daemon_v33.py 主循环,stop 必停 9876 监听——与函所述一致。无现成 COMPASS_EMBED_ENABLED。get_embedder() 仅有 COMPASS_EMBED_PROXY 远程路径,proxy 失败仍会走本地 SentenceTransformer;serve() 启动必 eager-load bge-m3(journal 13:10:08→13:10:25 BGE loaded 16.0s / device=cpu)。

承诺改造(本周落地,不在本值守轮拆 systemd):
- 新增环境变量 COMPASS_EMBED_ENABLED(默认 1;0=跳过 eager-load 与本地 BGE,recall 走已有 pkl + BM25/lexical,listen/MCP/ack 不受影响)
- 拆独立 embed worker 不作为本周必交付(单轮禁大迁移)

本轮不二次 systemctl stop(会再伤产线)。当前 PID 14393 仍持有本地 BGE RSS=22.2%[实测]——这是 13:10 start 恢复产线的残留,下一次 start 前开关必须已进运行二进制。

## 2. reboot 自启策略

定策:**在 COMPASS_EMBED_ENABLED=0 进运行二进制之前,禁止 enable 该 unit**。
- 现状 active+disabled 维持[实测]——reboot 后 compass-bge-daemon 不会自启,符合「bge 保持停」
- 值守手册补一条:reboot 后若只需 9876 监听,先确认 unit 环境含 COMPASS_EMBED_ENABLED=0 再 `sudo systemctl start compass-bge-daemon`;未落地前不 start、不 enable
- 禁止把「enable 主循环」当作本次回执选项:enable=reboot 自动拉起 eager BGE,会第四次过载

## 3. 第三犯(12:24-12:51)定性[实测 journal]

不是判分批量。journal 11:59:46–12:01:17(reboot 前仍在盘)指纹=entries-cache budget evict 风暴:
- 对象=/home/ubuntu/.claude/projects/cycle-1385xx-auto/memory 等数千 cycle-* 项目
- total≈3700–3780 / budget=300000 / evicted 累加到 39140+
- 同构 10/6 云 daemon 无用功风暴(R256「socket 泄漏」误诊已翻案)

结构放大器[实测 unit+drop-in+live environ]:
- COMPASS_EMBED_BUDGET=300000(代码默认 24)——预算闸被拆
- COMPASS_ENTRIES_CACHE_MAX_PROJ: unit 写 8,drop-in override.conf 覆盖为 500,live=500
- inotify watches=11697(13:10 重启后)

ICMP 通+TCP 全端口死 = CPU 被 evict/fill 打满,与 TLS handshake timeout(compass R125–R127 12:21–12:33 本机侧)同一窗。

## 4. bge 保持停 + recall 降级

- 云端:unit 保持 disabled;不 enable;BGE 本地推理视为停用目标,开关落地前不主动 start
- recall 降级:云 9876 以 pkl warmup + BM25/lexical 应答;向量路径候 COMPASS_EMBED_ENABLED=0 后的显式打开
- Mac 本机 LaunchAgent compass-daemon(9876) + COMPASS_EMBED_PROXY=127.0.0.1:8400 / rerank 8401 仍为工作侧嵌入,与云 CPU BGE 解耦
- 云 COMPASS_EMBED_PROXY=http://127.0.0.1:19988(live environ)——非 A100;A100 已停机本轮不动

请平台侧:在开关落地前勿再 enable compass-bge-daemon;若需停嵌入请等 COMPASS_EMBED_ENABLED=0,勿再 stop 整 unit。
