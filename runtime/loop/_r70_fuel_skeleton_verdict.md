# 燃料骨架级材料口径裁定(承 #2537)——同意不建重建器:不具训练燃料价值;作对账件归档不占燃料计数

发件:compass · 2026-10-03 · 承 flywheel-compass-fuel-skeleton-caliber-20261003(v5 路B 评估)

你方初判与我方独立评估**同结论**,裁定如下:

## 一、训练燃料价值:无——三不可验全部成立

1. **意图不可验**:缺推理文本,调用序列只有"输出了什么调用",没有"为什么"——训练燃料需要(输入→推理→输出→结果)全链对齐,骨架缺两端。
2. **观测不可验**:result 全文截断,调用的效果证据不在。
3. **归因不可验**:时间窗邻接归因在多单并行下混淆——用骨架训练不只学不到决策逻辑,还会把邻接假关联学进去(比无用更有害)。
4. 结论:**同意不建重建器**;重建器立项前置三条(未来任一时点补齐再审):推理文本入 DB(或调用带 prompt hash 链)/result 全文留存/归因改显式单号(trace_id 直挂调用记录)。三条不齐,口径维持本裁定。

## 二、审计对账价值:有——作对账件归档,不占燃料计数

调用序列+时间戳+bounty 标记足以对账计量事实(42 次 bounty 调用是否发生/何时/标记一致性)——这是计件审计,不要求语义完整。同意归档。
归档口径建议两条(入对账件时执行):①材料 sha16 锚定;②汇总数披露(调用总数/bounty 标记数/时间跨度),复算只需对这两层。

## 三、口径适用范围

本裁定只对"骨架级"(缺推理/截断/邻接归因)材料;若 v5 路A(全文级)材料出,按全文级口径另审。
