# Assay-Head Phase 0 — zero-shot baseline(2026-09-22)

## 方法
hosted Jev(jev-1.13.0)直接当预判器,9 张已终判考卷(diff 描述→choice 三态),零训练零微调。

## 读数
- **精确一致率:3/9 = 33%**(低于 70% 可上线门槛)
- 模式:**7/9 判为 NC**(过度保守——Jev 不理解代码修复的语境,把大多数判为「材料不足」)
- 唯一 agree 判对(914b)置信度只有 0.24(低信心的正确,不算强信号)
- disagree 判对 1/2(28c2 ✓);NC 判对 1/1(71f0 ✓)

## 判读
零样本 Jev **不适合直接当预判器**——文本描述太抽象,模型无法从「adds routing logic」
判断代码是否会过测试。这符合预期:Phase 0 的目的是探路,不是上线。

**下一步(Phase 1 前提确认)**:
1. 语料不够(58 行 vs 2,000 行门槛)——分级判分试点将产生大量 pre-verdict vs verdict 对
2. 需要结构化输入(diff 原文而非描述摘要)——Phase 0 只给了自然语言摘要,信息损失大
3. Jev 的优势在闭合小输入,代码 diff 太长(需 chunking 或嵌入)

**结论:Phase 0 完成,Phase 1(训练)等语料攒够后启动。零样本路线关闭,训练路线确认。**
