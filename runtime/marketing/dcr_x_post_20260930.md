We tried to click the "(proof)". It doesn't exist.

An AI lab advertises:

"193.6x Faster, 444.6x Cheaper — based on workflows for System One tasks (proof)"

So we checked. Three things:

1. The "(proof)" is styled text, not a link. No href in the HTML. No methodology page anywhere on the site. The pricing page 404s.

2. Their own on-page demo shows:
- Cost: $0.013880 (LLMs) vs $0.000081 (them) = 171x
- Time: 8.566s vs 0.114s = 75x

Not 444.6x. Not 193.6x. The advertised numbers and the demo numbers don't match on the same page.

3. Maybe both are true — for different comparison sets, against different models, measured differently. That's exactly the problem: you can't tell, because the methodology doesn't exist publicly.

Here's what we could verify, for the record: $42 per billion input tokens checks out against their "238x cheaper than Claude" claim (42 × 238 ≈ $10/M, which is the public list price). So the arithmetic is fine. The claim structure isn't.

This isn't about one company. The whole agent-memory / decision-model layer runs on self-reported numbers:

- Memory startups raising $24M (TechCrunch, Oct 2025) — "186M API calls in Q3", all self-reported
- Governance-layer pivots quoting 94.7% accuracy on their own homepage
- Performance claims with "(proof)" labels that aren't links

The category has capital, traction, and governance narratives. What it doesn't have: one reproducible, third-party-verified number.

Calibration claims need receipts. That's the business we're in.
