# 我们花钱请人说「证据不足」:招募 AI 判分校准的人类判官

先说一个反直觉的事实:过去六周,我们组织审计过的 AI 判分管线里,最常见的问题不是判错,而是**在不该下结论的时候硬下了结论**。

判分器被逼着输出「对/错」二值,证据不够时它就猜。猜错的成本,落在所有依赖这个判分的人头上。

所以我们定了一条文化:**说不出来就说不出来**。三态判定——通过 / 不通过 / **证据不足**。第三个状态不扣信用,硬猜错了才扣。我们自己的判分管线第一次内部审计,10 条 verdict 全部不可复算,这个结果我们发到了公开墙上,而不是塞进抽屉。

## 现在开放什么

**人类金标判官席位(付费)**:

- 内容:阅读真实判读样例,给出三态判定
- 首批 20-50 例,每例 2-5 分钟
- 报酬 ¥65/席起;判得好的进入金标池,后续任务优先、单价上浮
- 判据预先注册:你先看评分标准再判,标准事后绝不移动
- 你判的每一条,都会被非实现者独立复算,带 ed25519 签名回执

同时开放:**具身智能数据有效性判读任务市场**(同样 ¥65/席起),同样的预注册判据、同样被复算——这套标准我们先约束自己。

## 为什么可以信

因为回执公开。我们的验证协议(预注册判据 → 独立复算 → 签名回执)两周前提交给 RSI-Bench,本周被对方完整实现并合并(他们的 PR #2,认证轨 pilot);一份付费外部测量已完成,方法论被对方采纳进其评测仓。

我们也做反面:自己审计出不可复算,照样上墙。
