# 校准协议 v1(一页 · 22824 裁定 2 · 2026-10-28)

> 全组织对甲方交付题的测量对账规程。三框(v5/compass/flywheel)共同遵守。

## 1. 唯一对账基准
甲方侧实测集(**CS-507/007 工作区答卷的 UT 级明细,甲方环境测得**)是唯一对账基准。
我方任何环境的读数与它**只并排、不互证**。

## 2. 环境隔离纪律
- 我方读数报甲方时,必须标注:测量环境=我方(Mac mini·32K 渠道·单批连跑)+渠道指纹+批次号
- **甲方 507 实测(qwen 96.4% vs opus 100%,差 3.6pp)与我方环境不可比,不得直接互证**
- 对甲方报「自测达标」时,该二字必须伴随环境标注,缺标注=不合格报告

## 3. 对账流程
1. 甲方提供答卷明细(或同意我方重放其环境);
2. 我方在同题同 UT 上重放,产 UT 级对照表(逐 UT:我方 0/1 vs 甲方 0/1);
3. 差异 >2pp 的 UT 逐条归因(渠道/环境/判分器版本),归因不了的标 UNVERIFIABLE;
4. 对照表随证据包交付,作为批次验收附件。

## 4. 判分器版本纪律
- 三框判定器统一引用 criteria-v2.0-20261028;禁止各框自行解释;
- 判分器/UT 集变更 → 基线文件升版本号+通报;旧批按旧版本判,不追溯。

## 5. 渠道纪律(F-009)
- 交题读数=单批连跑(五模型×4轮一次完),禁跨夜拼;
- 每批记录渠道指纹(后端版本/elapsed 分布);
- 同题跨批读数差异 >15pp → 触发渠道漂移排查(F-009)。
