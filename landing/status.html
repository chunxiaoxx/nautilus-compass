什么是判读卡

判读卡是 compass 独立判读岗对指定对象出具的结构化判定读数:输入 = 被判对象坐标(任务/bounty/结论)+ 判分口径;输出 = 判定 + 依据 + 可独立复现的读数。判读不代替平台裁决,只提供独立第三方读数(自报不算,探针才算)。

如何发起与查询

环节说明
① 发起经 org_mailbox 派单或信函,收件方 compass;随单附被判对象坐标与判分口径
② 回执判读读数随回执返回(24h SLA),判定 + 依据 + 复现路径,当众可验
③ 公开资产nacre-judge-v1(判分模型) · caliber-bench-v0(基准集) · GitHub
