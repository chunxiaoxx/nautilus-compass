30 秒理解 · 这是什么

问题

你的 AI 助手在 Claude Desktop 里学到的事 · 切到 Cursor 它不知道 · 切到 Cline 又重新学一遍。每个 chat 都是 Memento · 每次 session 从零开始。

更糟糕: 它没记忆 · 还会反复犯老错 (声称完成但没验证 · 重复无效尝试 · 找错服务器)。

Compass 解决

同一个 user_id 跨所有 MCP/A2A 兼容 client · memory 自动 federate。 AI 在哪学到的 · 在哪都知道。

每个 session 末自动 drift 自审 (green / yellow / red) · 反复犯错的 agent 被自然淘汰 (在 stake 经济下还会被罚)。

5 个真实场景

  • ①
    跨 agent 共享 "用户偏好"

    你在 Claude Desktop 说"我喜欢简洁回复 · 不要分析师腔" · Cursor 立刻知道。 不用每个 client 重复教一次。

  • ②
    项目级 memory · 跨 session 累积

    你在 ZenMind 项目里讨论过 "token 经济学 v2 必须加 stake unstake 时间锁" · 下次任何 agent 回到这个项目 · Compass 自动 recall · 不用重新解释。

  • ③
    AI drift 自动告警

    session 末 LLM 自审打 drift: red + 列举证据 ("找错服务器 · 忘记 PEM 路径 · 声称完成但没验证")。 你下次能直接看 timeline · 避坑。claude-mem 永远不会做这个。

  • ④
    开发者级生产部署

    docker-compose · systemd · audit log 90d retention · daily backup · Prometheus metrics · OAuth2 PKCE · GDPR 删除/导出 endpoint · 一切 production-ready。

  • ⑤
    Nautilus 平台 8 fusion · 经济驱动校正

    drift=red → stake_penalty (1% locked) · drift=green → stake_bonus (0.1%)。 让 AI 自审跟经济激励挂钩 · 长期培育 green-多 agent · 自然淘汰 red-多 agent。

诚实的失败

Compass v0.8 的算法选型经过 4 个失败实验 · 我们公开记录因为 paper-grade 工程 应该报 negative findings:

Neo4j graph rerank: -6.2 pts · 在 closed haystack 上 graph 信号跟 cross-encoder 重复 · 不加分反而 confuse · 撤回。
SSP "infer preference" prompt: -37.5 pts · 让 LLM "推断用户偏好" 反而让它编造食物相关答案 · 不管问题是什么 · 撤回。
Double-model router (ssp+ku 用强 model): -2.1 pts · sample 50 噪声不可区分 · 撤回。
MiniMax thinking-1024 refusal cascade · sample 50 acc 45.8% (假象) · full 500 拒答率从 17% 涨到 44% · acc 跌到 33% · kill at 302 题。 纸上记录因为这是产业级 production 警告: per-model thinking-on/off 必须 benchmark · 不能假设 thinking 总是有用。
