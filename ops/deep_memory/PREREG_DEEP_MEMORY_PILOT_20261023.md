# 预注册判据 · compass 深度记忆库试点(2026-10-23 开工即落)

## 对象
compass 单框 1336 jsonl → 提取→分块→本机嵌入(8400)→ sqlite-vec 入库。

## 预注册验收判据(明早验收,只许更严)
1. 【入库量】blocks ≥ 15,000(预计 2-5 万;值守碎片打 grade=low)
2. 【嵌入完整性】入库向量数 = blocks 数(零失败);抽样 10 块向量维度=1024
3. 【检索命中】20 个历史问题探针(覆盖:GPU 纪律/勘误/判读岗/迁移/组织函件),
   deep_recall top5 含相关块的题数 ≥ 16/20(80% 门)
4. 【信噪分离】grade=high(正史)块的命中优先级:20 题中 ≥14 题首命中为 high 块
5. 【时效】端到端单次 deep_recall ≤ 3 秒
6. 【可回滚】历史库为独立单文件,现役 pkl/recall 零改动

## 边界
- 试点仅 compass 框;过门后才铺全框
- 命中块一律标 [历史·情景],禁止当现状结论引用
