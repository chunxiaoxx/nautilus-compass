# ephem 数据政策 · docs/data_policy.md(内部规范·摘录)

§1 时基: 全管线 UTC。
§2 持久化: 时间戳持久化(落盘/消息体/外部表)必须无损——ISO-8601 字符串
   或 astropy jd1/jd2 双值;**单 JD 浮点值禁止越过持久化边界**(JD 量级
   ~2.46e6 下 double 的分辨率约 20μs,亚毫秒信息静默丢失,OBS-772 实证)。
§3 内存流转: 模块内部计算可用 Time 对象;跨模块传递以 Time 对象或 ISO
   字符串为准,浮点 jd 仅限引擎算子内部瞬时使用。
§4 对照: format.py 为合规参照实现。
