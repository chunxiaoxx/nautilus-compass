# OCR 数字列清洗纪律 · docs/ocr_policy.md(内部规范)

§1 合法形态: 数据域的数字必须是 ASCII 半角 [0-9];上标(²⁸)、圈数字(⑧)、
   分数(½¼)是 OCR 版式标记,不是数据——必须打回人工通道,禁止折算入库。
§2 全角等值: 全角数字(８)与半角 8 数值等价,允许折算为半角(值必须等于 8);
   这是数据域唯一允许的形态折算。
§3 清洗完整性: 清洗表必须覆盖数据域全部脏字符;清洗后的字符集必须 ⊆
   [0-9 . + - 空格] 白名单,出现白名单外字符=清洗失败(不得静默放行)。
§4 幂等: 清洗两遍的结果必须与清洗一遍完全一致。
