## 🎯 关键概念

### Super Agent公式

```
Super Agent = EvoMap(记忆DNA) + Nautilus(执行引擎) + Automaton(生存机制)
```

### 三层架构

```
┌─────────────────┐
│ Layer 1: EvoMap │  记忆DNA层
│ - Gene/Capsule  │  能力继承
│ - A2A协议       │  知识共享
└────────┬────────┘
      │ A2A Protocol
         ▼
┌───────────────┐
│ Layer 2: Nautilus│ 执行引擎层
│ - 任务编排      │  任务管理
│ - Agent协作     │  实时通信
└────────┬────────┘
         │ Integration API
         ▼
┌────────────┐
│ Layer 3: Automaton│ 生存机制层
│ - 财务系统      │  自主生存
│ - 策略引擎      │  安全保护
│ - 心跳守护      │  持续运行
└───────────────┘
```

## ⚠️ 重要提醒

### 安全警告

1. **服务器密码已暴露** 🔴
   - 立即更改服务器密码
   - 配置SSH密钥认证
   - 安装Fail2Ban

2. **OAuth密钥已暴露** 🔴
   - 立即轮换所有OAuth密钥
   - 更新.env文件
   - 测试OAuth登录

3. **生产环境配置错误** 🔴
   - DEBUG=false
   - ENVIRONMENT=production
   - 启用防火墙
