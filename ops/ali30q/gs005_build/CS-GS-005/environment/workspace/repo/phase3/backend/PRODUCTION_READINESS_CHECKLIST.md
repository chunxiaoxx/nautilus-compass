## 使用说明

本检查清单包含 **150+ 检查项**，分为以下几个阶段：
1. **部署前检查**: 确保所有准备工作完成
2. **上线检查**: 部署过程中的验证
3. **上线后验证**: 确保系统正常运行
4. **性能基准**: 验证性能指标

**检查方式**:
- ✅ 已完成
- ⚠️ 部分完成/需要注意
- ❌ 未完成
- N/A 不适用

- **P0**: 系统完全不可用，需要立即修复

- **P2**: 部分功能受影响，计划修复

```bash
#!/bin/bash
# quick-check.sh - 快速检查脚本

echo "=== 系统状态检查 ==="

# 检查服务状态

# 检查磁盘空间

df -h

# 检查内存使用
echo "检查内存使用..."
free -h

# 检查 CPU 负载
echo "检查 CPU 负载..."
uptime

# 检查网络连接
echo "检查网络连接..."
netstat -tuln | grep -E ':(80|443|5432|6379|8000)'

# 检查 SSL 证书
echo "检查 SSL 证书..."
echo | openssl s_client -servername yourdomain.com -connect yourdomain.com:443 2>/dev/null | openssl x509 -noout -dates

# 检查应用健康
echo "检查应用健康..."
curl -f http://localhost:8000/health || echo "健康检查失败"

echo "=== 检查完成 ==="
```
