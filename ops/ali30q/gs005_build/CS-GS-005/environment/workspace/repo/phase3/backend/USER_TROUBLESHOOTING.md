## 账户和认证问题

### 问题 1：无法注册账户

**症状**：
- 提交注册信息后返回错误
- 显示 "用户名已存在" 或 "邮箱已存在"

**可能原因**：
1. 用户名或邮箱已被使用
2. 密码不符合要求
3. 网络连接问题
4. 服务器错误

**解决方案**：

**步骤 1：检查用户名和邮箱**
```
- 尝试使用不同的用户名
- 使用其他邮箱地址
- 确保用户名只包含字母、数字、下划线
```

**步骤 2：检查密码强度**
```
密码要求：
- 至少 8 个字符
- 建议包含大小写字母、数字和特殊字符
```

**步骤 3：查看详细错误信息**
```json
{
  "detail": "具体错误原因"
}
```

**步骤 4：检查网络连接**
```bash
# 测试 API 是否可访问
curl http://localhost:8000/health
```

---

### 问题 2：登录失败

**症状**：
- 输入用户名和密码后返回 401 错误
- 提示 "用户名或密码错误"

**诊断步骤**：

**步骤 1：确认账户信息**
```
✓ 用户名拼写是否正确
✓ 密码是否正确（注意大小写）
✓ 是否使用了正确的登录方式（用户名或邮箱）
```

**步骤 2：检查账户状态**
```
- 账户是否已激活
- 账户是否被禁用
```

**步骤 3：尝试重置密码**
```
目前系统不支持自助重置密码
请联系管理员协助处理
```

**步骤 4：清除缓存重试**
```
- 清除浏览器缓存
- 使用隐私模式尝试
- 尝试不同的浏览器
```

### 问题 3：Token 过期或无效

**症状**：
- API 调用返回 401 错误
- 提示 "Token 无效" 或 "Token 已过期"

**解决方案**：

**步骤 1：重新登录获取新 Token**
```bash
curl -X POST http://localhost:8000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"your_username","password":"your_password"}'
```

**步骤 2：检查 Token 格式**
```
正确格式：Bearer eyJ0eXAiOiJKV1QiLCJhbGc...
错误格式：eyJ0eXAiOiJKV1QiLCJhbGc...（缺少 Bearer）
```

**步骤 3：在 API 文档中更新 Token**
```
1. 点击右上角 "Authorize" 按钮
2. 输入：Bearer 新的token
3. 点击 "Authorize" 确认
```

### 问题 4：无法绑定钱包地址

**症状**：
- 提交钱包地址后返回错误
- 提示 "钱包地址格式错误" 或 "钱包地址已被使用"

**诊断步骤**：

**步骤 1：验证钱包地址格式**
```
正确格式：0x 开头，后跟 40 个十六进制字符
示例：0x7809b48a102755776436aa2948d1e42d2377465d

常见错误：
✗ 缺少 0x 前缀
✗ 长度不是 42 个字符
✗ 包含非十六进制字符
```

**步骤 2：检查地址是否已被使用**
```
每个钱包地址只能绑定一个账户
如果地址已被使用，需要使用其他地址
```

**步骤 3：确认拥有该钱包**
```
- 确保您拥有该钱包的私钥
- 可以在 MetaMask 中查看地址
- 复制地址时避免多余的空格
```

## 任务操作问题

### 问题 5：无法创建任务

**症状**：
- 提交任务信息后返回错误
- 任务创建失败

**诊断步骤**：

**步骤 1：检查必填字段**
```json
{
  "description": "必填 - 任务描述",
  "reward": "必填 - 奖励金额（Wei）",
  "task_type": "必填 - 任务类型",
  "timeout": "必填 - 超时时间（秒）"
}
```

**步骤 2：验证数据格式**
```
✓ reward 必须是正整数
✓ timeout 必须是正整数
✓ task_type 必须是有效的枚举值
  （CODE, DATA, COMPUTE, RESEARCH, DESIGN, WRITING, OTHER）
```

**步骤 3：检查钱包余额**
```
确保您的钱包有足够的 ETH 支付 Gas 费用
查询余额：在 MetaMask 中查看
```

**步骤 4：查看详细错误**
```bash
# 查看 API 返回的错误信息
{
  "detail": "具体错误原因"
}
```

### 问题 6：无法接受任务

**症状**：
- 点击接受任务后返回错误
- 提示 "任务不可用" 或 "权限不足"

**可能原因**：
1. 任务已被其他人接受
2. 未注册为 Agent
3. 钱包余额不足
4. 任务状态不是 "Open"

**解决方案**：

**步骤 1：检查任务状态**
```bash
GET /api/tasks/{任务ID}

# 确认 status 字段为 "Open"
```

**步骤 2：确认已注册为 Agent**
```bash
GET /api/agents/me

# 如果返回 404，说明未注册
# 需要先调用 POST /api/agents 注册
```

**步骤 3：检查钱包余额**
```
1. 在 MetaMask 中查看余额
2. 确保有足够的测试 ETH
3. 如果不足，访问水龙头获取：
   https://sepoliafaucet.com/
```

**步骤 4：查询预估 Gas 费用**
```bash
GET /api/tasks/{任务ID}/gas

# 确认您的余额足够支付 Gas
```

---

### 问题 7：任务提交失败

**症状**：
- 提交任务结果后返回错误
- 提示 "任务状态错误" 或 "权限不足"

**诊断步骤**：

**步骤 1：检查任务状态**
```
只有状态为 "Accepted" 的任务才能提交
查询任务状态：GET /api/tasks/{任务ID}
```

**步骤 2：确认是任务执行者**
```
只有接受任务的 Agent 才能提交结果
检查任务的 agent 字段是否是您的地址
```

**步骤 3：检查提交内容**
```json
{
  "result": "必填 - 不能为空"
}
```

**步骤 4：检查是否超时**
```
如果任务已超时，状态会变为 "Failed"
超时的任务无法提交
```

---

### 问题 8：任务一直处于待验证状态

**症状**：
- 任务已提交但长时间未完成
- 状态停留在 "Submitted"

**可能原因**：
1. 发布者未及时验证
2. 发布者对结果不满意
3. 系统延迟

**解决方案**：

**步骤 1：等待发布者验证**
```
建议等待时间：24-48 小时
发布者需要时间审核提交的结果
```

**步骤 2：主动沟通**
```
如果超过 48 小时未响应：
- 检查提交的结果是否符合要求
- 联系发布者询问进度
- 必要时可以发起争议
```

**步骤 3：检查区块链状态**
```bash
# 查看提交交易是否成功
https://sepolia.etherscan.io/tx/{交易哈希}
```

### 问题 10：API Key 无法使用

**症状**：
- 使用 API Key 调用接口返回 401 错误
- 提示 "API Key 无效"

**解决方案**：

**步骤 1：检查 API Key 格式**
```
正确格式：nautilus_ak_开头
示例：nautilus_ak_1234567890abcdef...
```

**步骤 2：检查请求头**
```
Header 名称：X-API-Key
Header 值：nautilus_ak_...

错误示例：
✗ Authorization: nautilus_ak_...（错误的 Header）
✗ X-Api-Key: nautilus_ak_...（大小写错误）
```

**步骤 3：确认 API Key 有效**
```bash
# 使用 API Key 测试
curl -X GET http://localhost:8000/api/agents/me \
  -H "X-API-Key: your_api_key"
```

**步骤 4：API Key 丢失**
```
如果 API Key 丢失：
1. 使用 JWT Token 继续操作
2. 联系管理员重置 API Key
```

## 区块链交易问题

### 问题 12：交易一直未确认

**症状**：
- 操作提交后长时间没有响应
- 交易状态显示 "Pending"

**诊断步骤**：

**步骤 1：查看交易状态**
```bash
# 在区块链浏览器查看
https://sepolia.etherscan.io/tx/{交易哈希}

状态说明：
- Pending：等待确认
- Success：已确认
- Failed：失败
```

**步骤 2：检查网络状况**
```
访问：https://sepolia.etherscan.io/
查看当前网络状态和 Gas 价格
```

**步骤 3：等待确认**
```
正常确认时间：10-30 秒
网络拥堵时：1-5 分钟
如果超过 10 分钟，可能有问题
```

**步骤 4：重试操作**
```
如果长时间未确认：
1. 等待交易失败或确认
2. 不要重复提交相同操作
3. 检查钱包余额是否充足
```

### 问题 13：交易失败

**症状**：
- 交易在区块链上显示为 "Failed"
- Gas 费用被扣除但操作未成功

**可能原因**：
1. Gas 费用不足
2. 合约执行错误
3. 参数错误
4. 网络问题

**解决方案**：

**步骤 1：查看失败原因**
```bash
# 在区块链浏览器查看交易详情
https://sepolia.etherscan.io/tx/{交易哈希}

# 查看 "Error Message" 字段
```

**步骤 2：常见错误及解决**

**错误：Out of gas**
```
原因：Gas 限制设置过低
解决：系统会自动设置合理的 Gas 限制
     如果仍然失败，可能是合约问题
```

**错误：Insufficient funds**
```
原因：钱包余额不足
解决：获取更多测试 ETH
     访问：https://sepoliafaucet.com/
```

**错误：Execution reverted**
```
原因：合约执行条件不满足
解决：检查操作是否符合业务规则
     例如：任务状态是否正确
```

**步骤 3：重试操作**
```
1. 确认问题已解决
2. 等待几分钟后重试
3. 如果持续失败，联系技术支持
```

## API 调用问题

- 请求返回 400 Bad Request
- 提示参数错误

**诊断步骤**：

**步骤 1：检查请求参数**
```json
// 查看错误详情
{
  "detail": [
    {
      "loc": ["body", "reward"],
      "msg": "field required",
      "type": "value_error.missing"
    }
  ]
}
```

**步骤 2：验证数据类型**
```
常见错误：
✗ 字符串传入数字字段
✗ 数字传入字符串字段
✗ 缺少必填字段
✗ 枚举值拼写错误
```

**步骤 3：参考 API 文档**
```
访问：http://localhost:8000/docs
查看接口的参数要求和示例
```

### 问题 16：API 返回 404 错误

**症状**：
- 请求返回 404 Not Found
- 提示资源不存在

**可能原因**：
1. URL 路径错误
2. 资源 ID 不存在
3. 接口不存在

**解决方案**：

**步骤 1：检查 URL 路径**
```
正确：http://localhost:8000/api/tasks/1
错误：http://localhost:8000/api/task/1（缺少 s）
错误：http://localhost:8000/tasks/1（缺少 /api）
```

**步骤 2：验证资源 ID**
```bash
# 先查询资源是否存在
GET /api/tasks

# 确认 ID 正确后再访问
GET /api/tasks/{正确的ID}
```

**步骤 3：查看 API 文档**
```
访问：http://localhost:8000/docs
确认接口路径和方法
```

---

### 问题 17：API 返回 429 错误

**症状**：
- 请求返回 429 Too Many Requests
- 提示请求过于频繁

**解决方案**：

**步骤 1：了解速率限制**
```
默认限制：100 请求/分钟
超过限制会被暂时阻止
```

**步骤 2：降低请求频率**
```
- 增加请求间隔
- 批量处理数据
- 使用分页查询
```

**步骤 3：等待后重试**
```
等待 1 分钟后速率限制会重置
然后可以继续请求
```

## 数据问题

### 问题 23：数据不一致

**症状**：
- 数据库中的数据与区块链不一致
- 任务状态显示错误
