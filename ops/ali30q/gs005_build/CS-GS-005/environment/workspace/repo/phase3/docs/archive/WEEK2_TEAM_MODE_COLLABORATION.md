## 🎯 新协作模式

### Dialog A: 团队模式全权负责

**使用团队模式**:
```
/team

任务: Week 2 Phase 1 性能优化

团队配置:
- Agent 1: 后端开发
- Agent 2: 测试工程师
- Agent 3: 性能工程师
- Agent 4: 代码审查
- Agent 5: 文档工程师

自主决策: 技术实现、测试策略、代码优化
需要批准: 架构变更、目标调整、部署决策
```

**工作方式**:
- 内部多Agent并行工作
- 自主完成开发、测试、审查
- Phase完成时向Dialog B汇报

---

### Dialog B: 战略协调

**减少微观管理**:
- ❌ 不审查每个任务的代码
- ❌ 不给出具体实现方案
- ✅ 关注Phase级别目标
- ✅ 关键决策点介入

**关注重点**:
- Phase完成后验收
- 遇到阻塞时协调
- 架构重大决策
- 最终部署批准

---

### Dialog C: Phase级审查

**减少频繁审查**:
- ❌ 不审查每个任务
- ✅ Phase 1完成后审查
- ✅ Phase 2完成后审查
- ✅ 最终部署前审查
