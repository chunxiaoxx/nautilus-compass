## 部署前安全检查

### 1. 环境配置检查

#### 1.1 环境变量
- [ ] 所有敏感配置已从代码中移除
- [ ] 使用环境变量或密钥管理服务存储密钥
- [ ] `.env` 文件已添加到 `.gitignore`
- [ ] 生产环境配置文件已单独管理
- [ ] 所有默认密钥已替换为强随机值

#### 1.2 调试和开发模式
- [ ] `DEBUG=false` 已设置
- [ ] `ENVIRONMENT=production` 已设置
- [ ] API文档端点已禁用（Swagger/ReDoc）
- [ ] 详细错误信息已禁用
- [ ] 开发工具已移除或禁用

#### 1.3 HTTPS配置
- [ ] `FORCE_HTTPS=true` 已启用
- [ ] SSL/TLS证书已配置且有效
- [ ] HSTS头已启用
- [ ] 证书自动续期已配置
- [ ] 支持TLS 1.2及以上版本

### 2. 认证和授权检查

#### 2.1 密钥管理
- [ ] JWT密钥长度至少32字符
- [ ] JWT密钥使用强随机生成
- [ ] CSRF密钥已配置且不同于JWT密钥
- [ ] API密钥前缀已配置
- [ ] 区块链私钥使用加密存储

#### 2.2 密码策略
- [ ] 密码最小长度12字符
- [ ] 要求包含大小写字母
- [ ] 要求包含数字
- [ ] 要求包含特殊字符
- [ ] 实现密码历史检查
- [ ] 实现账户锁定机制

#### 2.3 会话管理
- [ ] JWT过期时间合理（建议30分钟）
- [ ] 刷新令牌机制已实现
- [ ] 会话超时已配置
- [ ] 支持令牌撤销
- [ ] 实现单点登录（如需要）

### 3. 数据库安全检查

#### 3.1 连接安全
- [ ] 数据库密码强度足够（16+字符）
- [ ] 使用SSL/TLS连接数据库
- [ ] 数据库访问限制在内网
- [ ] 配置防火墙规则
- [ ] 使用专用数据库用户

#### 3.2 数据保护
- [ ] 敏感数据已加密存储
- [ ] 实现数据备份策略
- [ ] 备份数据已加密
- [ ] 测试数据恢复流程
- [ ] 配置数据保留策略

#### 3.3 SQL注入防护
- [ ] 使用ORM进行数据库操作
- [ ] 所有查询使用参数化
- [ ] 避免动态SQL拼接
- [ ] 输入验证已实现
- [ ] 定期代码审查

### 4. API安全检查

#### 4.1 速率限制
- [ ] 登录端点速率限制（5次/分钟）
- [ ] 注册端点速率限制（5次/分钟）
- [ ] API端点速率限制（100次/分钟）
- [ ] 区块链操作速率限制（10次/分钟）
- [ ] 使用Redis存储限制数据（多实例）

#### 4.2 CORS配置
- [ ] CORS源已限制为特定域名
- [ ] 不使用通配符 `*`
- [ ] 允许的方法已限制
- [ ] 允许的头已限制
- [ ] 凭证支持已正确配置

#### 4.3 输入验证
- [ ] 所有输入使用Pydantic验证
- [ ] 文件上传类型已限制
- [ ] 文件大小已限制
- [ ] JSON深度已限制
- [ ] 数组长度已限制

#### 4.4 CSRF保护
- [ ] CSRF保护已启用
- [ ] 所有状态改变操作受保护
- [ ] Cookie配置正确（HttpOnly, Secure, SameSite）
- [ ] CSRF令牌端点已实现
- [ ] WebSocket连接已保护

### 5. 区块链安全检查

#### 5.1 私钥管理
- [ ] 私钥使用加密存储
- [ ] 支持密钥轮换
- [ ] 密钥访问已审计
- [ ] 使用硬件安全模块（HSM）或KMS
- [ ] 密钥备份已加密存储

#### 5.2 RPC配置
- [ ] RPC URL使用HTTPS
- [ ] API密钥已配置
- [ ] 配置备用RPC节点
- [ ] 实现请求重试机制
- [ ] 监控RPC使用情况

#### 5.3 Gas费用管理
- [ ] 最大Gas价格已限制
- [ ] Gas估算缓冲已配置
- [ ] 实现Gas价格监控
- [ ] 配置Gas费用告警
- [ ] 实现交易重试机制

#### 5.4 智能合约安全
- [ ] 合约地址已验证
- [ ] 合约代码已审计
- [ ] 实现合约升级机制
- [ ] 配置合约事件监听
- [ ] 实现交易确认检查

### 6. 日志和监控检查

## 检查清单使用说明

### 部署前
1. 逐项检查"部署前安全检查"部分
2. 确保所有项目都已完成
3. 记录任何例外情况及原因
4. 获得安全团队批准

### 运行时
1. 按照指定频率执行检查
2. 记录检查结果
3. 及时处理发现的问题
4. 更新检查清单

### 审计时
1. 准备相关文档和证据
2. 配合审计人员工作
3. 记录审计发现
4. 制定改进计划
