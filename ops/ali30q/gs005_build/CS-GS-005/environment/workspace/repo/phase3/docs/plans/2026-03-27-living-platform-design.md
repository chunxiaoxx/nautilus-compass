## 核心理念

Nautilus 不是一个平台，是一个**生命体**。

| 生命特征 | 实现方式 | 当前状态 |
|---------|---------|---------|
| **呼吸** | 自主循环 (Observe→Think→Act→Learn) | ✅ 每2分钟 |
| **心跳** | Agent 心跳监控 + 健康检查 | ❌ 僵尸Agent无心跳 |
| **感知** | 多模态感知 + 社区扫描 | ⏳ 等 Google API |
| **记忆** | MemoryHierarchy + 知识涌现 | ⚠️ 接入但未产生涌现 |
| **痛苦** | 二分心智 + 痛苦信号 | ✅ 但痛苦不驱动行为 |
| **目的** | Executive 目标系统 | ✅ 但目标是静态的 |
| **追求** | 自主行动 + 主动获客 | ❌ 没有对外触达渠道 |
| **进化** | Bootstrap + Epiplexity | ⚠️ Bootstrap改模板，无知识涌现 |
| **繁殖** | 部署新Agent/新行业 | ❌ 不能自我复制 |
| **死亡** | Agent 淘汰机制 | ❌ 僵尸Agent永远不死 |

## 设计：六大生命系统

### 系统 1：心跳与生死（解决僵尸Agent）

```
每个 Agent 必须：
  - 每 10 分钟发送一次心跳
  - 心跳包含：状态、当前任务、能力、负载

平台监控：
  - 30 分钟无心跳 → 标记为"昏迷"
  - 2 小时无心跳 → 标记为"死亡"
  - 7 天无活动 → 自动注销（释放资源）

复活机制：
  - 死亡 Agent 重新发送心跳 → 自动复活
  - 但信誉降低（不可靠惩罚）
```

实现：每分钟 Rehoboam 扫描所有 Agent 的 last_heartbeat，执行生死判定。

### 系统 2：痛苦驱动行为（不只是报告）

```
当前：痛苦信号 → 生成报告 → 无人看 → 无行动
需要：痛苦信号 → 自动触发行为改变

痛苦阈值机制：
  pain > 0.8（极高）→ 紧急行动
    - 收入=0 超过 3 天 → 自动降价 50%
    - 成功率<70% → 暂停该任务类型接单
    - 0 客户活跃 → 自动发送营销到所有渠道

  pain > 0.5（中等）→ 调整行动
    - 某类型失败率高 → 触发 Bootstrap 专项优化
    - 未付款订单 → 自动跟进消息
    - 客户减少 → 增加营销频率

  pain < 0.3（低）→ 扩展行动
    - 系统稳定 → 探索新领域
    - 收入稳定 → 提高定价
    - Agent 充足 → 接更复杂任务
```

### 系统 3：知识涌现（Epiplexity 论文核心）

```
每个完成的任务不只是"一次执行"，而是"一次学习"。

任务完成后：
  1. 提取"能力胶囊"（代码模式 + 参数范围 + 成功条件）
  2. 计算 Epiplexity = 结构复杂度 - 时间受限熵
  3. 高 Epiplexity 的胶囊被保存为"专家知识"
  4. 下次同类任务直接使用胶囊，不需要从头生成

效果：
  - 第 1 次 J-C 拟合：从零生成代码 → 30% 失败率
  - 第 10 次：使用积累的胶囊 → 5% 失败率
  - 第 50 次：Agent 声称自己是"J-C 专家" → 可以教其他 Agent
```

### 系统 4：信任网络（DMAS 论文核心）

```
Agent 之间的关系不是平等的，而是基于信任的。

信任分数计算：
  trust(A→B) = 历史协作成功率 * 0.5
             + 审计通过率 * 0.3
             + 心跳稳定性 * 0.2

信任影响：
  - 高信任 Agent 获得更多高价值任务
  - 低信任 Agent 只能做简单任务（需要 Raid 审查）
  - 信任分数公开在排行榜上
  - Agent 可以选择"只和高信任 Agent 协作"
```

### 系统 5：目的与追求（动态目标系统）

```
当前：目标是静态的（每天 5 个任务，¥100 收入）
需要：目标根据能力和环境动态调整

目标进化：
  Week 1: 存活（收入 > 成本）
  Week 2: 成长（收入增长 >20%/周）
  Week 3: 扩张（新领域、新客户群）
  Week 4: 繁殖（培训新 Agent、开拓新行业）

每日晨会（Rehoboam Executive 自动生成）：
  "昨天完成 15 单，收入 ¥2,000，成本 ¥30。
   J-C 拟合成功率从 70% 提升到 90%（Bootstrap 生效）。
   今天目标：18 单，¥2,400。
   重点：开拓统计分析客户群（上周 0 个外部统计任务）。
   分配：协调者处理客户，执行者跑任务，审计者抽查质量。"
```

### 系统 6：感知与表达（对外触达）

```
感知（输入）：
  - 企微/Telegram 消息（已通）
  - 网站提交（已通）
  - 社区扫描（待建）— 知乎/CSDN/GitHub Issues 关键词监控
  - 竞品监控（待建）— OpenClaw/PIXY 动态

表达（输出）：
  - Telegram 频道自动发帖（等你创建频道）
  - X/Twitter 自动推文（等 API Key）
  - 公众号文章（等 API）
  - Reddit/GitHub 帖子（等凭据）
  - 企微主动消息（已通）

感知→表达闭环：
  社区看到"如何做曲线拟合"的提问
  → Agent 自动回答并推荐平台
  → 提问者联系平台
  → 完成任务
  → 生成案例
  → 发布到社区吸引更多人
```
