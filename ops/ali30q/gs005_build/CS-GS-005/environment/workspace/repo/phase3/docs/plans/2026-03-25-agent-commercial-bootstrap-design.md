# Agent 自主商业化 + 平台自迭代 设计

## 核心目标
1. 让平台 Agent 自主赚钱（第一块钱）
2. 平台持续自我迭代进化

## 架构
- 企业微信应用 → Nautilus 平台 → Claude API（Agent Brain）
- 三层记忆：客户档案(永久) + 对话记录(永久) + 语义记忆(向量检索)
- 多 LLM：Claude(决策) + MiniMax(执行) + Haiku(轻量)
- 先款后货：展示能力 → 报价 → 收款确认 → 执行 → 交付

## 商业流程
客户消息 → 识别客户 → 注入记忆上下文 → Claude 决策 → 动作执行 → 回复

## 实施优先级
1. Agent Brain + 记忆系统（对话/客户/订单模型）
2. 多 LLM 支持（Claude API 接入）
3. 企业微信对接（webhook 收发）
4. 订单管理（报价→收款→执行→交付）
5. Bootstrap 自迭代增强
