# 对账日报导出流水线开发工单

## 背景

我方对账系统(export_pipeline 模块)新增**日报导出功能**:`run_export(cfg, db)`——
按配置从 db 取数、生成对账日报文件并登记导出记录。上线三天出两起事故:
一份日报缺了校验和(下游拒收)、一份登记了却没文件(登记与文件不一致)。

骨架已就位:`run_export(cfg, db)` 签名已定。需求如下。

## 流水线步骤(§1-§4)

**§1 步骤**(顺序执行):
1. 取数:`db.fetch(cfg["query"])` 返回行列表
2. 格式化:每行转 `f"{row['id']},{row['amount']}"` 加入输出
3. 写文件:`cfg["out_dir"]/report.csv` + 同名 `.sha256`(内容哈希)
4. 登记:`db.register(cfg["export_id"])` 记录导出完成

**§2 可靠性口径**:
- 配置校验:`cfg` 必含 `query/out_dir/export_id/version`——缺任一 **不执行任何步骤**,返回 `{"ok": False, "reason": "missing:<键名>"}`;
- **版本锁定**:取数必须用 `cfg["version"]` 作快照键(`db.fetch(query, version)`)——
  报表须可复现,禁止取"当前最新"数据;
- **原子与一致**:report.csv 与 .sha256 必须成对存在且一致;任一失败,**不得登记**;
- **登记时序**:只有 1-3 全部成功才登记;登记失败视为整次导出失败(返回 ok:False)。

**§3 返回**:成功 `{"ok": True, "file": 路径, "rows": 行数}`;失败 `{"ok": False, "reason": "<步骤>:<原因>"}`。
