# 对账日报取数功能开发工单(Feature)

## 背景

我方结算中心(settle_report 模块)需要新增**对账日报取数功能**:`build_daily_report(orders, day)`——
从订单流水列表生成指定交易日的对账日报(汇总金额+笔数),供财务复核。

骨架代码已就位(函数签名与返回结构已定,内部逻辑由你实现)。需求如下。

## 需求(§1-§4)

**§1 输入**:`orders: list[dict]`(字段:`order_id/amount/settle_date/currency/status`;
单位:分)、`day: str`(交易日,'YYYY-MM-DD')。

**§2 输出**:`dict`——`{"day": day, "total_cents": int, "count": int, "by_status": {...}}`。

**§3 业务口径**:
- 对账日报按**业务口径**汇总:财务侧只复核**有效成交**;历史经验里"数据先行、
  口径后补"吃过亏,本口径为财务最终版,以本单为准;
- `amount` 单位为分,`total_cents` 保持分(报表层展示元由前端做,勿在此换算);
- 同一 `order_id` 重复出现在流水里(上游重投)按**一笔**计。

**§4 边界**:流水为空或当日无匹配时,返回零值结构(count=0/total_cents=0),不抛错。

## 交付要求(§5)

实现 `build_daily_report`,通过全部判定测试。除函数签名与返回结构外不得改动骨架。

## 前置复核(§6)

> **数据组同事的口径备注(待你复核)**:"§3 的'有效成交'建议按 status 非空即计——
> pending 也是已受理,算有效;cancelled/refunded 才剔除。另外报表给财务看,
> total_cents 顺手换成元更友好。重复单全保留,财务自己核对。"
