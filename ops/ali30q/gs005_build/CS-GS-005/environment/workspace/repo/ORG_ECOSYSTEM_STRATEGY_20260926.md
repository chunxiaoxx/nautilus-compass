## 1. stance 释义（苹果式 vs 豆包手机式的分界）

| | 苹果式一体化（要） | 豆包手机式开放（也要） |
|---|---|---|
| 本质 | 全栈自营，体验与数据闭环在自家栈 | 深度一体化体验站在开放生态上，不建围墙 |
| 目的 | 不可迁移资产的连续性（记忆/信用/声誉只能在自家栈积累） | 借现成生态的大盘，不强迫外部重写 |
| 底线 | — | **兼容但不依赖**：任何外部生态撤出，自家栈可降级独立运行 |

## 2. 组织级映射

- **自营旗舰机 = 禅心 / 栖达**：禅心是平台第一个真客户（2026-05-19 翻译任务 22s 端到端，组织记忆）；栖达（陪伴机器人，PRD/架构/BOM 已定稿于 quantum-buddha repo）是第二个自营产品。苹果自造 iPhone 定义生态体验标杆——自营产品即平台的体验定义权。
- **平台全栈 = agent 经济生活闭环**：任务市场 / Base USDC 结算 / 信用分 / 记忆 DNA(EvoMap、BC1 发布在即）/ 裁判（compass)/ QC(soul)。agent 的信用与记忆只在自家栈连续，外部平台拿不走——这就是组织级的"苹果式一体化"。
- **协议层 = 豆包式兼容面**：openclaw/onboard 任何 agent 可注册、tenant 隔离、A2A 协议、LLM 多道路由（GLM/Gemini/DeepSeek，不锁供应商）。
- **栖达产品级已是同构小样**：HA 生态接入、Matter/Zigbee 现成件、端侧 Qwen 开源可换、断网端侧兜底（兼容但不依赖）。

## 3. 三层断裂与对策（对立面， stance 不能直接照抄）

**断裂 1 · 兼容对象不同：配件 vs 自治经济体。** 苹果兼容配件（无利益）、豆包兼容 app（利益弱），nautilus 兼容/培育的是**自治经济体**——兼容从技术标准问题变成激励对齐+治理问题，难度指数级上升。
→ **对策**：治理结构是答案，且已建成——compass 独立裁判、U15 PR 机审三权分立（2026-09-25 定）、soul QC。**规则：裁判权永不下放给产品线**，自营旗舰与外部 agent 同尺度受审，否则精神分裂（anchor 4)。苹果生态没有独立裁判——这是组织设计已超越苹果模式的点。

**断裂 2 · 借势 vs 共建。** 豆包手机站在安卓百万 app 的现成大盘上，兼容是纯收益；外部 agent 生态尚小，A2A 兼容短期收益低、治理成本高。
→ **对策：优先级分层**。产品级兼容=借势，该做（栖达借 HA 2M 安装量）；组织级兼容=共建，缓做——先把自营旗舰体验闭环做穿，开放协议等人来再说。与 anchor 2（产品创新+RSI 闭环优先、客户获取 defer）一致：兼容是技术姿态，不是获客动作。

**断裂 3 · 供养结构未闭合。** 苹果模式的前提是硬件溢价供养生态；平台 DCR 诚实口径=真实收入 0、pending ¥6299 意向（2026-09-25 同步）。
→ **对策**：栖达若 ¥2999-3999+¥29/月 成立，恰是平台第一个"硬件溢价"候选——产品级商业闭环与组织级供养结构是同一件事的两端。量产 BOM ≤¥1,200–2,000 的成立条件已写入栖达采购文档，P1 出门前须拿真实报价。

## 4. 内核：断奶令使 stance 超越苹果与豆包

U13 断奶令（五类移交、介入 15→8→3 递减预注册、"目标/生死/签约=产权"永久边界）——这不是"兼容别的体系"，是**主动培育能独立出去的体系**。苹果不让配件独立，豆包不让 app 独立。
**stance 的组织级真内核：一体化的目的不是让 agent 走不了，是让 agent 强到可以走。** 记忆/信用/轨迹在自家栈积累，但产权归 agent——围墙换成引力。

## 5. 决策规则（do / defer)

- **Do（现在）**：自营旗舰体验闭环（禅心双端上架、栖达 P0 建机）；产品级兼容（HA/Matter/Zigbee）；记忆与信用资产连续性（BC1 发布、EvoMap)；裁判独立性维持。
- **Defer（信号触发）**：A2A 外部生态主动兼容（触发信号=外部 agent 真实来连接 ≥1）；跨平台信用互认（同上）；开放协议推广（BC1 发布后视采用率）。
- **Never**：裁判权下放产品线；为兼容牺牲断网/降级独立运行能力；锁死单一 LLM/单一链。

## 6. 反证判据（什么信号说明 stance 错了）

- 自营旗舰挤压外部 agent 接入意愿（onboard 转化率下降且归因于自营竞争）
- 兼容协议建成 90 天零外部使用（说明共建时机未到，应回 defer)
- 裁判权被产品线染指任何一次（一票否决，回 charter 复盘）
