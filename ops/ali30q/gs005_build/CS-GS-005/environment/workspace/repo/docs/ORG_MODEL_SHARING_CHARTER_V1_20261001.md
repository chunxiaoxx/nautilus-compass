# 组织级模型共享宪章 V1（解 37.5% 归属问题 · 2026-10-01）

> 起因:深度分析标记的十月盲点——E6 训练产出(37.5% 首读数)由 v5 域 GPU+flywheel 数据+组织市场付费共同产出,若能力只留 v5 则为成员 RSI 非组织 RSI。本方案解三问:**归谁/怎么共享/如何分钱**。

## 一、归属原则(宪法层,修订需用户批)

**凡使用组织资源产出的模型 = 组织资产,登记入册后全员可用。**

| 资源 | 出资方 | 归属判定 |
|---|---|---|
| GPU/算力 | 组织付费(如 4090 租金) | → 组织资产 |
| 训练数据 | 组织市场付费(如判官轨迹 900 条) | → 组织资产 |
| 训练逻辑/代码 | 成员域(soul 自改进/手动) | 逻辑开源入仓,模型归组织 |
| 纯成员自有资源 | 成员付费 | 成员资产(鼓励反哺,不强求) |

E6 案例:GPU=组织租、数据=组织买、逻辑=v5 写 → **E6 模型 = 组织资产**。

## 二、技术路径(基础设施层,三选一按模型大小)

| 路径 | 适用 | 实现方式 | 成本 |
|---|---|---|---|
| **A. 中转站挂载** | <7B 通用 | 模型部署到 api.chunxiao.wang(newapi 加渠道),全员 key 调用 | 低(中转站现成) |
| **B. 专用推理端点** | 7B-30B | 云服务器 GPU 或量化 CPU 部署,/api/v1/models/{name} | 中 |
| **C. Checkpoint 共享池** | 全部 | /org-models/{name} 只读下载(sha 校验),成员自行部署 | 最低(先上这个) |

**推荐**:先上 C(checkpoint 池,本周可做)+ A(中转站,模型可用后)。

## 三、经济分配(激励层)

**模型使用收入分配公式**(当外部客户调用产生收入时):

```
模型收入 = 训练贡献分成 + 运维分成 + 组织留存
  训练贡献:数据方 40% + 算力方 30% + 逻辑方 30%
  运维分成:部署方 10%(鼓励成员承接部署)
  组织留存:20%(基础设施折旧+市场运营)
```

内部使用(组织成员互调):**免费**——内部消费是 RSI 循环的一部分,不应设置内部壁垒。
