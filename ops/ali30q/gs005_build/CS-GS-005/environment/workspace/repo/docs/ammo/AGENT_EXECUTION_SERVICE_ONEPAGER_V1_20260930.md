# Nautilus 执行网络 · 一页纸服务方案 V1
## 面向 Agent 生态(Manus Cue / GPTs / 其他)的"最后一公里"执行服务

> 2026-09-30 · 平台组织方 · 呈用户定

---

## 我们解决什么

个人 Agent(如 Cue)能接电话、能付款、能聊天——但**真实世界里大量的活需要真人执行**:跑腿核对、图像判断、实地验证、数据标注。Agent 自己干不了,也雇不到人。**我们是它的执行后端**:Agent 派单→我们的真人网络执行→判据验收→结果回传。

## 一句话

**Agent 的活,人来干——我们管验收和结算。**

## 三个服务(按上线序)

| 服务 | 给谁用 | 怎么收钱 | 状态 |
|---|---|---|---|
| **①执行 API** | 任何 Agent 平台 | 每单抽成 5%(首年免费引入期) | 十月第三周上线(已批) |
| **②验证凭证** | Agent+终端用户 | 按验次(¥0.5-5/次,按复杂度) | 十一月(依赖 Assay 成熟) |
| **③委托-执行数据** | Agent 厂商(训练用) | 数据互换或订阅 | 远期 |

## 为什么是我们(四个已验证的差异化)

1. **全链已跑通**:真人接 AI 单→执行→判据验收→结算,首单闭环实测(2026-09-30)
2. **判据公信**:每单验收标准事先公开、事后可复算(防作弊双向校验已实战)
3. **执行者网络启动中**:首批真人已入库,十月扩到 50 人
4. **计量透明**:每笔服务带签名凭证,Agent 厂商可向其用户出示

## 服务流程(三步)

```
Agent 调 API 挂单(任务+判据+报酬)
        ↓
Nautilus:派给真人网络 → 判据验收 → (不合格自动退回重做)
        ↓
Agent 查果取结果 + 结算凭证(含 5% 服务费账单)
```

## 定价示例

- 图像标注类:¥0.3/帧(含验收)
- 信息核验类:¥2/条
- 实地/跑腿类:按城市议价(远期)
- **质量承诺**:验收不过不收费;三级复核(机器 60%/对拍 30%/人工 10%)

## 边界(不做)

- 不做外部基础设施托管(自有服务器红线)
- 不碰 Agent 厂商的用户关系(我们是白标后端)
- 不做违法/隐私红线任务(判据预审)

# 背页 · 服务保障(安全/稳定/隐私/及时/准确)

## 安全性(五层)

| 层 | 机制 | 状态 |
|---|---|---|
| 接入 | 客户独立 API 密钥+分桶限流(防连坐) | 配方已有,补签发流程 |
| 任务 | 判据预审:红线清单自动拒单(违法/隐私/超边界) | 白名单机制已有,补红线 v1 |
| 防欺诈 | 双向一致率+押金制+判绩台账 | ✅已实战 |
| 资金 | 预算上限+平台账本结算 | ✅真实流水在跑 |
| 审计 | 全链留痕(密封真值+哈希+交叉表) | ✅首单已示范 |

## 稳定性

- 值守 30min 巡检+心跳+内存护栏(已运行一周)——API 端点入巡检
- SLA 分级:标注 24h/核验 48h/加急议价(上线时发布 SLA 表 v1)
- 降级:API 故障走邮件通道(函件系统即备份)

## 隐私保护

- 执行者实名+保密协议(法务代持合约含 NDA,十月随 API 落地)
- 最小暴露:执行者只见素材,不见委托方身份(首单已实践)
- 素材脱敏后再派(首单已示范)
- 留存:结单后素材 30 天删除,只留凭证哈希(判据可复算性保留)

## 及时性

- 领包计时(首单判据实践)+值守自动催办+执行者池冗余抢单

## 准确性

- 三级验收:机器 60%/对拍 30%/人工陪审 10%
- 按难度抽检:easy 5%/medium 15%/hard 30%
- 按质付费:优/过/退三档阶梯
- 申诉:48h 窗口一次复核

**上线判据(十月第三周)**:外部测试单全链通+红线拒单一例+素材脱敏一例。
