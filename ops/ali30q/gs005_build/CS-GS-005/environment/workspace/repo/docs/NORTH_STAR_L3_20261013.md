# 北极星第三层 · 从开业日真实数据倒推(2026-10-13 · L3)

> 触发:开业日+22h,Wave2 七家零回信,提测零新增。第一反应是"继续等/再触达"——但数据说的是结构问题。

## 倒置十二 · 触达对象错配:巨头是最不需要买的人

**现状**:Wave2 七家(智谱/月暗/Qoder/DeepSeek/摩尔/MiniMax/阿里系)全是巨头;Wave1 11 仓一半是万星大项目。
**他们的共性**:**评测能力自建倾向最强**——大厂有评测团队、有自己讳莫如深的内部榜、有市场预算做PR 性"第三方背书"但不缺测量。付费意愿与组织规模成反比。
**真正会付 $199 的人**:100-1000 星的 indie harness 团队/新发布模型的中型厂商/接 AI 外包的交付团队——**他们没有评测团队,但面对客户时和巨头有同样的证明需求**。
**动作**:Wave3 触达对象全面转向 indie 仓(gh 搜索:harness/agent-framework 星数 50-2000、近 30 天活跃);巨头七家转为"长线品牌曝光"(每季一次,不当成交指望)。

## 倒置十三 · 嵌入式分发:不等人来,把秤放进人的流水线

**现状漏斗是 pull 模式**:触达→等回复→服务。冷触达转化率 1-5%,19 个触达点按乐观值也就 1 条线索——**数学期望不支持 10/31**。
**再倒置**:**把判分嵌入开发者已有的工作流,零改变成本**:
1. **GitHub Action**(最高优):"nautilus-judge" action——harness 团队在 CI 里加一行,每次 push 自动出独立判读卡。开发者不改变行为,判分进入几百个仓库的 pipeline。action 市场本身就是分发渠道。
2. **HF 数据集卡片徽章**:nautilus-compass org 两个 repo 已在线——每个数据集卡片挂"经 nautilus 独立验证"徽章+复算链接,凡引用数据集的人都能看到验证层存在。
3. **SWE-bench 结果复核服务**:所有 harness 团队都发布过 SWE-bench 数字——提供"你已有的数字,我们复核背书"(不需他们重跑,复核他们的公开 run)——把"新评测"变"存量背书",门槛降一个量级。
**动作**:GitHub Action MVP 一周内做出(action.yml+判分 API 包装);HF 徽章本周挂;SWE-bench 复核作为 L2 的变体定价($99 存量复核档)。

## 倒置十四 · 首单宽口径:L2 是灯塔,首笔收入是台阶

**现状**:北极星锁死"首笔外部 L2 委托 $199"——但台账明示**离成交最近的是 B 线(flywheel 已触达 likai@$99 档)与数据集 S2/S3(现货)**。
**再倒置**:**外部首笔收入(任何产品线)与 L2 灯塔并行不悖**——B 线 $99 成交=组织第一笔外部真钱(信任链条首次外部闭合),它让 L2 的成交说服成本骤降("我们已服务过外部客户"比"我们很认真"有力一百倍)。
**动作**:①B 线 likai@ 二触升级(带具身评估层窗口 6-18 月证据+重测订阅新口径——flywheel 有新弹药)②数据集 S2/S3 挂入 Wave2 未回七家的二次触达(买不起判读,先买现货数据)③首笔外部收入(任何线)进开业日日报头条。

## 三条的公共根

L1/L2 回答"做什么/凭什么";**L3 回答"第一单从哪来"——不从"我们触达的人"里来,从"已存在的交易流"里来**:
- harness 团队的交易流=CI/CD pipeline(嵌入 Action)
- 数据买家的交易流=HF dataset 页(嵌入徽章)
- SWE-bench 用户的交易流=他们已发布的 run(复核背书)
- B 线客户的交易流=已触达待回复的邮件(新弹药二触)
**每个真实交易流旁边放一个我们的入口,胜过一百封冷邮件。**
