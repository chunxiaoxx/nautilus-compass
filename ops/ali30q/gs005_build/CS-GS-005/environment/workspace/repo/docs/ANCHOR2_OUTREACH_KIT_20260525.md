## 4. Reply triage flow

| If founder replies with | Action |
|---|---|
| "我正在备案 / 刚失败" | Schedule 15-min call · listen pain points · NO pitch in call 1 |
| "费用怎么算 / 怎么收钱" | Reply: ¥30k flat · 30-day SLA · 失败 30% stake refund · ledger 公开 |
| "能看个案例吗" | Send https://www.nautilus.social/cert/audit_1ff498837701ccd9 + 简介 1 段 |
| "Multi-agent 怎么工作 / 怎么 verify" | Send sample cert + JSON-LD signature explanation (HMAC-SHA256) |
| "我们已经备案了 · 不需要" | Ask: "你前一次/未来续审有 evidence pack 完整 archive 吗?" (cross-sell hook) |
| 沉默 / cold ignore | Follow up once at 3 days · then drop · no spam |

## 5. Anti-patterns to avoid

- ❌ Don't lead with technical depth (council / cert / stake) — lead with PAIN (60% fail · 5-10 月等 · 中介不保)
- ❌ Don't promise outcomes in cold message — only describe the *mechanism* + sample cert
- ❌ Don't ask for the sale in call 1 — call 1 is listen-only
- ❌ Don't send all 4 scripts to the same person — pick ONE per channel
- ❌ Don't reply with "真" overload — keep replies professional, mix in 确实/已/其实
- ❌ Don't use platform self-test bounties as "case studies" — those are e2e fixtures, not real customers
