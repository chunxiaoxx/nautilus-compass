### v2.0 的技术与运营口径

- **采集协议层**回答“采什么、怎样形成训练数据”：EGO 用于覆盖第一视角的场景、任务语义与人类工作流程；UMI 用于覆盖更接近机器人末端的观察、位姿/相对动作与夹爪状态。两者可单独或组合写入客户任务书。
- **供给与运营层**回答“在哪里采、谁采、怎样控质和扩量”：协同基地、分布式众包、垂直现场均可承载 EGO 或 UMI；“垂直现场”不是第三种采集技术。
- **当前资源**：协同基地是当前的项目启动资源。国曙组织人员，负责项目运营、质量闭环和最终交付；合作方提供基地支持、指导培训与派单协同。
- **证据门槛后的路径**：分布式众包、垂直行业在岗采集，以及 Agent 自动引导、预标注、自动验收均须在 POC 已固化金样本、授权规则、可复现任务包和结算口径后逐项开启。
- **共同买方闭环**：世界模型与本体/策略团队对同一数据包关注点不同：前者需要环境、时序与任务先验，后者需要接近动作接口的操作示范与机器人验证。两者都依赖“真实任务—合格 episode—训练/验证”的共同闭环。

## 3. 研究与行业来源

### S01 — NVIDIA EgoScale（官方研究页）

- URL: https://research.nvidia.com/labs/gear/egoscale/
- 日期：2026-02-19
- 可用结论：在其特定实验中，超过 2 万小时带动作标签的第一视角人类视频预训练，再配合少量人机对齐数据，可显著提升灵巧操作表现；该结果支持“人类第一视角经验是可扩展数据源”的研究方向。
- 边界：不能推导为任意第一视角视频都有效，也不能推导为国曙数据已产生模型提升；需要任务标签、动作结构和人机对齐。

### S15 — EgoMimic（官方项目页）

- URL: https://ego-mimic.github.io/
- 可用结论：公开研究以 Aria 眼镜、3D 手部跟踪、SLAM 和机器人数据对齐来研究跨具身模仿，说明从人类第一视角到机器人执行之间需要显式对齐。
- 边界：该项目是研究路线，不代表国曙已部署相同设备、算法或模型效果；PPT 只能据此说明 EGO 的适用范围与对齐限制。

### S16 — UMI: Universal Manipulation Interface（官方项目页）

- URL: https://umi-gripper.github.io/
- 可用结论：公开路线使用带相机的手持平行夹爪，并结合末端邻近视觉、IMU/SLAM、夹爪状态与相对动作表示来记录操作示范。
- 边界：这是 UMI 技术路线的外部参考，不是国曙当前自有设备或既有交付能力；不表述为跨本体零适配迁移。

### S02 — Shift Terms（官方）

- URL: https://www.joinshift.us/terms
- 可用结论：平台把采集、切分、标注、审核和付款连接起来；参与者为独立承包人；使用头戴或批准设备；按质量与验收条件接受提交；仅对通过验收的提交结算；明确权限、敏感场景和知识产权安排。
- 借鉴：众包必须以任务协议、合规边界、验收和结算闭环为核心。
- 边界：Shift 的执行规模与商业表现未被独立核验。
