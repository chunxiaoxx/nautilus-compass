### 三种用法的实用化程度
1. **合成数据生成:半实用**。DreamGen 标杆:1 任务遥操种子→11h 生成 78 万条合成轨迹(≈6500h),GR00T N1.5 学会 22 个新行为;但全部需要**真机种子+真机评估闭环**,纯合成未证成。
2. **策略评估(world-model-as-a-judge):最热新方向**。驾驶域已进生产(GAIA-3/Tesla);操作域 benchmark 混战,学界告诫"世界模型尚不能忠实还原物理交互"。
3. **Model-based RL/规划:规划最接近实用**(V-JEPA 2 零样本抓放),世界模型内大规模 RL 仍 demo 级。

### 真机 vs 仿真 vs 世界模型:关键数字与判断
- 缺口:2026 初全球高质量真机交互数据仅 **~50 万小时**,共识需求千万小时级,缺口>99%。
- 反方:Stanford AI Index 2026——仿真操控成功率 89.4% → 真实家庭 **12%**(manipulation 的 sim-to-real 未解)。
- Sergey Levine:"仿真/人类视频是 spork(叉勺),真机数据不可替代"。
- 市场信号:光轮智能 2026 Q1 订单 5.5 亿(超 2025 全年);**失败数据溢价 1.5×**;非本体数据定价 = 真机的 1/3-1/2;真机行情 500-1000 元/h(与国曙 PPT 报价互证)。

### 对数采生意的五条含义(agent 判断,置信度标注)
1. 世界模型 1-2 年内**做大**数采市场(放大器需要高质量输入)——高置信
2. 品类分化:通用轨迹被压价;**失败/接触密集数据、世界模型后训练数据、评估用 ground-truth 真机 rollout 三类溢价上升**——中高置信
3. 天花板风险在 3 年+尺度(盯 Cosmos WAM 客户真机用量 / 1X-Tesla 真合配比)——中置信
4. **"数据+评估"捆绑是最稳升级路径**(买单点从生成移向可信评估,评估永远需要真机 ground truth 校准)——高置信
5. 世界模型公司本身是真机数据的新买方(要的 spec 不同:多视角/物理接触/失败样本/精确动作标注)——中高置信

## §3 数采方案与玩家全景(调研 agent B)

### 技术路线×成本×产能
| 路线 | 代表 | 成本 | 产能/质量 |
|---|---|---|---|
| 主从臂遥操作 | ALOHA 2(~$15-20k/套)、GELLO(<$5k) | 高 | 10-30 条/h,ACT 成功率比 VR 数据高 ~20%,质量之王 |
| VR 遥操作 | Open-TeleVision(Vision Pro ~$3.5k / Quest 3 ~$500) | 中 | 10-25 条/h,可远程,精度低于主从 |
| 外骨骼 | 智元 A2、傅利叶 | 最高 | 5-15 条/h,全身、retarget 损失小 |
| 手持数采(UMI 类) | UMI(~$500)、FastUMI-100K | 最低 | 20-60 条/h,**同等成功率有时需 >5× episode**,缺物理接地 |
| 第一视角人类视频 | Apple EgoDex(829h)、Meta Aria、NVIDIA EgoScale(2 万 h) | 低 | **1h Aria ≈ 1h 遥操作的策略贡献**(同款眼镜消除视觉域差);log-linear scaling |
| 仿真合成 | Isaac(GR00T:真机仅 88h + 仿真 78 万条)、Genesis | 边际≈0 | manipulation 落地率低(89.4%→12%) |
| 真机部署回流 | AgiBot LWD、Figure、Tesla | 前期重 | 2026 趋势:policy-assisted teleop 人力降 5-10× |

关键口径:中国真机遥操作有效数据成本 **500 元+/h**;操作员疲劳→质量衰减是公认痛点;**单任务 500-1000 条 demo 后边际价值锐减**;LeRobot 格式(Parquet+video)成事实标准。

### 数据集基准

### 中国生态

- **国地中心(上海)**:全国首个异构训练场(单机日 500+ 条),7 个互联基地,2026 推 2.0;**北京人形中心**:RoboMIND + 万㎡ 中试厂。
- **帕西尼**:5 座超级数采工厂(触觉见长)。**数据堂**(8000㎡ 工厂,拟报北交所,2025 扣非净利 4979 万)、**海天瑞声**(2025 营收 3.77 亿 +59%)。**京东**:"60 万采集大军"计划(在岗员工+UMI 背包)目标两年 1000 万小时。

### 海外生态

### QC 做法与痛点(与我方最相关)
- 合格判定:episode 级成败标签 + 帧级执行质量;过滤依据:延迟 ≥300ms 判无效/传感器伪影/操作员失误;**过滤最差 10-20% demo 稳定提升策略性能**(ICLR 2025:DROID 76k→36k)。
- **实时质控是新前沿**:episode 级 DQA(采完即反馈,arXiv 2605.26349)、influence-based curation——**2026 年才出论文,无成熟商用**。
- 中国痛点实录:"一周采集大半是废数据""缺实时质控""标准化治理难"。

### 门槛与缝隙(agent 判断)
1. **QC/验证是最大缝隙,采集本身不是**(高置信)——采集已"劳动密集+资本堆量",废品率+质控缺失是公开痛点,自动 DQA 无商用。
2. 买方付费已证实且愿外包(XDOF 出道即 20 客户);纯采集将像语音标注一样价格战(高置信)。
3. **格式/标准窗口 12-24 个月**:异构数据治理成 LeRobot/国标 + 过 YD/T 6770 测试(中置信)。
4. egocentric 人类视频是成本结构颠覆点,轻资产"可穿戴+动作标签管线"可能胜过重资产训练场(中置信)。
5. 仿真真机双押共识下,"仿真数据的真机校验/物理有效性验证"(类 VISTA)玩家少、技术含量高(高置信)。

## §7 业务流程 SOP 与堵点痛点(gap-filler agent 补齐;原 agent F 挂死已终止)

**"有效数据"判定的现状(2026-07 实录)**:
- 漏斗实况:"采 100 小时,筛下来只有 50 小时有效"(**有效率 ~50%**);质检"依赖人工,很多都是手搓"。

- 已有的结构化标准(可直接复用进我方裁判器):**学术四维协议**(成功率二元/平滑度=关节角速度方差/安全性=碰撞/效率,Eval-Actions 基准)+ **RoboMIND 7 类失败模式**(抓取不完整/握持不足/关键帧错位/旋转错误/动作顺序错/目标物错等)。
- 但**合同级验收条款范本不存在**——"有效"由谁判、怎么判、判错谁担,行业无答案。

**职业化现状(P2 产品的政策地基,全部坐实)**:

## §8 一整套商业模式(核心 = 市场真需求 → 可实现的解决方案 → 我们的飞轮怎么闭环转动)

### 8.1 市场真需求(全部有两路以上证据交叉,非叙事)

|---|---|---|

| N2 | **废品率是买卖双方最大的钱坑** | "一周采集大半废数据";过滤最差 10-20% demo 能提升策略性能(ICLR 2025);国曙自认日人产仅 3-4h 有效 |

### 8.2 我们的解决方案(只做能力射程内的,不碰硬件/劳务/仿真引擎)

**定位一句话:做具身数据的"独立裁判 + 采集员认证"层**——三方生态(仿真派光轮/人力派国曙/平台派觅蜂)都需要、都不做、都替代不了的夹层。

**产品线(按启动难度排)**:
1. **P1 · 数据验收裁判服务**(对 N2/N3):可复现的 episode 级 QC 管线(成败判定/延迟/平滑度/多样性/格式合规),交付「验收报告+废品清单+按质计价单」。计价从"元/小时"改写成**"元/合格小时"**。= FDE 裁判链(checklist_scorer + canonical verify + 幂等门)换域,技术复用度最高。
2. **P2 · 采集员认证培训**(对 N4):招募→培训→考核→持证上岗→按质分级工资的全套体系,卖给人力派(国曙类)和平台派(觅蜂类加盟基地)。= fde.nautilus.social 培训链 + 飞书 S1-S3 派活-QC-结算引擎换内容,已 LIVE 的资产直接复用。**政策地基已坐实**:挂靠《人工智能训练师》国家职业标准(2021)/《生成式 AI 系统应用员》(2025),学员证书补贴 1100-3250 元/人(上海另有数据标注专项 1000 元)——培训成本可由政府补贴对冲;院校"订单班"位置尚无人占。
3. **P3 · 质量评测/标准服务**(对 N5/N6):对齐 YD/T 6770 出「数据集质量评测报告」,对标国曙卖 8-50 万/套的 Benchmark 业务;远期给世界模型厂供"评估用 ground-truth 校准集"规格定义。学光轮:开源一个免费质量审计工具当获客漏斗 + 以方法论挤进地方/团体标准。

**明确不做**:自建数采工厂(重资产,人力派已卷)、硬件(觅蜂 MEgo 已卡位)、仿真引擎(光轮+NVIDIA 已卡位)、纯劳务差价(觅蜂原话:利润不在劳务佣金)。

### 8.3 飞轮闭环设计(每圈都有外部验证信号,不自嗨)

**第一圈(最薄闭环,walking skeleton,2-4 周量级)**:
拿公开数据集(AgiBot World / DROID 子集)建 QC 管线 → 产出一份**可复现的《废品率审计报告》**(开源,列每条被判废的证据)→ 以此为弹药接触 1 家人力派或平台派 → **首单付费验收 = 外部验证信号 #1**。不买任何硬件,零边际成本启动。

**飞轮主循环**:
```
更多数据过裁判 → 错判/边界案例回流 → 裁判规则库+评测集变强(资产累积)
      ↑                                            ↓
买卖双方都用我们的尺子(网络效应) ← 验收报告被买方采纳为付款依据
```
- **数据侧自强化**:每一批被审的数据都在喂肥规则库——裁判越判越准,和 FDE"难题→验证→变强"是同一个环的换域。
- **人才侧自强化**:持证采集员产出合格率数据回流认证标准 → 认证含金量上升 → 人力派更愿送人来考。
- **与中心环(北极星)的关系**:QC 轨迹判定 = "难题+验证器"形态,天然是 FDE 燃料新域;income 记账/verdict 门直接复用平台账本——**不是开新战线,是给已闭环的飞轮换更大的市场**。

**每圈的外部验证信号(收敛判据,防剧场化)**:①首单付费 ②验收报告被写进买卖合同作付款依据 ③认证证书被第二家雇主认可 ④标准文件引用我们的方法。四个信号出现任一 = 该圈闭合;连续两圈无信号 = 诚实复盘方向。

### 8.4 风险与对冲
- **世界模型压价通用轨迹** → 我们卖裁判不卖轨迹,数据越被质疑裁判越值钱(反脆弱)。
- **平台派自建 QC**(觅蜂 MEgo Engine 已含评估) → 防线 = 独立第三方身份(买方不信卖方自检,同一逻辑全行业成立)+ 先发规则库。
- **我们无行业信誉冷启动难** → 开源审计报告打样(光轮 YCB 模式),用可复现性说话。
- **三脊柱纪律**:此线按 7/15 战略结论"另起干净地基 + Day1 带三脊柱",不继承老平台债。
