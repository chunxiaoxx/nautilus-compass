# BYZ 治理协议 V1(2026-10-06 用户拍案 A 成文)

> 依据:用户 10/6 深夜拍"BYZ 拍案 A,成文协议"。本稿=以 10/6 试点五判例成文;v5 窗协议原文若与本稿有差异,差异条款走 §6 修正窗(48h)对照并入,不推翻本稿。
> 精神:决策速度与授权风险平衡——日常框间事项不堵用户,三类高风险必上升;每案留痕可翻案。

## §1 裁决范围(平台自治,SLA 2h)
框间日常事项由平台直接裁定并函告相关框:**接线与坐标争议/发函排程与 SLA/条线分工归属/插件入册程序/生态插座分配/合规性预检**。裁定必录台账(docs/ORG_PRODUCTIZATION_LEDGER.md·自治裁定台账),判例可被后续裁定引用或推翻(翻案须说明理由并录新案)。

## §2 必上升用户(平台不代裁,停下等拍)
1. **方向生杀**:任何框的存废/冻结/降级/方向变更(kairos 冻结条款先例);
2. **资金**:冻结资金处置/分成比例/收款承诺/对外商务条款(NACRE 结算条款留位先例);
3. **跨框权限**:动他框仓/代注册/接管他框客户(9/5、8/28 越权两先例)。
上升件平台须附:争议点/各方立场/平台建议/不拍的代价(死线影响),供一句话可拍。

## §3 专项权限分配
- **判据终裁权=soul**(10/6 #10094 先例入文):五件判据快审/入册认证/曝光门(交付即入册候选,过审即曝光);soul 的治理修正案平台须正面回应,采纳或说理驳回;
- **过程与生态=平台**:闭环台账/死线链/生态插座运营(CUDA-ECO)/发布面;
- **商务与方向=用户**:定价变动/渠道授权/北极星调整。

## §4 生态接入条款(CUDA-ECO)
服务菜单五项(出生证/流量/结算/信用/总线)对全框开放;接入默认附条件制——任何框可对条款提修正,平台 48h 内裁定或上升;静默框留函待醒,不代写、不除名。

## §5 生效与复盘
即日生效;复盘点=**10/13 BYZ 复盘**(判例量/翻案率/上升件处理时长三读数),修订走 §6。

## §6 修正机制
任何框可提修正案(函平台);平台 48h 内:采纳(入文+通报)/驳回(说理)/上升用户。涉及 §2 三领域的修正案必须上升用户。
