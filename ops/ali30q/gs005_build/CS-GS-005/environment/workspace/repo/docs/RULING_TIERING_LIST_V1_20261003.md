# 裁决分级清单 V1(2026-10-03 试行)

> 依据:ORG_CHARTER_V1_20260926 第十三条(裁决层级:用户裁/平台裁/框自裁)。
> 目的:把用户裁决带宽留给真正只有用户能裁的件;可下放的按层自裁+登记 rulings 留痕。
> 试行 7 天(至 2026-10-10),各框异议期内可提异议;无异议转正。用户一票可上收任何自裁权。

## 一、用户裁(不可下放)

| 类 | 例(当前实例) |
|---|---|
| 花钱与额度 | GitHub Team 升级(≈$4/user/月)、预授权池(¥200)外支出、算力采购 |
| 产权 | GitHub 机器账号建立、org 资产归属、v7 白名单、deploy key 组织策略开关 |
| 对外承诺与外发 | 触客收件人与发送、判官招募稿批发、公开发布、跨组织协议签署 |
| 方向生杀 | 主线变更、框增删、宪法修订 |
| 法币/代币互换 | NAU↔USDC↔法币通道参数 |

## 二、平台裁(操作层自裁,登记 rulings,kind=platform_ruling)

| 类 | 例(当前实例) |
|---|---|
| 判据豁免的**登记形式**(sha 锚定/豁免窗口/登记格式)与时点后移 | M1③ 签名 push 豁免(B 案:工具链修复前以公钥指纹锚定过渡) |
| 技术选型与端点契约(含跨框判分接口契约,判据语义除外) | writeback items[].id 契约、鉴权门宽限期(48h)、auto_judge_dispatch 类接口格式 |
| 部署窗口与运维 | ff-only 拉取、restart 时机、回滚 |
| 协调裁决(操作面) | A2A 纠纷中不涉产权/承诺的部分、材料坐标登记与对表 |
| 格式门与卫生 | registry 合并审、sites-enabled 卫生、死域名清理 |
| 结算口径(NAU 计量纪律,不涉法币) | 自产自销双轨制(2026-10-04:工程价值照实记+燃料计量走四验门) |

**边界澄清(v1.1 · 2026-10-04 · 承 compass #2725 建议,只许更严方向)**:判据实质的裁度权(阈值/宽松化/追溯边界)依宪法第十三条①**恒归用户裁**,平台裁仅覆盖豁免的登记形式与时点,不可覆盖判据实质。

## 三、框自裁

框内工作序与节奏、框内资源分配、不影响他框与主线的提交与值守节奏、框内文档结构。

## 四、运行规则

1. 呈批前自问:本件落在哪层?属平台裁的,裁决后登记 rulings(trace=platform_ruling:*)再执行,不呈用户。
2. 分级有争议→自动升一层裁。用户对任何平台裁/框自裁件可一票推翻(登记 interventions)。
3. 每周报两数:呈用户件数(应递减)、平台自裁件数+rulings 登记数。
4. 修订:只许更严(收紧自放权不许扩张),扩张须用户明批。
