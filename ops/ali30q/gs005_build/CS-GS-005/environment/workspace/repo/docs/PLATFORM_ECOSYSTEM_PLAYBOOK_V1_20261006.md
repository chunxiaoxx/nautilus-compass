# 平台生态运营手册 V1 · "CUDA 生态"锚(2026-10-06 用户拍)

> 用户令:引导各对话框收敛闭环及时交付;各框应在**平台基础设施上**建设生态体系;平台对话框**主动引导提供服务;平台=英伟达 CUDA 生态**。
> 定位升格:平台不止过程管理者=**生态底座运营者**。本手册=运营口径正本,与白皮书 §2(五插座+插件三纪律)互为表里,不新建系统。

## 1. 类比映射(Why CUDA)

| CUDA 生态 | 平台生态 |
|---|---|
| CUDA toolkit/驱动/运行时 | 平台底盘五插座:信箱总线 A2A/sinks 入册/五件判据上架门/结算计量/发布面 |
| ISV 与开发者(在 CUDA 上写应用) | 各框(v5/compass/flywheel/zenmind/soul…)以插件形态长在插座上 |
| 开发者计划/Inception(免费 SDK+流量+背书) | 平台服务菜单(§2) |
| GTC 发布会 | 10/12 榜单发布+开业 |
| "买 GPU 送开发者,开发者多→GPU 更好卖"双边飞轮 | 涡轮增压:框产出→入池判读→榜单/数据资产增厚→流量与信用反哺各框获客 |

核心洞察:CUDA 赢在**让开发者在上面赚钱/出名比别处容易**。平台同理——各框挂平台插座的收益必须>单干(曝光/结算/信用三收益),生态才有向心力。

## 2. 生态服务菜单(平台主动提供,不另建,全部现物)

1. **出生证**:sinks 入册+五件判据核验=组织资产认证(不入册不算数)。
2. **流量**:榜单 CTA 导流/晨报段位(≤5 行心跳+交付曝光)/发布面(nautilus.social+HF+社区)。
3. **结算**:判分-结算绑定/NAU 台账/交叉销售通道(L2 客户购 S2 八折式)。
4. **信用**:判据 sha 预注册+不可写面判读背书——挂平台判读体系的产出=可审计中立。
5. **总线**:A2A/信箱/判分 API/assay CLI(PyPI 3.3.0)——接入即用,配方见台账坐标。

## 3. 运营纪律(平台侧,主动引导≠代做)

- **主动引导**:平台逐框送"接入菜单+接入配方",回函 SLA 2h;静默框(zenmind/soul)留函待醒,不代写。
- **交付即接入(soul 修正案 #10094 已采纳,10/6)**:任何交付物自动获得**入册候选**;**过审(soul 五件判据快审)即曝光**(晨报/榜单 CTA)——治理门前置:交付即入册,过审即曝光,顺序不可倒置。
- **阴阳双防线不变**:平台承载+信用不利己(阴),各框生长不离阴(阳);平台不接管框客户(f 9/22 边界)。
- **读数**:生态健康=台账跨框交换笔数+入册数+榜单/晨报曝光转化(周报披露)。
