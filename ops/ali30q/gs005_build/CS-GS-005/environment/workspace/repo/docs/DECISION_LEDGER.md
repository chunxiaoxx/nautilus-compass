# 决策分级授权 v1(试点 · 2026-08-28 用户确认开始 · 期 2 周)

> 授权的前提是可审计:每个 B 级决策落账本文件,周报回看。
> 分级轴 = **信息和后果在谁那里**(非操作类型):同一动作后果外溢时自动升级。

## A 级 · 必须用户拍(信息独占 or 后果不可逆)

1. 信息只有用户有:附件包/甲方关系/预算/算力采购
2. 后果用户担且难逆:对外承诺、花钱、北极星改写、红线事项
3. **首次实弹类**:任何新机制的第一次真实执行(如 ZERO→派单 P1)
4. 跨框资源争端的最终裁决(如发动机 vs 实验——8/28 发动机优先即此类)

## B 级 · 框自决 + 事后报备(落本台账)

- 优先级排序/挂起恢复/排期调整(框内、可逆)
- 白名单内运维(重启指定 unit/跑只读脚本)
- 跨框例行函件:催办/回执/通报/例行广播(非承诺性)
- 监督响应:dry-run 级自动动作、判据内的观察期处置

**保险丝**:B 级决策引发三曲线下跌或跨框异议 → 自动升 A 级复盘,同类一周内不再自决。

## C 级 · 框自决不留痕

纯运维细节(loop 频率/文件位置/临时目录)
