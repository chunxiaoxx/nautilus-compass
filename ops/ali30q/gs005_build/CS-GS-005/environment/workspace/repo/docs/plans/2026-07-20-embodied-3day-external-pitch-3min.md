# 3分钟对外讲稿（外部页同源）

## 开场 20 秒（先讲问题，再讲结果）
客户当前最大困境是：
- 题目与口径不一致，拿到结果还要再验一遍；
- 失败样本处理没有标准，质量不稳定；
- 一次试图全量扩量，反馈链条长、风险高。

我们今天给你一个可复用的可持续闭环：
- 1 个样板先打通 A/B/C/D/E（题面-场景-仿真-交互-真实轨迹先验）；
- 同一份 JSON 同时喂对内和对外；
- 用失败样本做下轮规则修订。

## 核心结果 40 秒
- pilot: `pilot_day3_core_v1`
- pass@5 = `5/5`
- 重复一致性 = `100%`
- E-D 一致率 = `96%`
- 平均耗时约 `48.7s` / run

这说明我们不是“讲概念”，而是“可复现”。

## 核心能力 40 秒（不讲模型术语）
- **统一口径**：pass@5 就是 5 次重跑里有多少次合格，不是一次偶然成绩。
- **失败可复用**：`薛美雪_001` 属于高价值失败案例，已进入规则修订池。
- **同源双端口**：内部看细节，外部看指标，底层字段一致。

## 演示流程 45 秒
1. 切“对外版本”；展示 A/B/C/D/E 一页。
2. 走“题库燃料”交互表，点开一条高频问题。
3. 展示 Paris 生成式导览地图（JSON 改动后重生路径）。
4. 展示“小世界模型”交互：起点终点 + 障碍复杂度 => 生成路径 + 风险分。

## 你要的行动承诺 35 秒
- 本周只保留 1 个 pilot，不新增样板，先稳定指标。
- 下周扩到 3 个样板线，只在重复一致性和 E-D 一致率稳定后扩。
- 对齐双方口径：失败样本进入回流池、不得以单次成功代替稳定。
