## 二、三层路由规则(试行·阿里任务内,10/26 后固化)

- **信箱**=正式事:交付/验收/拍板/对外承诺(留痕)
- **A2A**=快事:执行指令/进度/告警(小时级)
- **市场**=活和钱:工序/状态/结算
- 同一事只走一层,双发违规;指令须带工单号

## 三、长期维护机制(今日建立)

1. **v7 读数岗扩"渠道健康"**:每轮读数加一行渠道态(信箱/A2A/市场/中转站/A100/TG 六项✅❌),❌ 即函平台
2. **额度断供识别**:各框静默>1h,先查 LLM 网关调用记录(429/额度错)再定性,禁判"埋头干活"(10/24 误判教训)
3. **活性双源实测**:文件时间戳+进程双源,每轮实测不得凭旧观测(21265 误判教训)
4. **共享设施值班表**:中转站/A100 待 hr/flywheel 指认值班框——候用户拍
5. **知识传递**:甲方验收标准类信息,24h 内合成 checklist 全网分发(13 门表模式),不走零散函件
