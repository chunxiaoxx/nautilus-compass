## 一、商业模式 v3(以销定产 · 双通道 + 一条自有品类)

### 1.1 两个已对接方的正确用法(先想清楚再谈)
| 对接方 | 它是什么 | 我们的切法 |
|---|---|---|
| **智元** | 最大买方之一 + **觅蜂母公司**(自有数采工厂+Genie Studio) | 不要直接卖"通用遥操数据"给它(和它自己的工厂竞争)。正确入口 = **觅蜂"蜂巢共创"加盟基地**:领 MEgo 设备与标准,做它的委托产能;我们的差异化 = **全网合格率最高的基地**(内部裁判链预检,交付一次过) → 结算快、返工少、拿高档单价 |
| **灵心巧手** | 灵巧手厂商(dexterous hand) | **联合产品:灵巧手操作数据包**——它出硬件(手),我们出采集运营+QC,共同卖给模型厂/它的客户。灵巧手+触觉是最高溢价品类(行情 1500-3000 元/h,触觉数据全行业稀缺,帕西尼刚起量),且买它手的客户天然需要配套数据 = 它有动力推 |

### 1.2 收入结构(三条腿,按现金流先后排)
1. **培训认证(最快回款,第 1-2 个月可启动)**:人社部《人工智能训练师》证书体系 + 政府补贴 1100-3250 元/人;招"采集员培训班"——学员付费低/补贴覆盖,毕业即进我们基地或输送给同行。**这条腿同时解决自己基地的人员供给**。
2. **数采交付(主营,第 2-4 个月起量)**:蜂巢加盟单(标准化产能)+ 灵巧手数据包(自有高毛利品类)。计价按"合格小时",内部裁判链保证合格率 = 毛利来源(行业有效率仅 ~50%,我们每提 10pp 合格率等于白赚 10% 产能)。
3. **QC/验收服务(资产化,第 4 个月后)**:裁判规则库+评测集独立输出——给其他基地做验收、给买方做第三方审计。轨 B 品牌,防止焊死在单一渠道。

### 1.3 不做清单(减法)
不自研硬件(买 ARX/MEgo/灵心巧手)、不做仿真引擎(光轮卡位)、不接纯劳务外包单(价格战)、不先建大基地(招商书阶段以销定产)。

## 二、分阶段路线(每阶段有外部验证信号,不达标不进下一阶)

### Phase 0 · 样板间(第 1-6 周,预算 ≤¥15 万)
**目标:一个工位产出一份"客户验过货"的样板数据包。**
- 硬件:国产双臂标准工位一套(ARX L5×2 + 主从 + 3 相机 + 工作站 ≈ ¥10-13 万);若走蜂巢则申领 MEgo 设备替代部分自购。
- 人:用户(BD/统筹)+ 采集员 2 人(先招熟人/兼职,日薪 200-250 元行情)+ AI 侧出全部软件。
- 软件(本框交付,复用已有资产):采集→LeRobot v3 格式→**QC 裁判 v0**(四维协议+7 类失败模式 checklist,自动预检+人工复核)→飞书 ERP(派活/质检/结算,FDE S1-S3 引擎换内容)。
- **验证信号:智元/觅蜂或灵心巧手对样板包出具书面反馈(合格率/单价/量的意向)。拿不到 = 回炉,不建基地。**

### Phase 1 · 首基地(第 7-16 周,以签约量定投资)
- 触发条件:Phase 0 拿到意向量(如 ≥500 小时/月)。
- 选址:县域(人力 150-200 元/天,政府场地/就业补贴——用你的政府资源);规模 = 订单量 ÷(3-4h 有效/人/天 × 目标合格率),**先 20-50 人,不超**。
- 培训班先行:开班→持证→上岗,补贴申报同步走;培训毕业考核 = 上岗认证(考核数据直接喂裁判规则库)。
- **验证信号:首月按"合格小时"全额结算无纠纷;基地毛利为正。**

### Phase 2 · 复制与资产化(第 4 个月后)
- 基地复制(国曙五步法框架:政府对接→招募培训→设备部署→试运行→投产,5-8 周/个);
- 灵巧手数据包成标准 SKU;裁判规则库对外输出(轨 B);
- **验证信号:第二基地不靠创始人驻场也能达标 = SOP 真的成立。**

## 三、运营 SOP 骨架(每环节:产出物 + 验收标准 + 负责角色)

| # | 环节 | 产出物 | 验收标准 | 谁 |
|---|---|---|---|---|
| 1 | 需求定义 | 任务规格书(任务 ontology/本体/传感器/格式/量/单价) | 客户签字 | 用户+AI 侧起草 |
| 2 | 场景搭建 | 场地+道具+机位+标定记录 | 标定误差入档;场景清单对齐规格书 | 运营 |
| 3 | 招募培训 | 持证采集员 | 培训考核通过(考核数据过裁判 ≥ 阈值) | 运营+培训系统 |
| 4 | 采集执行 | 原始轨迹 | 实时预检:延迟<300ms、无多余动作、无遮挡 | 采集员+QC 端 |
| 5 | 质检 | 合格数据集+废品清单 | 四维协议(成功/平滑/安全/效率)+7 类失败模式;抽检复核一致率 ≥95% | 裁判链+质检员 |
| 6 | 标注 | 语言指令+子任务分段 | 与轨迹逐帧对齐,VLM 预标+人审 | 标注员 |
| 7 | 交付 | LeRobot v3 / 客户格式 + 验收报告 | 客户侧复现通过;按合格小时开票 | AI 侧+用户 |
| 8 | 回流 | 错判/边界案例入规则库;采集员合格率入人才档案 | 每批次规则库有增量 | 裁判链自动 |

人力结构参照行业:采集 80-85% / 质检 8-12% / 管理 4-8%;质检大半自动化后,质检人力比可压到 5% 以下 = 结构性成本优势。

## 四、软硬件集成架构(AI 侧承建,全部有现成件)

```
[采集端] 双臂工位(ARX+LeRobot 栈)/ MEgo 穿戴 / 灵心巧手工位
    ↓ 本地缓存+断点续传
[数据湖] LeRobotDataset v3(Parquet+视频)· Rerun 可视化
    ↓
[QC 裁判] 自动预检(规则)→ 自动评分(四维)→ 人工抽检 → verdict 落库
    ↓                                   ↘ 错判回流规则库
[标注] VLM 预标 + 人审(Encord 流程参照,自建轻量版)
    ↓
[交付+结算] 验收报告 + 飞书 ERP(派活/质检/结算/学员档案 = FDE S1-S3 引擎换内容)
```
- 全栈开源可用:LeRobot/OpenTeleVision/Rerun/MuJoCo(标定验证);裁判 verdict 结构直接沿用 fde_verdicts 范式。
- 三脊柱 Day1 生效:单一 repo 单一 main、部署纪律、物理删除纪律——不重演老平台的 4 平行世界。

## 六、风险与对冲(只列真的)
1. **智元/觅蜂条款压价+数据产权归平台**(蜂巢模式议价权在它)→ 对冲:灵巧手自有品类 + 轨 B 独立规则库,不做纯代工。
2. **价格战已开打**(2026H2,基础采集单价下探)→ 对冲:只做"合格小时"和高溢价品类,不接底价单。
3. **招商书→实体的执行风险**(团队/场地/资金从零)→ 对冲:Phase 0 只花 ≤15 万验证,以销定产,验证信号不达标不加码。
4. **世界模型长期压真机需求** → 3 年+尺度;且"预训练几乎全用真实数据"是当前业内共识;裁判/评估反而受益。

## 八、五目无感穿戴数采设备(用户愿景 · 硬件路线图 · Phase 2+)

用户 7/17 提出的自有设备方向:**五目视觉采集 + 无感穿戴形态**(头戴 + 吊坠 + 手环,做成装饰品级无感,面向垂直行业);**UWB 无线抗干扰通讯**;**自标注 + 自适应**;**一次采集、多设备/多本体通用**(cross-embodiment)。

- **行业坐标**:与光轮 EgoSuite(VR/眼镜/外骨骼)、觅蜂 MEgo View(7 摄头戴)、Meta Aria、鹿明 FastUMI Ego 同赛道,但"吊坠+手环+装饰品级无感"形态与 UWB 方案在公开调研中**未见先例**——垂直行业(餐饮/护理/零售在岗员工)无感采集是差异化空间,与京东"在岗员工采集"路线互证需求真实。
- **技术依据**:egocentric 人类视频已证 1h ≈ 1h 遥操作的策略贡献(Aria);自标注方向有 EgoScale 动作标注管线可参照;跨本体通用对应 LeRobot/RLDS 格式层 + retargeting 研究(RDT2 等)。
- **执行定位**:**Phase 2+ 路线图项,不进 Phase 0/1 预算**。路径 = 先用现成设备(MEgo/Quest/自建 UMI)验证数据管线与买方需求,同时做设备定义文档(传感器清单/UWB 组网/标定方案/BOM 目标价),找 ODM/硬件合作方落地,不自建电子研发团队。
- 下一步(AI 侧):设备定义文档 v0 进 backlog,待 Phase 0 样板包验证后启动。
