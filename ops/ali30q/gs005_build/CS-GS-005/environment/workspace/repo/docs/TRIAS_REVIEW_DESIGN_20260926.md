# 评审权三权分立 · 设计正本 v1(2026-09-26)

> 用户 9/25 中秋夜定方向;两框意见合成:compass #1056(评委团+三档表)+ v5 #1032(判分接口契约)。呈批版随判分日呈用户;本文=工程正本。

## 一、三权

- **提案权**:soul(及一切自迭代 agent)。出厂三重门(编译/测试/路径黑名单)挡废品,不做判决。
- **判决权**:机审一期(已建 pr_review.py,今晚部署窗挂 timer)→ 评委团二期(W42 接 v5 判分链)。判决权与提案权分离:soul 出席自己的评审(当事人回避,compass 案)。
- **终批权**:用户(宪章档专属;方向/生死/对外签约=永久产权)。

## 二、三档机械判定(compass 表,机审已对齐)

| 档 | 机械判定 | 判决路径 |
|---|---|---|
| 操作 | ≤1 文件 ∧ ≤50 行 ∧ 三重门全绿 ∧ 无行为变更嫌疑 | 机审直通 |
| 政策 | 2-5 文件或 50-400 行;**判据/门禁/鉴权类改动不论行数升档** | 评委团 3 席 2/3 |
| 宪章 | 安全部件/红线域/协议正本/付费通道;≥400 行或 >5 文件 | 呈用户终批 |

机审产 GREEN/POLICY+GREEN → W42 起送评委团;机审只亮牌不合不关(安全锚:draft PR 永不自动合并,改锚=用户批件)。

## 三、评委团(compass 案)

- 轮值非常设:六框席位池,政策案抽 3;当事人回避。
- 票权:初始等权;判绩滚动加权(Assay Ledger 最近 30 案,前 25% 权 1.5/中位 1.0/后 25% 权 0.5);**首 30 案=观察期等权**(加权生效回看点)。
- 平票:platform 主持人无票权、有僵局优先建议权;仍分歧=升宪章档呈用户。
- compass 定位:裁判供给方,入席但涉 Assay 判绩复核案回避。

## 四、判分接口(v5 案,复用不另立)

- 承接件:exam3arm 三门判分器 / jumpc 坐标制判分器 / 校准回放(机器 vs 人工 89%)。
- 契约:输入{pr_id, repo, base_commit, claim} → 输出{evidence_gate, readback, verdict, blind};工单走 fde_dispatch;判分资产四文件纪律。
- **盲字母密封**(platform 承接):PR 号→盲字母映射平台侧密封,防判自己框带立场;首批密封件随部署窗后落。
- Rule of Two 判分会话隔离照 Muse W6(断网禁写生产)。

## 五、判绩账(Assay Ledger 双向)

评委判准率 + 提案者声明可信度("语义不变"声明须 diff 锚行自证,声明不实入账)——评委与提案者双向压力。
