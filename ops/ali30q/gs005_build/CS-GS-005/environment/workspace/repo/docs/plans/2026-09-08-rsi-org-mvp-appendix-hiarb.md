## 一、两版对照(合并后的完整答案)

| 问题 | 合并答案 |
|---|---|
| 高维空间能当什么 | **门卫**(预筛,毫秒/近零边际)+ **异构第二法官**(嵌入源与生产不同构时,误差与生成式判官不同源,互相照亮盲区)+ **判官体检仪**(Δ 元仲裁) |
| 高维空间不能当什么 | **唯一法官**:盲区定理(判别空间与错误空间同构→正交方向结构性失明,实证边界 0.1%-1%,跨判官家族一致) |
| 换的本质 | 摊销(论文 3 的 R):预付维度和能量,在线变单次前向——**预付不是免付,校准环是固定成本** |
| 盲区对策 | 盲区换形不消失:嵌入版本异构+定期轮换+多投影随机化;残余交符号层/终审层 |

## 二、三层异构仲裁栈(MVP 的 verdict 体系定位)

| 层 | 机制 | 成本 | 组织内实例 |
|---|---|---|---|
| L0 摊销层 | 嵌入距离/线性探针/Δ | 毫秒 | 矿队列检索打分(规则版→BGE 升级候选) |
| L1 符号异构层 | 程序化 ground truth | 秒-分钟 | pytest 机械 verdict+RED 预检+test_tamper 守卫 |
| L2 外部真值层 | 人/客户/预注册仪器 | 贵 | holdout+置换检验+三道闸 |

**对 MVP 草案的三个直接影响:**

1. **风险表补第五条**:若 L2 纵向记忆的检索升级为 BGE 嵌入版,需按"盲区换形"设计——判分嵌入与生产嵌入**版本异构**,否则同构盲区(9/8 凌晨 L2 初步实证 B=C<A 已经是相似度空间无判别力的一次例证)
2. **晋升判据的读法**:skill_registry 晋升门(复用计数)是 L1 层符号判据,不要被"语义相似度"替换——语义相似是 L0,当不了晋升法官
3. **判据 3(经济)的叙事背书**:验证业务卖的是 L1/L2(接地验证),L0 人人都有且人手一份盲区——论文 2 恰好论证了 L0 不构成护城河

## 三、Δ 元仲裁(论文 2 的潜在第四贡献,也是组织的工具)

Δ 在部署前预测判官盲区(9.7+/5.3/2.3 → 放行 0%/45%/13%)。组织用法:**每季给自家判官做 Δ 体检**——g2b1 判官(pytest)的盲区(测试本身写错)与 LLM 判官的盲区(数值精度)位置不同,Δ 体检报告=三层栈的维护清单。

## 四、待头脑风暴裁决的两问

1. MVP 的 L0 层要不要现在就建(嵌入指纹库),还是等判据 1(纵向读数)先出?——平台倾向:等。理由:L2 初步实证显示相似度空间对修复正确性无判别力,L0 的价值位在数据池审计(flywheel X1-lite 主场),不在修复管道
2. 2×2 实验(判官类型×同构性,flywheel 版设计)要不要列为组织级实验候选?——若做,L2 的三臂 harness 可直接复用为其中一臂
