## 二、四闸门(每题顺序过,不过不进下环)

1. **供给闸**(供给线出口):真素材挂靠+V3 结构+语境达标 → 进判分队列
2. **判分闸**(判分线出口):五模型×4 轮完整+五模型均值<70+opus≥1 次全 1+qwen 25-50 带+区分度≥20pp → 进校准
3. **校准闸**(S3 出口):蒙对≤0.30/等价≥0.90/缺陷逐条一致 → 进打包
4. **打包闸**(S2 出口):21 门机械脚本预检+证据包(答卷/读数/日志/矩阵)+追溯矩阵行 → 呈用户

## 三、机制协同(平台职责,今天实战验证的)

- **排产台账日更**:每题一行坐标(当前环/卡点/ETA),loop 每轮对台账推进,阻塞即协调不等人报
- **回执制+点名制**:各框 ETA 一句话回执,未回点名(回执率入台账)
- **广播制**:甲方反馈/机制变更全员同步(今天两例实操)
- **批量错峰**:判分按批 4-5 题,渠道分桶,云 load>50 自动降速(值守轮监控)
- **不凑数红线**:四闸全过几件交几件,未过如实报返修——质量红线优先于周五数量
