## 3) 闭环价值映射：问题->训练/治理动作
| 问题模式 | 对指标影响 | 直接动作 | 产能意义 |
|---|---|---|---|
| 附件口径错乱 | 降低一次通过率，增加复训成本 | 出题前加“附件校验脚本” | 降低回修率 |
| 步骤模板化（AI痕迹） | 审核评分偏低、复跑不稳定 | 重写提示词为任务语气模板 | 提升自然表达命中率 |
| 产物字段重复编号 | 格式一致但语义弱 | 引入字段 schema 与强约束解码 | 降低抽检失败 |
| 证据链缺失 | 人工复核加权失败 | 引入“引用行号必须存在”规则 | 提升可复验能力 |
| 术语口径冲突（销售/人力） | 合作方理解偏差 | domain 标准化 + 同源字典 | 减少沟通成本 |

## 4) 11题价值判断（可复用）
- 前 3 优先：AI痕迹、附件一致性、产物字段命名。

- 后 4 项：格式统一性、章节层级、风格统一、可视化说明。
