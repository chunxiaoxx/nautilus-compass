# pilot_day3_core_v1 · 3 天单样板闭环

版本:2026-07-21  
原则:只允许 1 个样板任务,先完成 3 天闭环再扩量。

## 一句话
这条样板不是证明我们已经能大规模交付,而是证明我们可以把一次业务任务拆成可复跑、可审计、可回流的闭环。

## 样板 ID
- `pilot_task_id`: `pilot_day3_core_v1`
- 策略:单样板冻结,不扩量
- 目标:打通 A/B/C/D/E 五视图

## 五视图
| 视图 | 含义 | 对客户怎么讲 |
|---|---|---|
| A 语义 | 题面、目标、边界、禁忌动作 | 先把需求说清楚 |
| B 场景 | 对象、环境、初始条件、扰动 | 把任务放进具体场景 |
| C 模拟 | 仿真参数、baseline、gap log | 先在低成本环境里验 |
| D 交互 | 控制链路、回放、时延、动作结果 | 证明能跑通一次 |
| E 真实轨迹先验 | Ego video/本体轨迹摘要、关键帧对齐 | 用现实轨迹校准模拟和交互 |

## 当前结果
| 指标 | 数值 | 解释 |
|---|---:|---|
| pass@5 | 5/5 | 同一样板 5 次重跑全部通过 |
| repeat consistency | 100% | 同一规则下复跑一致 |
| E-D match | 96% | 真实轨迹先验与交互回放对齐度 |
| failure top3 | 空 | 当前样板未暴露主失败类 |

## 已暴露的反例
`薛美雪_001` 在 doubao pass@5 = 0/5。失败不是坏事,它证明这套机制不是只报好结果。该样本进入失败回放池,用于规则修订和蒸馏。

## 演示口径
1. 一条样板先打穿,不一次性承诺全量稳定。
2. 失败是训练资源,不是需要隐藏的瑕疵。
3. 内外展示同源:对外看效果,对内看失败细节,底层字段一致。

## 下一步门槛
- 客户给真实 spec。
- 样板包给对方验货并获得书面反馈。
- 反馈通过后才进入 1→3 扩量;未通过则回炉规则和 SOP。
