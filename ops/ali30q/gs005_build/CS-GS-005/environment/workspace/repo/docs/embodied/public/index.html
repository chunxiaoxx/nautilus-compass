一条训练闭环,两条采集线

EGO / FIRST-PERSON EGO:采集真实世界的任务经验
  • 第一视角视频、时间戳、场景/物体状态、任务/步骤语义。
  • 适合世界模型、环境时序、任务先验与长流程经验。
  • 边界:EGO 记录人类经验,不自动等于机器人可执行动作。
UMI / END-EFFECTOR UMI:采集更接近机器人动作接口的示范
  • 末端邻近视觉、夹爪状态、位姿/相对动作、对象状态。
  • 适合本体策略、动作示范与机器人验证。
  • 边界:设备选型、标定和本体适配必须写入 POC 任务书。

双数据集同一结论:卡脖子的不是采集质量(44%/98%),是验收基础设施——判据、标签、合同。成功判据没写清,数据再多也结不了账。这正是验收条款的价值——我们把判据、抽检比例(κ≥0.8 一致性)、复检仲裁机制作为合同标准件提供。审计报告与判定程序可提供复跑,同输入同输出。

裁判规则(episode 级,全自动预检 + 人工抽检)

规则判什么
R1 时长过短/过长轨迹(误触、挂机)
R2 丢帧时间戳间隔异常(采集设备故障)
R3 停滞连续静止(操作中断/发呆)
R4 平滑度动作抖动/变形(jerk 分布校准:最差 10% 复核、最差 1% 判废)
R5 成败标签任务成败标注缺失或失败(不可结算)
R6 关节越限超出安全工作空间
R7 夹爪活动全程无操作(疑似空采)

判定协议对齐学术四维标准(成功/平滑/安全/效率)与主流失败模式分类;阈值按客户 spec 校准。

条款项标准写法

      
        
合格判定episode 级 7 条确定性规则(见上),阈值按 spec 双方确认后冻结入附件;同输入同输出

返工闭环不合格批次归因到失败模式,针对性返工后重新过裁判;返工成本我方承担

        
报告交付机器可读验收报告随批交付,口径对齐 YD/T 6770-2026《具身智能基准测试方法》

生产 SOP:八个环节,每环有"交什么、怎么验"

  

    

      
#环节产出物验收标准

      
        
1需求定义任务规格书(任务/本体/传感器/格式/量/单价)客户签字

        
2场景搭建场地+道具+机位+标定记录标定误差入档,场景对齐规格书

        
3招募培训持证采集员考核数据过裁判 ≥ 阈值(考核即认证)

        
4采集执行原始轨迹实时预检:延迟<300ms、无多余动作、无遮挡

        
5质检合格数据集+废品清单(每条附证据)四维协议+失败模式分类;抽检一致率 κ≥0.8

        
6标注语言指令+子任务分段与轨迹逐帧对齐;预标+人审

        
7交付LeRobot v3 / 客户格式 + 验收报告客户侧复现通过;按合格小时开票

        
8回流错判案例入规则库;人员合格率入档案每批次规则库有增量(越判越准)

      
    

  


  
培训认证:人从哪来,证谁买单

  

    
职业标准与证书
对接人社部《人工智能训练师》国家职业标准(五级体系);培训 5 天带考核,考核数据本身过裁判 = 考核即认证;毕业进基地上岗或输送合作方。

    
政府补贴(公开标准)
证书补贴按等级:五级 1000 / 四级 1500 / 三级 2400 / 二级 3000 / 一级 3600 元(广东口径;上海三级 2500,在校生按 80%)。多地纳入紧缺工种目录,另可抵个税。补贴可覆盖学员大部分培训成本。

    
为什么这对贵方重要
行业现状是 3 天速成上岗、劳务中介层层转包 —— 动作一致性差是废品率高的根源之一。持证+带考核的人员产线,是合格率承诺的地基。

  


  
高溢价品类:别人的废品,我们的 SKU

  

    
失败样本包
裁判判废的每条轨迹都带失败模式标签(7 类归因)—— 正是世界模型训练需要的失败数据,行业溢价 ~1.5×,头部厂商已专门开源失败交互数据集验证了这一需求。

    
评估用 ground-truth 校准集
行业共识"评估必须真机"(数字孪生无法完全复现真实物理)。按贵方评测协议定制采集+判定的校准集,规格可谈。

    
数据来源验证(provenance)
合成数据管线全面开源化后,"这条轨迹是真机采的吗"成为新问题。我们的判定规则可扩展做真采/合成鉴别,保护贵方数据资产的可信度。
