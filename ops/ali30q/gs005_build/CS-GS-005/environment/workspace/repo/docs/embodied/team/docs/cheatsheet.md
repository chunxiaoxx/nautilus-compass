# 讲解速记卡(2026-07-22 · 配 /embodied/public/ 使用)

## 一句话
行业买数据按小时付钱,但一半是废品、"什么算合格"没人能判——我们把判定做成可复跑的程序,按「合格小时」收钱。

## 三个数字
- **~50%** 行业有效率(买 100 小时一半能用)→ 开场砸痛点
- **0 条** 两个公开数据集按严格结算口径可结算数(pusht 0/206 差一线;aloha 0/50 无标签列)→ 痛点实证
- **4-10×** 成本(50-250 元/h)→售价(500-1000+)毛利差 → 生意为什么成立

## 三个故事(每个 30 秒)
1. **差一线全归零**:pusht 判据 0.95,最好 0.94 → 判据没写清 = 颗粒无收 → 验收条款值钱。
2. **连标签都没有**:aloha 真机数据集无成败标注列 → 行业缺验收基础设施 → 我们卖的就是这个。
3. **裁判错了能改**(7/17 真事):规则把单次快动作当抖动全判废 → 改"持续抖动指数 p95"复跑验证上线 → 错判回流规则库 = 飞轮;敢当客户面讲,因为透明可复跑。

## 脚本
- 30 秒:痛点(50%)→ 裁判(可复跑/对赌/仲裁)→ 实证(两数据集 0 条可结算 = 空白本身)。
- 3 分钟:生成式面板破冰 → 审计表讲故事①② → 三项服务 → 承诺四条。
- 10 分钟:+让客户玩裁判模拟(50%→95%=产能翻倍)+ 亲手采一条被判一次(全场记忆点)+ 速算器出方案框架 → "给规格书,4-6 周样板包"。

## 追问五答
- 有基地吗?→ 样板间模式以销定产;重资产采集场普遍不盈利,我们反着来;不要求预付产能承诺。
- 凭什么你判的算?→ 确定性程序+合同阈值+κ≥0.8 抽检+复跑仲裁。**您不需要信我们,只需要能复跑。**
- 价格?→ 按品类公开行情(无本体~灵巧手 300-3000 元/合格小时);精确报价以规格书为准。
- 仿真替代?→ 预训练共识用真实数据;合成越多、验真需求越大,裁判反而受益(反脆弱)。
- 产权?→ 合同显式约定,支持独家;允许二次授权则出交易所挂牌口径的质量评估报告。

## 15 分钟自学
①玩两个 DEMO 各 2 分钟(故意抖被判废一次)②生成式面板选"模型厂/训练场"各生成读完 ③背三数字三故事 ④录 30 秒电梯版听回放。
对外只需 partner 一页 + 本卡;内部九页是参谋部,不必全掌握。

## 新增: 冷启动怎么讲(30 秒)
- 我们不会先建一个大基地等订单，而是先选“任务 001”：一个 10–60 秒、成功失败可判、三天能交付的小任务。
- Day 1 冻结判据并试采；Day 2 采金样本、边界样本、失败样本；Day 3 交数据包和 QC 报告，只要书面反馈。
- 世界模型团队先用 EGO 采任务上下文；本体/灵巧手团队先用 UMI 或对方本体采动作；平台方优先兼容其既有设备。
- 现场话术: “先用一包能验货的数据证明交付，再讨论设备、基地和规模。”

## 新增:3 天单样板怎么讲(30 秒)
- 这不是规模化成绩,只是一条样板链路的闭环证据:同一条业务样本,从题面/场景/模拟/交互/真实轨迹先验五个视图走完。
- 当前指标: `pilot_day3_core_v1` pass@5 = 5/5、repeat = 100%、E-D 轨迹一致率 = 96%。
- 它证明的是"我们有办法把一次成功和一次失败都变成可复盘数据",不是承诺现在已经能复制 100 个基地。
- 现场话术:先小样板验货,客户给书面反馈,再谈基地和量。

## 新增:Paris HTML demo 怎么讲(30 秒)
- 这个 demo 不是游戏客户端,也不是视频世界模型;它展示的是 **LLM 实时生成 HTML/CSS/JS 交互页面**。
- 为什么放巴黎?因为客户容易理解:输入偏好 → 页面生成路线、地图点、行程卡片、预算提示。
- 为什么跟我们有关?同一技术可换成"基地参观导览页"和"审计报告动态页":后端只给真实 verdict JSON,模型负责排版与交互,不编数据。
- 红线:对外说"演示",不说已接入生产;要上线 LLM 版,API key 必须放后端,不能放前端。

## 现场推荐演示顺序(8-12 分钟)
1. 外发页首屏:输入客户类型,生成专属方案页。
2. QC 合格率模拟:把滑杆从行业均值拉到 SOP 化,讲"同样的人,废品率下降就是毛利"。
3. 采集沙盘:故意抖一次,讲"错判/误判能回流规则库"。
4. 3 天证据包:只讲一条样板,不扩张叙事。
5. Paris HTML demo:说明生成式页面如何变成参观导览/审计报告。
6. 需求速算器:把客户规格收回来,落到下一步"给 spec,做样板包"。

## 共建方追问:五个"凭什么"(机制级速答)

共享底答:**行业靠人治(老师傅/手搓质检/口头标准),人治不可复制不可累积;我们把它变成程序和数据——程序部署即复制,数据判过即沉淀,反馈当天到人。**

1. **上手快**:学员每条练习轨迹立即过裁判逐条归因(即时反馈>练习时长);沙盘=零成本预练场,上真设备前先被判一百次;考核即认证。验证:Phase 0 记录入职→稳定过裁判天数 vs 行业 3 天/50%。
2. **留存高**:行业流失四因逐个拆——直雇(中介 20% 差价一半变工资)/当日反馈不白干/底薪+有效小时奖金(合格率=员工收入)/轮换+晋升+证书带得走;县域劳动力池结构红利。验证:月流失率自立基线(行业无量化=敢量化即差异化)。
3. **高标准**:spec 前置冻结进合同 → 实时预检拦在当刻(行业空白)→ 甲方可复跑终检 → 返工归因。核心:消灭"两把尺子",双方用同一把且可复跑仲裁。验证:首单一次性通过率。
4. **1-10 复制**:判定=代码(零漂移)、培训=课程+沙盘+考核程序(教官不必是老师傅)、运营=SOP+飞书 ERP(另一业务线已生产运行);基地长从"发明打法"降为"执行 SOP"。验证:Phase 2 门=第二基地免驻场达标。
5. **飞轮**:verdict 带证据、规则改动带版本 = 回流有介质;三条回流线(错判→规则库/考核→课程/抽检→阈值);**7/17 已实转两圈**(pusht 阈值 confound 修正、沙盘 R4 误判修正,git 可查);四外部信号防自嗨。

压舱话术:"这五条今天是设计推理+行业证据,不是实绩——所以试单做小、验收门写死。您不需要信这五条,只需要看第一个门出不出数。"
