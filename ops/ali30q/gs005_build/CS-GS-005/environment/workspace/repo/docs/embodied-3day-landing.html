常见问题（先把术语降噪）

为什么要把“内部”和“外部”拆开？

避免展示页的管理信息与对外展示内容混在一起，保证安全边界和对外表达一致。

世界模型演示放什么内容？

先放“可解释的生成 + 可复跑的复核”两件事：路径导览页与失败回放判断，避免只讲模型能力不落地。

目前怎么避免废品多？

按 episode 级规则先验，按合格/失败模式打分，争议都可复跑复验，不合格不计账。

3 天闭环演示能证明什么？

证明流程链可跑通：任务接收、产出、QC、回流、复训和演示汇报不是孤立 demo。
