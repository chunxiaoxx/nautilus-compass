# 组织免疫登记表(教训-强制位正本)v0.1 · 2026-09-22

> 纪律(用户拍板 9/22):**文档不会自动成为肌肉。任何教训,必须在五类强制位之一落位才算"结案";找不到位的明示"当前无肌肉",走接线收敛审查决定造不造位。禁"写进文档=以为防了"。**
> 本表=索引,不是肌肉本身。肌肉状态三档:肌肉(系统自动)/半肌肉(检查点在,触发靠自觉)/纸面。

## 五类强制位(组织只存在这五种"自动触发位")

| 位 | 类型 | 例 |
|---|---|---|
| 1 每日对账读数 | 沉默类(存量/资产/差距) | frame_snapshot 水位/探活/判读 |
| 2 请求时校验门 | 流程类(准入/承诺/身份) | schema 门/工单承诺清单/key 绑定 |
| 3 每 prompt hook | 认知类 | drift_check/先读后答契约 |
| 4 判分验收判据 | 质量类 | evidence 必附/RED_OK/回放一致率 |
| 5 SLA/timer | 时限类 | E4/E5/轻巡检/48h 默认同意 |

## 入册流程(每次复盘必过)

1. 新教训提炼一行
2. 找位:五类强制位之一能否落?
3. 落位 → 登记表加行(位/落位处/验证方式/状态)
4. 无位 → 明示"当前无肌肉";造位走接线收敛审查(先盘存量,禁新建冲动)
5. 状态迁移:纸面→半→肌肉,迁移时改本表并留时间戳

- 变更随 commit;每日对账不重读本表(它不是读数源,是索引)
- 复盘流程引用本表为强制步骤(判读口诀已挂指针)
