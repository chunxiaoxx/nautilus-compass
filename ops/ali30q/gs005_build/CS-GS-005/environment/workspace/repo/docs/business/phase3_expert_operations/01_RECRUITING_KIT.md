# 第三期专家招募工具包（对外）

> 版本：2026-07-24  
> 使用边界：第三期统一对外口径（不得新增价格或付款变体）

## 0. 一页对外说明（可直接发给渠道/群）

- 招募主题：第三期垂域高难度题目  
- 统一结算：`200 元 / 题`  
- 结算触发：客户验收通过 + 结果回流完成  
- 结算时效：`3` 个工作日  
- 交互门槛：`6+` 轮  
- 关键识别：预审通过 ≠ 验收通过  

## 1. 对外流程（可直接复用）

```mermaid
flowchart LR
  曝光 --> 报名 --> 预审 --> 入口下发 --> 交互["6+轮交互"] --> 回填 --> 验收 --> 结算
  预审 -->|不通过| 补齐["发标准补齐清单后重提"]
  补齐 --> 预审
```

## 2. 外部话术（建议直接复制）

### 2.2 首条私聊模板
```mermaid
flowchart LR
  模板[统一模板提交\n背景/约束/验收标准]
  核对{预审是否通过}
  模板 --> 核对
  核对 -->|通过| 续办[推进续办]
  核对 -->|不通过| 补齐清单[标准补齐清单]
  续办 --> 交互["在任务内完成 6+轮交互"]
```

### 2.3 固定回复（禁止改写）

| 问题 | 标准回复 |
|---|---|
| 预审和验收一样吗？ | 预审只决定可不可以进交互，不等于验收通过。 |
| 能先拿款吗？ | 不行。结算必须在验收通过后且按流程走 3 个工作日。 |
| 6+轮可以跳吗？ | 不能。必须保留 6+ 轮交互与记录。 |
| 可否替提交人代交互？ | 不可，提交与交互以本人身份执行。 |

## 3. 外部最小采集项

1. 姓名 / 豆包 UID  
2. 题目背景与目标  
3. 时间约束、权限边界  
4. 验收标准（成功条件 + 失败条件）  
5. 是否含敏感依赖  

**禁采信息**：身份证、银行卡、验证码、账号口令  

## 4. 外部状态看板文案

```mermaid
flowchart LR
  待预审 --> 可交互 --> 复核中 --> 客户验收 --> 结算中 --> 已结算
```

- 待预审：待初筛和资料完整性确认  
- 可交互：续办入口已下发  
- 复核中：交互与结果待对齐  
- 已结算：付款完成，流程关闭
