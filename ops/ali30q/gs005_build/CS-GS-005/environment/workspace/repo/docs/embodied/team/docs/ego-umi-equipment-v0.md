# EGO/UMI 设备采购与组装清单 v0

版本: 2026-07-23
目标: 用最小、可复现的设备组合，在三天内完成任务 001。先验证“交付是否能被客户验收”，再决定是否采购本体、遥操工位或定制五目设备。

## 一、采购原则

- **设备跟任务走**: 没有任务规格书，不采购大件本体。
- **先双线**: EGO 记录人、环境与任务上下文；UMI 记录接近末端执行器的动作线索。二者时间同步、同一任务 ID。
- **先稳定再精密**: 能连续录 1–2 小时、可导出、可备份，比纸面参数更重要。
- **客户本体优先**: 客户要求用某机器人/灵巧手验证时，由客户提供本体，我们提供协议、培训、QC、回放与交付。
- **五目设备后置**: 头戴+吊坠+手环+UWB+自标注是 Phase 2+ 的产品定义与 ODM 项目，不影响任务 001 开工。

## 二、P0: EGO 最小套件(24–48 小时内准备两套)

| 模块 | 最小配置 | 验收条件 | 备注 |
|---|---|---|---|
| 第一视角相机 | 头戴运动相机或手机头戴夹具 | 1080p/30fps 以上，连续录 60 分钟无中断 | 首要是看清双手、物体、关键动作 |
| 补充视角 | 胸前或肩部相机 | 与头戴视角可互补，不长期遮挡手部 | 不强制三机位，先保证一个主视角可用 |
| 手部线索 | 腕部 IMU、手部标记或近景相机 | 能将手部动作与主视频对齐 | 第一版不承诺完整手部骨骼 |
| 音频 | 领夹麦或环境麦 | 指令/关键事件可听，已取得授权 | 无授权时关闭或脱敏 |
| 时间同步 | 拍板/LED 闪烁/统一计时器 | 各设备首帧误差进入记录 | 每一轮开采前都测一次 |
| 标定 | AprilTag/标定板、卷尺、场景照片 | 相机位置、物体与坐标说明可复现 | 标定记录进入 `meta/` |
| 续航与存储 | 备用电池、充电器、存储卡、读卡器 | 一轮采集不断电，有余量可备份 | 设备故障是现场中断主因 |
| 合规 | 授权书、隐私贴纸、脱敏流程 | 人脸/屏幕/敏感物体处理方式明确 | 未授权场景不采 |

### EGO 开工验收(每套设备)

1. 录制 60 秒试片，检查时间、分辨率、声音与稳定性。
2. 回看能否同时看到手、物体、开始动作、结束状态。
3. 导出文件，按命名规则落盘；确认没有厂商 App 才能访问的封闭格式。
4. 用同一闪光/拍板对齐全部视角；把偏差写入元数据。

## 三、P1: UMI 最小原型(一周内准备 1–2 套)

| 模块 | 最小配置 | 验收条件 | 备注 |
|---|---|---|---|
| 手持夹爪 | 可重复开合的轻量夹爪 | 开合状态可记录，操作者可连续练习 | 先不追求复杂灵巧手 |
| 腕部相机 | 近端广角相机 | 能看见夹爪、目标物与接触区域 | 与 EGO 做时间同步 |
| 状态信号 | 夹爪开合编码器或开关事件 | 开/合事件写入日志 | 足以构建第一版动作条件 |
| 姿态/位移 | IMU 或视觉 SLAM/标记 | 能记录相对运动，明确误差范围 | 先记录可用线索，不伪造绝对精度 |
| 记录器 | 微控制器/日志器 + 笔记本脚本 | 视频、状态、时间戳能一起导出 | 任何 API key 留在后端，不写入设备端 |
| 触发器 | 开始/结束按钮或脚踏 | 一条 episode 边界能被明确记录 | 与任务卡的起止一致 |
| 夹具与备件 | 3D 打印夹具、螺丝、绑带、备用线材 | 现场可在 10 分钟内更换 | 不让小故障毁掉整天采集 |

### UMI 开工验收(每套设备)

1. 连续完成 10 次相同抓放；检查视频、夹爪事件、姿态时间戳是否都存在。
2. 从日志回放一条 episode，人工能判断动作先后和成功/失败。
3. 输出至少能映射为 LeRobot 式目录：`video/`、`meta/`、`trajectory/`、`qc/`。
4. 普通采集员完成 30 分钟练习后，按相同脚本再录一条；记录上手问题进入培训材料。

## 四、按客户类型选设备

| 目标客户 | 第一设备 | 第二设备 | 此刻不建议 |
|---|---|---|---|
| 世界模型/多模态团队 | EGO 头戴/胸前/手腕 | 少量 UMI 补动作 | 一开始采购机械臂 |
| 本体/灵巧手团队 | UMI/GELLO 或客户本体 | EGO 补场景 | 自己采购全套人形本体 |
| 聚合/数据平台 | 兼容对方设备与格式 | EGO/UMI 样机 | 强推自研设备 |
| 垂直行业现场 | 低打扰 EGO | 条件触发 UMI | 高干扰遥操作 |
| 政府/训练基地 | EGO+UMI 样板间 | 后续接入本体 | 先承诺固定产能 |

## 五、统一组装与数据落盘 SOP

1. 给每个设备贴 ID：`EGO-H01`、`EGO-C01`、`UMI-01`。
2. 每天开工前同步时间、录 60 秒试片、记录设备版本和电量。
3. 按任务卡采集；开始/结束用统一触发方式标记。
4. 每条数据立刻写入统一目录：

`task001/{raw/ego,raw/umi,meta,qc,deliverables}`

5. 命名示例：

`TASK001_scene01_operatorA_ego_head_20260723T103000.mp4`
`TASK001_scene01_operatorA_umi_gripper_20260723T103000.jsonl`

6. 采后运行预检：文件是否完整、时间是否对齐、手/物体是否可见、授权是否齐全、episode 边界是否明确。
7. QC 通过与返工原因同批写入 `qc/`，不要事后凭记忆补写。

## 六、不要先买的东西

- 全套人形机器人、工业机械臂或高价遥操工位：除非客户任务、规格书和验证路径已经明确。
- Project Aria、Vision Pro 等高价终端：除非买方明确要求对应传感器或视角。
- 自研五目硬件：先把任务 001 的真实遮挡、续航、同步、佩戴舒适度数据收集起来，再给 ODM 定义规格。

## 七、现场故障与处理

| 风险 | 最早检查点 | 当日处理 |
|---|---|---|
| 多设备不同步 | 60 秒拍板试片 | 停止批量采集，重新同步并标记受影响批次 |
| 手或物体被遮挡 | 试采回看 | 调机位/佩戴位置，不能靠后期猜补 |
| 抖动、掉帧、断电 | 每轮预检 | 换电池/卡/设备；保留故障日志 |
| 姿态不可用 | UMI 十次重复测试 | 降级为事件+视频，不伪造高精度轨迹 |
| 隐私或授权缺失 | 开采前任务卡 | 立即停止采集，完成授权或删除受影响原始文件 |
| 夹爪松动或手感不稳定 | 练习轨迹 | 更换备件，记录版本差异并重做标定 |

> 任务 001 的采购产出不是一份“硬件清单”，而是一条可被普通采集员重复执行的数据生产线。设备参数、故障和修改都要回写任务卡与培训材料，才会形成下一轮更快上手的组织记忆。
