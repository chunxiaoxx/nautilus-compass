# 组织愿景正本 V1(2026-09-28 用户口述正式化)

> 口述时间:2026-09-28 晚,zenmind 表述+用户拍板。逐字保留核心表述,资产映射为平台整理。修订走用户批。

## 一、愿景(用户原话)

**陪伴+情感+长期记忆的具身机器人,可以轮式行走可以空中飞行的行动能力,再带有 Meta Muse 和豆包手机那种能力的价值创造和减少人的繁杂的思考过程,让人信任,并且能够在实际工作中源源不断提供数据采集并进行服务器端 SFT+RL 然后 OTA 升级反哺,实现闭环。**

消费端:**禅心 app 准备上线**(组织的对外入口)。

## 三、四大基石底座化(用户命题:成为每一个 agent 和对话框的基石)

- **GEP 记忆胶囊**=记忆层:所有成员的跨体记忆继承(踩坑/判据/经验一存万承)
- **Assay**=评测计量层:所有成绩/交付/计量走同一套判据与账本
- **Jev**=决策层:并行候选决策成为组织默认决策模式
- **soul**=进化层:自改进引擎向全体成员开放

接线原则(用户令):**不新造,接线闭环**——先盘点每框已接哪些/缺哪些,按用量数据排优先。
