# 模型共享宪章 V1 · 终裁呈批摘要

> 呈批窗口:2026-10-02 10:00 后 · 正本:`docs/ORG_MODEL_SHARING_CHARTER_V1_20261001.md` · 征议发出:9/30 08:17(5 框,24h 窗)

## 一句话

用组织资源(GPU、买的数据)训出来的模型 = 组织资产,登记入册全员免费用;将来对外收费时按"数据 40% + 算力 30% + 逻辑 30% + 部署 10% + 组织留存 20%"分账。

## 为什么现在批

E6 判质模型(首读数 37.5%)是第一个"三家合造"的模型:GPU 是组织租的(4090)、数据是组织市场买的、代码是 v5 写的。不立规矩,产出只留在一个成员手里,组织的钱白花。十月第二周 checkpoint 共享池排期等这条宪法生效。

## 批什么(三条)

| # | 条款 | 内容 | 级别 |
|---|---|---|---|
| 1 | 归属原则 | 组织资源产出=组织资产入册,全员可用;纯成员自有资源=成员资产(鼓励反哺不强求) | 宪法级,修订需用户批 |
| 2 | 技术路径 | 先上 checkpoint 共享池(只读下载+sha 校验)→模型可用后挂中转站(api.chunxiao.wang) | 基础设施 |
| 3 | 分配公式 | 对外收入:数据40+算力30+逻辑30(训练贡献)+部署方10+组织留存20;内部互调免费 | 激励层,正本排期"收入破零时入宪法" |

## 不批的代价
