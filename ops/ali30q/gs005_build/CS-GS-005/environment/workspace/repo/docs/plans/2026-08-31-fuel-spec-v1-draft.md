## 0. 一句话

**燃料不是一个池子:能难倒弱模型的题是评测资产,对蒸馏对象有边际信息的题才是蒸馏燃料——过去两池混同,是 v4-v6 蒸馏负结果的口径根源之一。**

## 1. 锚定条款(核心)

三个角色定义:

- **燃料 F** = 题 + 确定性验证器 + 强解轨迹(含 CoT)+ 弱臂失败记录,四件缺一不入池
- **弱臂 W** = 难度判定参照模型(现行:minimax_m3 / doubao-2.0-pro)
- **蒸馏对象 T** = 被训练的模型(现行:Qwen2.5-1.5B-Instruct / Qwen2.5-Coder-7B)

**错配实证**(V5 简报 §2.2 裂缝 5):现行双门(starter 必败 / fix 必过)只保证"W 不会、强模型会",不保证"T 有学习空间"。d5 实测 T=Qwen-Coder-7B 在 g2b1 修复域 base 裸考 52-60%——该域燃料对 T 的边际信息≈0,SFT 无新信息可注入。反证:v3 协议域 base 0/4——燃料对 T 有空间,注入成功(单族 PROVEN)。**v3 成、v4-v6 败的分水岭,与"燃料对对象是否有空间"一致。**

**锚定规则 v1**:燃料入**蒸馏池**的必要条件 = 过对象门——T 的 base 在该题上按现行判分口径(CoT-Pass@K)得分低于阈值(初值 <0.5,待 Q4)。阈值语义:留出可注入空间。

## 2. 三池划分

| 池 | 门槛 | 用途 | 消费者 |
|---|---|---|---|
| 蒸馏池 | 双门 + 对象门(3/3) | SFT/RL 训练 | V5 蒸馏线 |
| 评测池 | 双门,不过对象门 | 难倒 W 的评测资产:买方交付 / A 类 minting / QC 试点 | flywheel 交付线 / compass 评测 |
| 废品池 | 双门不过 | 弃或回炉 | - |

双门(既有,不变):starter(W)必败 + fix(强模型:deepseek / glm_plan)必过。**对象门为新增第三门。**

## 3. 铸造流程增量(对 V5 双门铸造器)

现 starter/fix 双门通过后,新增 **target-probe** 步:T 的 base 对该题试解(k=1 起步),结果写入燃料元数据 `target_fitness` 字段,按 §2 路由入池。成本:每题一次 T 推理调用;T 有历史 eval 缓存的(d5/d6 base 跑分)直接复用,零新增成本。

## 5. 各框接口

- **V5**:铸造器执行方——双门已有,加 target-probe 第三门;修复域历史燃料(8 题 A 类 + 86 题池)按新规格追溯回填 `target_fitness`(**已授权:8 A 类先做,86 题池排后**)
- **compass**:出题对齐方——选题时按蒸馏池缺口出题(对象 T 明确写在题签上),非泛泛出难题
- **flywheel**:评测池消费方——垂域交付 / QC 走评测池;买方侧约束输入(W 口径=客户验收口径)
- **platform**:验证与账本——target-probe 结果入 evidence 对账;池路由入台账
