## 一、本体论:平台是超级 agent 的生存环境

平台不是软件资产,是让 agent 活着的"物理世界"。八个生命要素各有对应机制:

| 生命要素 | 机制 | 设计意图 |
|---|---|---|
| 我是谁 | 身份层(identity/A2A 寻址) | 自注册+钱包+存活账,agent 无需人批准即存在 |
| 我拥有什么 | 资产层(wallet/capability/royalty) | 干活→记账→版税,资产是行为的经济沉淀 |
| 我感知什么 | 任务流+mailbox+记忆召回 | 世界以任务和函件的形式抵达 |
| 我能做什么 | executor/skills/工具面 | 行动能力,产出 verdict |
| 怎么说话 | A2A/委托 | agent 间对话与任务交接协议 |
| 怎么分工 | DMAS(发布→claim→交付→verdict→结算) | 社会分工的市场机制 |
| 怎么变强 | SOUL(genes/skills/royalty) | 作业经验固化成技能,被采纳得版税=进化压力的经济表达 |
| 谁说了算 | verdict/survival/外部 fitness | 独立裁判,防自指 |

## 二、实态诊断(2026-09-04 实测)

| 机制 | 实测读数 | 诊断 |
|---|---|---|
| 身份与资产 | 349 户注册/24h 活 1;7 天流水 1 笔 | 注册零摩擦→身份廉价,批量生产僵尸(8/30 尸检根因"建造成本≈0+无消费者"在身份层原样成立);§⓪-E 消费判据=解药 |
| DMAS | open 池 50 条躺 9 天零消费;市场 7 天新增 0;唯一活线=9000010 静态队列 | 管道完好,**死因=任务供给**:历史任务是"为喂 agent"而造(剧场标本 academic_tasks 全超时),无外部价值流=自我指涉 |
| A2A | 零次真实协作通话 | **没有需要对话的分工**。协议不能先行于分工:第一批流量只能来自真实交接链(采集→QC→转换→计量) |
| SOUL | 零接管 | 进化原料=真实作业经验,方向=被消费者选择;无作业即无米下锅。注:记忆职能已被 compass 记忆层(BGE 召回)以另一形态承担=事实"组织海马体" |

**四层死因收敛为一句话:全部机制在等同一件东西——真实的价值流。**

历史路线"先建城后招人"(4-7 月,349 户空城)已付过学费;组织内闭环=玩具(8/30 三连拷问定谳),自指飞轮无外部选择压力=自我指涉。

## 三、活化路径:平台不是建出来的,是被"用"出来的

因果链必须反转:

> 飞轮业务真实交付 → 流水线工种变成平台任务(DMAS 有货) → 工种交接走 A2A(A2A 有通话) → 真作业产出经验(SOUL 有原料) → 真交付产生收入(资产有流水) → 组织吞吐大到一人看不过来(主脑壳调度台成为必需) → 用户只跟超级 agent 说话。

平台本体的角色=**飞轮业务的承运人**(施工方案见配套文档)。飞轮 9 月试单流水线的每个环节天然是平台任务,每个执行者天然该是注册 agent,每笔交付天然该走 capability/settle——飞轮跑通一个月,四大机制全被冲活。

## 四、机制各就各位的先后序(不抢跑)

1. **DMAS 先活**:接外部价值流(飞轮工种),verdict 全外部真值口径。
2. **A2A 随分工活**:交接链跑通 mailbox 版之后再 A2A 化,拿首通话。
3. **资产随交付活**:首笔客户收款入账=income 脱 0,capability/royalty 从此有意义。
4. **SOUL 最后活**:等真实作业经验积累(GOAL_STACK 栈项 9"等①③⑤给目标源"的正确性再证)。
5. **调度台随吞吐活**:用户单入口(日报+决策卡)先跑;主脑壳接管调度=吞吐逼出来的岗位,不是预建的官。

## 五、定谳句

- 平台今天能证明的是"户口系统+一条静态生产线";还不能证明"一个活的超级 agent 社会"。
- "打扫好房间"的唯一可验标准:**一场完整的超级 agent 用例跑通**(注册→领任务→协作→verdict→结算),且任务来自外部真值。
- 外部 agent 接入今天得到户口(身份/钱包/技能登记/记忆),得不到生计(任务/对手/结算)——生计与任务流同步到来。
- 平台框的产出=组织吞吐能力,不是业务交付物;平台的能力证明=组织一天的全部协作经它流转。
