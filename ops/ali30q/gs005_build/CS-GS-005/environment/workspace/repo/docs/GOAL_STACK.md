- 切换条件:7 天窗口内三曲线均自然增长且零介入 → 台阶二

### 台阶二 · 目标从数据里长出来(goal-sourcing 从死到活)
- loop 模式:**读数型**(降频 1h)——只读曲线与 goal 队列,不动手
- 栈项候选(待台阶一尾声入栈):①supervisor ZERO/红色→自动转任务 ②QC 红行→v1 训练料 ③对账分歧→复查任务 ④矿红→自动续矿

### 台阶三 · 外部真值指挥迭代(防自指飞轮)
- loop 模式:**元监督型**(每日 1 次)——只看 income/B 流入与宪法红线

- 永久保留给人类+核心框:宪法级判断(该不该做/对外承诺/红线)
