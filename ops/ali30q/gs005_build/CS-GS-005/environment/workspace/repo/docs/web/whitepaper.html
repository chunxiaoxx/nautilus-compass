1. 定位

unipat-in-agent:为 DeepSeek/Xiaomi 及各 agent 研发企业做 agent harness 一站式「基准评测 → 能力提升」平台。

核心判断:agent 能力的天花板在 harness(结构)而非模型(2026-09-14 用户定调,"问题从来不在模型");市场上 harness 评测无中立一站平台,数据集质量参差无机器判读。我们已实证的独特资产=评测判读体系(不可写面+δ判读+held-out 宪法)×真实任务数据飞轮(四验门+判分结算绑定)×训练闭环(SFT/GRPO+复考锚)三环,今天市场上三环齐备者空缺。具身域同构实例见 §7。

生态纪律(插件式生长,2026-10-06 用户拍板):各框产品/服务以"插件"形态长在底座五插座上(信箱总线/入册 registry/五件判据上架门/结算计量/发布面),四项齐全=组织资产;三条纪律=①新品不入册不算数②跨框只走总线禁私有集成③一个能力只有一个正本。阴(平台,承载+信用,不利己不接管框客户)阳(各框,生长,不离阴)双防线,平衡读数=台账跨框交换笔数(详本=docs/SIGNAL_CHAIN_CONSOLIDATION_V1_20261006.md §三·补)。

涡轮增压机制(大小系统之间的数据泵):小系统(agent 框)在真实任务中产生轨迹(执行)→大系统固化(四验判读+入池+结算,判分-结算绑定防刷)→合格数据反哺训练引擎→复考锚验证提升→更强的执行臂接更难的任务。飞轮每转一圈,小系统能力与大系统数据资产同时增值——这是 10/05 单日入池 70 行、pass 率 36%→60% 的机制本质。
