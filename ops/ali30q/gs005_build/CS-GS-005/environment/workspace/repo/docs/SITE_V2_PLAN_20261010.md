# 网站价值规划 V1(2026-10-10 · 用户方向指令落地 · SITE_V2)

> 用户指令:统一登录注册管理/站间互联/底层数据互通/前端美化(图片 hero demo 动效 数据可视化)/面向对象设计与营销/触达联系咨询付款/思考网站应有功能价值。
> 本档=深度分析+分期路线,接入 loop 队列。与 10/12 开业协调:P0 开业前, P1 开业周, P2 迭代期。

## 一、价值定位分析:网站为谁解决什么(思考层)

四类访客×四层价值:

| 访客 | 要什么 | 网站该给的 | 现状 |
|---|---|---|---|
| **潜在客户**(harness 开发方) | "凭什么信你的判分" | 3 秒看懂价值主张→看榜→免费试→付费深报告 | △榜页强但入口散;hero 文字为主无 demo |
| **在途客户**(已提测) | 提交/查单/进度 | 提交页+邮箱查单门户 | ✅submit 页+customer 门户+by-contact API |
| **同行/生态**(agent 圈) | 组织故事+接入方式 | 全 agent 组织叙事+API/开发者文档 | △HN 文案叙事强,站内 unipat.html 弱;developers 页 V2 候 |
| **投资人/媒体** | 差异化证据 | 判据公开/负结果照报/账本可审计 | ✅判据披露+账本快照+sinks |

**核心判断**:信任层(判据/负结果/独立判读)是我们最强资产且已在线;**最大缺口在转化层**——访客落地后"下一步做什么"的动线弱(无 hero CTA/无定价门面/无付款指引/无咨询入口)。网站当前"证明了可信"但没"引导行动"。

## 二、差距表(需求→现状→动作)

| 用户需求点 | 现状 | 差距 | 分期 |
|---|---|---|---|
| 统一登录注册管理 | app 域 users router 全(注册/登录/me/钱包);各子域独立 | **跨子域 SSO 缺**(bench/data/compass 不共享会话);双后台(admin.html vs app/admin) | P1(已排 10/13-16 M2 窗) |
| 站间互相关联 | sites.html 枢纽+首页导航 13 链 | 页脚互链不全(compass 站无页脚链);站间跳转语境缺 | **P0**(静态快改) |
| 底层数据互通 | 同一 DB(65 表)+同一后端 8000;marketplace 已换源 | 表层各自渲染,无统一数据 API 门面 | P1(统一读数 API+各站消费) |
| 图片/hero | hero 纯文字 | **无视觉资产**:无产品图/无组织图/无流程图 | P0 文字 hero+CTA;P1 图片 |
| demo | 榜页即 demo(真数据) | 无产品演示动线(判读卡样例交互) | P1(demo 页=判读卡样例+复算命令展示) |

| **触达联系** | customer.html=查单;散落邮箱 | **全站无统一联系入口**(无页脚联系方式/无咨询表单/无响应 SLA 承诺) | **P0**(联系块+咨询表单) |
| **付款方式** | 收款 e2e 通(assay 订单);BP 五档在文档 | **站内零支付指引**(怎么下单/怎么付/发票) | **P0**(pricing 页定稿+下单指引段) |

## 三、分期路线

### P0 开业前(10/11-12,与 loop 冲刺合并,全静态低风险)
1. **全站统一页脚**:联系块(邮箱 service@nautilus.social+咨询表单链+响应 SLA"工作日 24h")+站间互链六站+对象分区(客户/开发者/生态)——六站页脚统一件(tokens.css 已铺,改动机械)
2. **主站 hero 升级**:一句话价值主张+双 CTA(免费提交/看榜单)+服务读数条(已有,保留)
3. **pricing 页定稿**:候用户三选拍板→落地+**下单指引段**(三步:提交→判读→付款,assay 订单流+发票/对公说明)
4. 咨询表单:org_intake/submissions 已有 IP 限流通口——customer.html 加咨询 tab(零新后端)

### P1 开业周(10/13-16)
5. **跨子域 SSO+统一账号**(已排 M2 窗,users 正本,各站共享会话)
6. **统一数据 API 门面**(/api/platform/overview 聚合读数,各站消费——底层数据互通的产品化)
7. **demo 页**:判读卡样例交互展示(nautilus-l1-0002 首卡+复算命令)+30s 流程图
8. **轻图表**:榜单对比条形(26.7% vs 16.7%)+NAU 流通趋势(dataviz 规范,静态渲染优先)
9. developers 页 V2(中转站如实披露+MCP/A2A 接入指南,作战板 A6)

### P2 迭代期(10/17+)
10. 视觉资产(组织架构图/判读流程图/产品截图)
11. campaign landing(按 HN/V2EX/X 渠道分别承接,UTM 追踪)
12. 动效(数字滚动/滚动入场,克制)
13. 营销自动化(提交→自动回卡→自动邮件)
