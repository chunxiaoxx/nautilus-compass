## 3. 失败样本复盘与规则修订

### 3.1 失败样本：`薛美雪_001`（失败）
- 结果：`pass@5=0/5`  
- 失败字段：  
  - `findings` 中多次出现“误更正”  
  - 特征重复集中在税务分档和跨期口径  
- 失败归因：
  - 训练指令对税务字段依赖的显式约束不够  
  - 对“按月合并税基+税率跳档”的二阶逻辑触发不足
- 处理动作：
  - 把该样本放入“失败回放池”；  
  - 更新规则约束模板（`sample_difficulty` 标记为税务口径）；  
  - 优先复训后再进入主闭环复测；
  - 外部展示暂不展示细分偏差，保留 `pass` 与 `re-run` 的合规状态。

### 3.2 规则修订草案（本轮确定）
1. `ego_replay_match_rate < 90%` -> 自动 `retry`。  
2. 关键输出字段新增“失败类型分桶”（合并、减除顺序、跨期归属、证据缺失）用于训练蒸馏。

## 4. 题目资产如何转为“燃料蒸馏”

### 4.1 第一批题库中的高价值模式
来自两份题面（连续劳务）与反馈表，已提取到可蒸馏的共性：

1. **制度+证据对齐型**  
   - 案例：`李子秋_002`、`宣伟淳`  
   - 模式：制度条款逐条对照、证据行号绑定、按责任人和时限给处置建议。  
   - 蒸馏价值：提高“可追溯输出”的准确率，并能直接映射合规咨询/质检工作流。

2. **财务口径重算型**  
   - 案例：`薛美雪_001`  
   - 模式：按月合并、分档税率、跨期归属、完税凭证校验。  
   - 蒸馏价值：提升计算链的鲁棒性，减少“只会输出结论不算过程”的误判。

3. **数据整合与闭环治理型**  
   - 案例：反馈表里多条“附件缺失/名字不一致/指标口径冲突”  
   - 模式：发现附件与题目描述不一致、指标体系不统一。  
   - 蒸馏价值：用于自动化预检（数据质量前置），降低执行失败率。

### 4.2 反馈表里“可直接改造成训练目标”的问题模板
- 附件清单不一致（文件名、实际文件、来源口径）  
- “隐性验收点”与题面目标不一致  
- 操作步骤过于模板化、AI痕迹明显  
- 数据公式要求写死、非引用  
- 产物格式与实际口径冲突  

这些问题是训练“执行力”而不是“知识记忆”的直接信号。下一步可把这些问题固定为 5 类 `hard_case`：
- `DATA_MISMATCH`（数据口径不一致）  
- `PROOFLESS_CALC`（计算无追溯）  
- `STEP_TEMPLATE_NOISE`（步骤模板化）  
- `FORMAT_VIOLATION`（产物结构不合规）  
- `TIME_BOUND_VIOLATION`（时限与责任缺失）

- 对外展示和内控审计分离后会出现口径漂移，我们这次不分叉，降低争议。
