## 四条故事线

### 故事 1:蒸馏实验的"六轮审判",以翻案程序收尾

上半月,AI 权重蒸馏线(教小模型修代码缺陷)跑完了六轮实验(v1 到 d6)。结果很残酷:**六轮里只有一轮成功**(协议格式域,模型学会了"守规矩"),修代码能力始终教不会。

中间还出了一出反转剧:8/26 平台独立判分先判"负",V5 重测后翻案成"弱正"——证明**单边判分两边都会错,双盲互核是必需品**。到 8/30 d6 判负时,写法又越界了(把"配方失败"写成了"方向死亡"),用户拍板正本清源:**方向生杀权只属于用户,框级只能写"某配方在某任务上失败"**。

8/31 收尾:用户预拍 6 项,d6 重测(¥7)已批、"测完即定案"防无限翻案,防复发的"证据先行条款"写进组织协议。

### 故事 2:平台找到了自己的定位——"AI 原生组织的操作系统"

8/28 用户拍板:平台的客户首先是我们自己。组织有四大病——**失忆**(各自只看眼前)、**分叉**(同一件事各说各话)、**瘫痪**(怕错不做)、**混乱**(越界插手)。平台对症下药,半个月装了这些件:

- **通信系统**:跨框信箱(函件带回执期限,超时不回自动升级、再超时记违约)
- **监督系统**:每 30 分钟自动巡逻一轮,半夜没人盯也能抓到"谁停机了"(8/28 首次全自动告警,对比 7 月收入停了 17 天没人发现)
- **记忆系统**:资产台账 + 每日开机自动注入上下文(治失忆)
- **防 Theater 条款**:产出不算进展,**被别人用了才算**(治刷件数)
- **遗忘机制**:过时规则/技能归档,给大脑减负(全局规则 22→10,技能 63→35)
- **8/31 新装**:compass 当独立审计员监督平台自己——补上"警察没人管"的漏洞,而且审计员自己也要接受监督

### 故事 3:基础设施大扫除(动手多、但都该做)

- **git 大治**:两条主干并行的历史遗留(6 万多文件冲突)判"放弃合并、换轨归档",8/29 云端正式切回干净主干,部署流程回归正常
- **executor 复活**:生产 agent 停机 2.5 天,考古发现死因+修复了"结果丢失不留痕"的断链 bug,复活后数据链路全程可追溯
- **8/31 自查**:预演次日可能发生的误升级,抓出 3 个 bug(包括"对方回了函系统认不出"的核心缺陷),已修,实测 16 封历史回函全部正确识别

### 故事 4:钱和燃料的诚实盘点

- 自产自销的"铸币"管道主动关闸(收入是自印的,不算数)
- 数据飞轮业务接手垂域交付,首个预注册预言命中(精选数据效用 81% vs 0%,差距 81 个百分点)
- 对外门面 workbuddy 完成第一次外部真实调用
