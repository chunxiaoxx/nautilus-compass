## 二、进展与问题的理论命名

**进展的本质**:过去两天产出的高价值结论多为**负结论+仪器化**——L2 负(注入有害)、KernelBench 负(天花板)、蒸馏负(燃料不足),但每次负结论都留下了能复用的仪器(三臂 harness/噪声门/熔断)。按 A2 解读:**组织在补验证短板,压缩侧(理论文档)已超前一个身位**——飞轮 9/7 自审"理论超前业务一个身位"与此一致。

**问题清单(理论视角)**:
1. **g 的人类带宽上限**:组织所有门控最终汇聚到用户拍板(12 项积压)——A3 的组织层表现
2. **自指风险**:auto-research 本身是无外部压力的自指循环——空转定理在研究层的复发面
3. 理论条目散落:同一概念在四框文档里四个名字(算子/评估器/仲裁器/判分 g)——压缩尚未发生在理论层本身
4. 负结论的转化率:仪器有了,但"负结论→新假设"(如 T6)靠人脑,无机制

## 三、auto-research 机制 v0(核心提案)

### 3.1 一句话

**每周一轮的"理论矿机+账本+预注册"循环**:从组织全部增量(文档/实验/函件)挖理论相关证据 → 对照账本更新条目状态 → 每轮产出 1-2 条预注册预测 → 交实验网络 grounding → 勘误节沉淀。

### 3.2 循环设计(全部复用现有积木)

| 步 | 动作 | 复用件 |
|---|---|---|
| 挖 | 周轮扫描五仓增量 docs/commits/函件,提取"理论相关"增量(新数据/新结论/新反例) | g2b1 矿机骨架(过滤规则换理论关键词) |
| 对照 | 增量 vs 账本条目:支持/证伪/无关/新条目候选 → 状态迁移+证据指针 | LLM 会话(与飞轮自改进时段同窗,周五) |
| 预注册 | 每轮从"假设"状态条目产 1-2 条可证伪预测(判据/样本/停机线冻结) | V5 铁口径模板(其已认领一页纸) |
| grounding | 预测挂到 L4 实验网络空闲臂(GPU 空闲窗/CL1 并批) | 实验网络日历 |
| 修订 | 结果回写账本:证伪→降级+勘误节;支持→升格"已证" | 月报勘误节(V5 勘误制度化) |
| 沉淀 | 账本正本=平台仓 docs/theory/;compass BGE 索引供跨框召回;feedback_log 收"理论-现实摩擦" | compass 三件套 |

### 3.3 自指防护(空转定理的自我适用)

auto-research 的 fitness **不能是账本更新量**(否则=自我指涉的自报活动,T1 预言其空转)。外部真值三通道:
1. **预测命中率**:预注册预测被实验网络的裁决率(跨框实验,报告者≠实验者)——主通道
2. **外部世界对照**:每轮附外部检索(外部是否已证伪/已实现同结论——理论独享性检验),borrow WebSearch/论文仓四方法
3. **双框互审**:账本月报过 V5 第二双眼睛+compass 复核回执
红线:改 L1 公理=L3 冻结 24h+用户批;账本更新量/条目数**永不进 KPI**(反 Goodhart,V5 第六刀)。

### 3.4 与三论文的同构声明(自检)

| 三论文 | auto-research 对应 |
|---|---|
| 压缩 | 理论账本(散落文档→结构化条目) |
| 验证 | 预注册预测+实验网络 grounding |
| 异构接地(A2 推论) | 报告者≠实验者+外部检索 |
| 空转定理 | 3.3 全节 |
| 盲区定理 | 双框互审(异构判官组合) |
| 摊销率 | 周轮=摊销节奏(高频小批,非大重构) |

若此机制自己空转(连续 N 轮预测命中率≈随机且无外部新证据),按 T1 自停——**给机制写好讣告条件是设计的一部分**。

### 7.3 外部调研:auto-research 全景与我们的差异定位

**行业现状(2026-09)**:乐观派——[AI Scientist(Sakana)](https://sakana.ai/ai-scientist/)(全流程论文工厂)、[Agent Laboratory](https://github.com/Schmidgall-Research/Agent-Laboratory)(idea→paper)、[Robin(Nature 2026)](https://www.nature.com/articles/s41586-026-10652-y)(生物假设+数据分析全自动)、autoresearch(Karpathy 系,overnight 实验训练)、[FutureHouse](https://www.futurehouse.ai/)。质疑派——[arXiv 2605.08956](https://arxiv.org/html/2605.08956v1)("agentic AI scientists 是 co-scientists,非自主发现")、bioRxiv 案例("cannot yet autonomously conduct")、Salesforce 质疑("experience-driven improvement 有实证极限")。

**我们的差异定位**(三条,全部有存量支撑):
1. **对象不同**:行业做"产论文的 agent"(单/多 agent 工厂);我们做"组织自己的理论账本"(对象=组织认知,产出=预注册预测)
2. **fitness 不同**:行业多以内置 LLM 评审;我们按 T2/T9 拒绝同构自评——grounding 网络+异构互审是结构差异,不是实现差异
3. **质疑派的预言我们已定理化**:他们实证发现"cannot yet autonomously"(外部描述),我们的空转定理(T1)给出机制解释(无外部验证→自报不动点)——**三论文对行业负结论有解释力,这本身是可对外发声的定位**(论文仓投稿叙事的第三条腿:第一二条是空转/盲区原始数据)

**外部呼应 T6**:Salesforce"experience-driven improvement 有实证极限"与我们的分布近邻定律(T6)方向一致——两条独立线(他们:经验极限;我们:分布距离决定增益)可能同一现象的两个切面。T6 若被 L2-ext 证实,我们对该现象有更精确的表述(距离可测量:组织知识与模型分布的嵌入距离)。
