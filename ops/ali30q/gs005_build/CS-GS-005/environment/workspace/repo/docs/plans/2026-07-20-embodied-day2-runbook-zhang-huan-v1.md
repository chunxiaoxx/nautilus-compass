## H. 失败样本扩展复盘（用于训练闭环）

### 样本：薛美雪_001（失败回放）
- 当前 run 结果：`pass@5 = 0/5`（doubao）  
- 命中问题：主要是“误更正”与税务差异差值口径偏差，类型集中在公式重建阶段。  
- 失败信号示例：
  - `('陈某', '12月')` 多次差异 `720.0`
  - `('李某', '10月')` 差异 `4120.0`
  - 若只看结果是否有数字会误判，因此必须保留 `findings` 字段作为训练信号。  

### 路由决策（样本级）
- 这类样本不直接进入 `pass` 交付池。  
- 进失效修复池：  
  - 更新 `sample_difficulty`（税务口径细分）  
  - 强制触发 `rule_revision_candidates`：按月合并、费用减除先后顺序、税率阶梯三条规则的再验  
  - 先在沙箱“失败回放任务”里做一次修订再回主闭环。  

### 这条失败样本给我们的价值
- 证明单样板闭环不仅要有成功路径，也必须含失败路径样本。  
- 失败样本让我们验证：
  1. 判定字段是否可追溯；  
  2. 产物是否可解释到每个字段；  
  3. 对外展示中如何屏蔽误差细节但保留可验收信号。
