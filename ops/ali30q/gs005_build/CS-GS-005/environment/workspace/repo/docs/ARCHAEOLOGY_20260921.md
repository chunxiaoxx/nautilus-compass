## 三、NMACS 复用方案(入考场开放日技术方案)

**两真洞**:
1. 内部:函件走明文共享 key,泄露即可冒名(无通道级防抵赖)
2. 对外(刚需):考场收外部考生卷——无签名则无"这份卷真是他交的"证明;**收费场景非抵赖是硬要求**

**复用设计(克制的)**:
- **范围**:仅考场外部接口。内部六框不 NMACS 化(key+审计已够,改造成本>收益)
- **外部考生身份**:报名时生成 Ed25519 密钥对(公钥托管平台,私钥考生持)
- **交卷协议=NMACS 三阶段改版**:①投卷(考生签名,平台验签回执)②确认(平台签名收执=防平台抵赖)③成绩单(compass 签名,已有件直接复用)——**双向非抵赖**
- **复用代码**:`nautilus/communication/crypto.py`(Ed25519 155 行现成)与判分签名同源——接线不是重写
- **ChaCha20 加密**:卷面含考生私有代码,传输加密一并启用(现成)
- 实施时点:考场开放日**门二(首个外部考生)前**完成——它与"对外触点"是同一件事的协议层
