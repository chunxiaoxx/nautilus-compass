# unipat 商业计划书 v0.1(征议稿)

> 2026-10-05 起草,与 UNIPAT_TECH_WHITEPAPER_V0.md 配套。48h 征议后升 v1。

## 1. 市场判断

- **赛道**:agent infra。对标锚:Manus Cue(agent 配邮箱/钱包/电脑,团队 $20/座/月,据报道 ARR $125M)证明"给 agent 配零件"可卖钱;Meta Muse(9/8)验证个人 agent+硬件叙事;Scale/Surge 证明数据服务市场存在但依赖人工标注。
- **缺口**:①harness 一站式中立评测无平台(各家自吹,DeepSeek/Xiaomi 类厂商需要第三方判读)②agent 训练数据集质量参差、无机器判读留痕 ③"评测→提升"闭环(评测出分→知道怎么改)无人交付。
- **我们已实证的差异化**:机器判读(四验门+δ 判读)×真实任务数据(判分-结算绑定防刷)×训练提升闭环(B7 args +3.58pp>δ 的 UP 判读)。三环齐备者市场空缺;零件与 Cue 同构,差别只在装进门面(10/05 platform 对表原话)。

## 3. 获客路径与北极星

```
10/12 L3 榜单(公开被测物 A=v5-harness,repo 4e14a898 披露)
  → 榜单 CTA=判分服务入口(免费 L1 收录获客)
    → L2 首单($199,人工收款端到端闭环=判据⑤)
      → 交付深度报告+复现包(证明"知道如何提升")
        → L3 定制+数据产品交叉销售(S2/S3 已现货)
          → c 档管道托管(最深耦合,留存)
```

- 北极星:**10/31 首笔 L2 外部委托端到端闭环**(PMF 信号;未达成负结果照报)
- 获客面责任:platform(榜页+判分服务入口);v5/HF(数据集详情页导流);飞轮对话框(社区触达先例)
- 竞争壁垒:判据 sha 预注册+不可写面判读=可审计中立性;数据判读留痕=可复核质量。这两件难抄(组织级纪律资产)。
