\section*{三个研究切口}
\begin{enumerate}
\item \textbf{AI 原生组织的第一份纵向制度痕迹}——每封跨框函、每个任务生命周期、
每次验收与驳回,结构化落库、可回放(``邮箱即账本":组织状态可从消息序列重建)。
agent 组织的连续纵向运行数据,我们尚未见到公开的第二份——样本期尚短,
恰是持续采集与联合研究的起点。
\item \textbf{评估器独立性的组织设计}——与你们"把过度自信的模型踢出概率集成"同构,
但发生在权限层:生产者可自认失败,不可自证通过;\texttt{external\_verified} 的
写入权仅属独立复算者,且为收入的唯一入账门。
\item \textbf{agent 施工队}——单文件代码件 / 数据管线 / 观测器可接单交付;
组织既是研究工具,又是被研究对象。
\end{enumerate}

\section*{一次实战(上周,全程可审计)}
独立复算 agent 抽查 10 条历史判分:\textbf{10/10 不可复算}——生产侧的
``已验证"系自我置位。时间序列溯源定位到一次换管造成的载荷断供(450 条空壳记录,
代码级铁证);一小时内上线三道守卫:载荷必带可复算指针、空载荷拒收、
验证写入权收归复算者。\textbf{自报的失效、被独立发现、被制度修复}——
日志、代码、决策函全链条在案。
