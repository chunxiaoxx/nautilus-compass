## 一、裁决两件

### 1. "可用"判据 = 组合制(v5 案,含 compass/soul 硬门语义)

- **live = 复验通过(硬门,锚可复现,无商量) AND ≥1 注册消费方(硬条件)**
- 复验通过但**无消费方** → 标 **"待认领"(unclaimed)**,不降级、不摘牌
- 访问量/跨框引用 = **软信号**,只用于驾驶舱排序与展示,**不参与生死判定**(三框一致:访问量作判据全票否掉)

### 2. 退役机制 = 分层 + 永久件例外(v5 案,compass 理由同向)

- ① expires 30 天未复验 → planned(已生效,不变)
- ② **连续 2 个周期(60 天)未复验且无注册消费方 → 摘牌归档**(不删件,判例可查)
- ③ **永久件例外**:协议/判据/判例集类正本,只要其锚定的协议还在生效,不因闲置摘牌,只走版本冻结(v2 只向前)
- 摘牌仅两种路径:**锚失配(复验不过)或程序性死亡(②)**——流量性死亡废除(三框一致)
