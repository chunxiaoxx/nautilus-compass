# 平台价值命题 v1(2026-09-21)

> 源自用户命题"平台如何真正发挥出作用?"的应答沉淀。判据沿用机制尸检标准:
> **改变过决定**。平台的作用不是自己做了多少,是让多少正确的决定得以发生。

## 核心命题

**平台=放大器,不是运动员。** 六框里唯一不生产业务内容的框——它的价值
全在"让其他五框的正确产出能够发生、可信、被看见"。

## 四层作用(每层附实证)

### 1. 物理层:六框之间的唯一神经
mailbox/dispatch 总线。没有它,compass 改判到不了 v5,flywheel 协议落不进
银河谈判。昨夜(9/20-21)25 封函全走它。**组织的存在性由物理通道保证。**

### 2. 制度层:让规则可信执行的那只手
平台不判卷(裁判=试金局)、不治理(治理=soul),但:
- **密封权**(三臂盲评,C4 纪律拦下执行框越权组包)
- **可判性**(判材组装:上下文块保留/expected_output_path/import 闭包)
- **防假绿**(API Error 假交卷拦截/截断修复/SLA 误报消源)
裁判可信的一半,在于裁判的材料与身份由中立第三方保证——这就是平台。

### 3. 主动性层:没人派活也知道该盯什么的框
OGE/哨兵 E1-E9/Loop。各框干自己的活,平台盯"组织的活":昨夜值守 17 轮
抓出五件(代投扩量/假交卷澄清/判材根因/双实例虚惊排除/误报消源)。
E9 自动工单生成器上线后,这层开始**自我供燃料**(失败自动变改进工单)。

### 4. 商业层:验证即服务的运行载体
伊洛产品=第三方验证。判分/盲评/申诉/改判/签名/墙全部跑在平台资产上。
§5b 申诉→改判→自纠错公开(2026-09-21 首例)就是产品 demo 在组织内真跑。
**第一个客户是自己,是字面成立的。**

## 与 RSI 内核的关系(2026-09-21 起)

反馈(E9 自动工单 ✅)→改动(soul 治理门+v5 autofix)→验证(试金局)→
回流(goals 状态,worker v1.0 目标源 v0 已接)——**四段全部有实物流**。
平台从"邮局"到"神经系统+免疫+公证处"的路已走完;最后一步=对外打开
(考场开放日双门:门一已过,门二等首个外部考生)。
