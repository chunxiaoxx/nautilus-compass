## 三级

| 级 | 定义 | 通道 | 现状 |
|---|---|---|---|
| **A 直发** | 有 API 有凭据(X/Reddit/GitHub/邮件) | agent 直发 | **未开通**(待用户批,开通前置=账号健康读数入快照+24h 撤回机制) |
| **B 一键批** | 无 API 或涉账号风险(知乎等) | agent 备成品稿+发布参数→飞书卡片推送→用户手机一键批 | **即日生效**(U29 批) |
| **C 留人** | 资金/签约/生死/产权 | 用户亲自 | 永久 |

## B 级规约

1. 备稿方(各框)提交:成品全文+目标渠道+发布参数(账号/时间/话题 tag)——函附+落仓
2. 平台推卡:飞书 p2p 卡片,两个按钮(批准发布/退回),卡内含稿全文预览
3. 批准→平台执行发布(浏览器自动化或用户 10 分钟亲手,视渠道);退回→改稿重推
4. 挂起超 72h 未决→快照亮牌(防 BC1 挂 5 天复发)
5. 审计账:每笔 B 级件落 `docs/evidence/org-os/outbound_ledger.jsonl`(稿/卡/决/发四时间戳)
