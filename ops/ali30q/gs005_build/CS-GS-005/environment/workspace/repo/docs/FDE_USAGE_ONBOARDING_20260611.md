## 一、内部:运营 / PM 如何用、如何落地

**入口**:① 飞书 FDE派活表(派任务·看进度) ② control-plane 控制面(看引擎/verdict/RSI·`nautilus.social/control`)。

**日常流程**:
1. **派活**:在飞书派活表填一行——task_uid / 业务线 / 类目 / L级 / 指派专家 / **验收标准(必填)** / 状态=待派单。
2. **自动**:平台 poller 每 5min 读「待派单」→ 派单 + 具名认领(防 agent 抢)→ 状态自动转「已派单」。运营不用手动 dispatch。
3. **盯进度**:派活表视图看每行卡在哪(待派单→已领取→已提交→QC中→过/打回→交付)。
4. **处理卡点 + 确认结算**:超期/打回由管理 agent 推提醒;运营决策优先级、确认应付。

**落地状态**:派活表+poller ✅ LIVE(S1)。进度看板/管理 agent/结算 = S3/S5 建。

## 二、外部:领域专家 如何用、如何落地

**入口**:飞书(收到邀请即用·零安装)。

**专家旅程(端到端)**:
1. **进场**:收到飞书邀请 → 打开「FDE派活表」→ 看到指派给自己的行。
2. **看验收标准**:每行「验收标准」列写明这道要写成什么、什么会被拒(RUBRIC 要点)。← 进来第一眼就知道标准。
3. **领活**:状态改「已领取」。
4. **亲笔**:🔴 专家本人写题干/教案正文(副驾驶 skills 只帮结构化/校验,**不代写**——买方跑 AI 检测)。
5. **提交**:在飞书交稿(S2)。
6. **看 QC 反馈**:系统逐项 pass/fail + reason 写回飞书 → 专家按 reason 改 → 再提交 → 过。
7. **结算**:过审后应付入账(S3)。

**副驾驶帮什么**:checklist 生成、16 列/4 段格式组装、附件解析、完整性+反 AI 味校验。**帮你达标,不替你写。**

**落地状态**:派活+领活 ✅(S1)。提交→QC 反馈环 = S2 建(下一片)。

## 三、外部:买方(保密大厂)如何用

**入口**:单独的「交付物」飞书 base(物理隔离)。

**规则(🔴 保密红线)**:
- 买方只看**成品交付物表** + 验收。
- **绝不可见**:派活表 / QC 内部列 / 避坑语料 / "我方=伊洛" / 其他专家的稿。
- 实现:独立交付 base(导出或外部协作分享)· 与内部 ops base 物理分开。

**落地状态**:🔴 未建(S3 交付片 + 引擎设计 §E 权限分层)。当前第3类交付物先走 L3 样例表(compass)。

## 四、推广:如何执行(诚实定位)

> ⚠️ 战略锚:**客户获取 defer**(买方已有=保密大厂)。所以"推广"重心 = **供给侧:招募领域专家**,不是找客户。

**A. 专家招募(主要推广)**:
- 渠道:垂直社区 / 前同事网络 / 行业 KOL(金融·法律·医疗·工程·ML 研究)。
- 客观筛:让候选在飞书做**一道试做题** → 过 checklist_scorer = 准入(不靠简历)。
- 转化:试做过 → 发 onboarding 一页纸(见下)→ 进场。

**B. 能力展示(对外·谨慎)**:
- 平台网页(nautilus.social)展示**能力与方法论**(原生 AI 组织 / RSI / FDE 工艺)。
- 🔴 **FDE 业务保密**:不公开宣传具体甲方、不晒买方交付内容。展示的是"我们能做什么"的能力面,不是客户案例。

**落地状态**:招募机制(试做题过筛)= 工具就位(checklist_scorer)·流程未跑首例。

## 五、专家招募 / onboarding 一页纸(可单独打印 / 发给候选专家)

> 把以下内容单独发给候选/新进专家。

### 加入我们 · 用你的领域专长,和 AI 一起做高难度数据集

**你是谁**
金融 / 法律 / 医疗 / 工程 / ML 研究等领域的资深专家(从业 ≥3 年,做过影响真金白银或重大决策的事,有一份可脱敏代表作)。

**你做什么**
用你的真实专业经验,产出两类高难度样例之一:
- **出题**:写一道你领域里"≥8 小时专家级、AI 做不了"的真场景难题 + 隐性验收点。
- **教案**:亲笔写一篇领域知识正文(1k–30k 字),沉淀你梳理提炼的专业知识。

**为什么是你**:这些内容**AI 写不了、网上搜不到**——只有你的真实专业经验能产出。AI 帮你加速(结构化、查漏、排版),但**核心内容必须你亲笔**(我们的客户会跑 AI 检测,拼凑的整批拒收)。

**怎么开始(全程在飞书,零安装)**
1. 收到邀请 → 打开飞书「FDE派活表」。
2. 看到指派给你的任务 + **验收标准**(写明什么算合格)。
3. 点「已领取」认领。
4. 按验收标准亲笔完成 → 在飞书提交。
5. 看到逐项反馈(哪里行、哪里要改) → 修改 → 通过。
6. 通过即结算。

**副驾驶帮你什么**:自动生成检查清单、按客户格式排版、解析附件、查完整性和 AI 味。**它帮你达标,不替你写。**

**门槛(试做)**:先做一道试做题,过我们的客观评分即录用——不看简历,看你能不能做出来。

**红线**:① 内容你亲笔(过 AI 检测) ② 真实专业经验,不编造数据/人物。
