# 🎯 北极星 · 唯一要闭的环(2026-06-22 用户确认 · 收敛锚)

> 解"搭建太多、一直分叉、从不收敛"的根因 = 缺一个钉死的中心目标。本文是那个目标。
> **用户 2026-06-22 确认**:目标表述对(补 agent 自治维度);forcing function = 先证或先杀蒸馏那一步。

---

## 一、唯一要闭的中心环

```
FDE 业务产难题(强模型解出 + 弱模型难倒 = A 类燃料)
        │
        ▼
难题当蒸馏燃料  ──训──▶  系统"可证变强"(两个维度,缺一不可):
        │                  (a) 模型权重变强(蒸馏注入分布外新模式·破能力墙)
        │                  (b) agent 群体自治变强(注册自主 agent · survival/能力进化/
        │                       marketplace/A2A 真接进来 · 不是对话框脚手架)
        ▼
更强的系统(更强模型 × 更自治 agent 群)产更难/更值钱的题
        │
        ▼
        └──────▶ 每一圈由外部 benchmark 证明提升 ──────▶ 循环
```

**一句话**:让"产出外部有价值的工作"可证地使"系统产出外部有价值工作的能力"变强——模型权重 + agent 自治两端都变强,每圈由外部 benchmark 证明。

---

## 二、这条环现状(诚实)

- ✅ **管道合上了**:同一套 dispatch/verdict 基底;甲方 verdict = 真外部 fitness 信号;一个 grounded-retrieval 记忆写回小环(6/20 bucket-A 首证)。
- 🔴 **因果环从没闭过**:把"转"变成"变强"的那一步——**蒸馏(用业务燃料训出可证更强的模型)从来没真跑过**(auto-mint OFF·S-PoC gated·true_wall 燃料反复溶解)。6/20 闭的"复利"是 grounded-retrieval 类 = 6/14 已判定"撞天花板、破不了能力墙"的那一类。
- 🔴 **agent 自治端也没闭**:producer 还是外部对话框(脚手架),没收口到注册自主 agent;survival/能力进化/marketplace 全 LIVE 但没接进飞轮。

**结论:内外飞轮是"概念/管道"合并,不是"因果/运行时"耦合。中心环开着。**

---

## 三、为什么一直分叉(元诊断 · 防复发)

中心环里有一步**又硬、又贵、又可能出负结论**的事(真训模型 + 证明它变强)。每次走到它跟前,就绕开去建旁边可做的东西(S1-S5/verdict-bus/能力路由/双门/reaper……)= 树枝。**用"可做的基建"回避"那一步会证明或证伪整个论点的硬事"** = 5-6 周"搭建≠闭环"复发的架构层显形。

---

## 四、收敛 forcing function(用户确认)

**先证或先杀「蒸馏那一步」。出结果前,其它都不算进展。**
- PoC:小批真 A 类燃料(强模型解出、弱模型难倒、轨迹已验正确)→ QLoRA 训小模型 → **外部 held-out benchmark 对比 base**。
- **赢**(beat base)= 飞轮因果环成立 → 放大。
- **平/输** = 诚实杀掉"蒸馏破墙"假设 → 回到"难倒题=护城河副产品"(仍净赚 B 类),不再假装飞轮在自我提升。

### 🔪 分叉过滤器(每件提案必过)
> "这件**直接推进中心环的因果链**(产燃料 / 跑蒸馏 / 证提升 / 收口注册 agent)吗?"
> 0 贡献 = 默认不做(进 parking lot)。基建/判分/路由/看板,除非是蒸馏 PoC 的必需前置,否则冻结。

---

## 五、第一步的诚实 gating 问题

蒸馏 PoC 的真前置 = **我们到底有没有干净的 A 类燃料?**(强模型解出 + 弱模型难倒 + 轨迹已验正确)。历史上 true_wall 候选(p13/p14)反复溶解;最接近的是 SWE path B(N=3·qwen 解出=doubao 难倒)。**所以 PoC 第 0 步 = 盘清现有可用 A 类燃料够不够训一个 QLoRA,不够则先把"产干净 A 类燃料"作为蒸馏的前置子目标。**
