# AI 原生组织运行协议 v1(2026-08-31 用户拍板通过)

> trace_id: org-protocol-v1-20260831 · 性质:组织运行宪法级文件,与 FDE_BUSINESS_CHARTER/LOOP_STATE_SSOT §⓪ 并列。
> 目的(用户原话):"能不能不需要我参与你们自发能做很多事,而且是很可靠的分工协作,只有核心问题和判断我来做。"
> 本协议回答"怎么才能":例行工作自发闭环,用户接口收窄为日报拍板。

## §1 决策权分级表(核心条款)

### L1 · 框级自决,做完报告
执行细节/任务顺序/工具选择/**停用空转资产**/修 bug/档案与文档整理/内部测试。
判据:做错了可逆、不花外部资源、不对外。
**不需要任何预授权。做完写进日报即可。**(样本:8/31 退役评审——用户一句授权,8 件自主处置闭环)

### L2 · 框级自决,事后追认
跨框派单与催办/优先级调整/L2 预算内花销/代表组织对其他框发函/启用已预注册解冻条件的资产。
**执行前不需批准,执行后 24h 内进日报,用户可追认否决。** 被否决的动作:立即回滚+记 anti-pattern。

### L3 · 必须升级用户(宪法级)
方向生杀(含任何"X 路线关闭/转向"表述·正本清源条款)/超出 L2 结构的预算/对外承诺与客户接触/红线事项(甲方保密·凭据·专家亲笔)/本协议及 SSOT/CHARTER 的修订/删除不可逆资产。
**重大 L3(方向级/预算级/关停级)呈报必附"反对理由栏"**(8/31 对立面审查新增,用户拍板):提案方自辩或非提案方出具——只给建议不给反对意见 = 呈报不完整,用户可退回;防"写选项的框替用户做决定"。

### 默认裁决条款(治"干等")
L3 升级后 **24h 无回音** → 按发起时预注册的保守动作执行,标注 `[待追认]`,不阻塞组织运行。
预注册保守动作=不改方向、不花钱、只做信息收集与准备。**禁止用"等用户"当作不作为的理由。**

### 证据先行条款(2026-08-31 用户拍板 · 治"组织裁决先于科学终审")

任何"X 配方已关闭/被证伪"的表述,前置条件 = **按预注册计划跑完的实验判读在先**。
无预注册判读、或判读欠功效(执行口径低于预注册口径,如 k=3 执行 vs k=8 预注册)时,
只能写"暂停/待验证"。**未测过的方法不得写入"全线关闭"类表述。**
违反 = 该表述自动作废,按正本清源条款处理(方向生杀=用户专属)。

## §2 L2 预算结构(**已锁定 · 2026-08-31 用户拍板"按建议锁定"**;改额度=L3 一次性拍)

## §3 daemon 化(组织常驻化改造 · 各框认领)

**目标:session 从"组织的前提"降级为"接口之一"。你不开机,组织照常运转。**

| 框 | 常驻载体(现状) | 认领改造 |
|---|---|---|
| platform | loop 30min 已在跑 + supervisor 30min + 云 backend | 维持;补"日结日报生成"步骤 |
| compass | 云服务 daemon(9876+MCP)已有 | 加"框级日 loop":读 bootstrap→mailbox→执行 L1(记忆治理/审计探针)→回函 |
| agent(V5) | executor schtasks 25min 配方现成 | 同配方挂"框级日 loop"(读栈/收函/执行/报告);v5-brain 举证函同步处理 |
| flywheel | daemon 已在跑(唯一业务线) | 同上对齐协议 |

各框 loop 最小规格:**每日 ≥1 轮**:① GET org/bootstrap(SSOT/goal/mailbox 一次拿全)② 执行 L1 项+回答 L2 函件 ③ L3 项投函升级 ④ 产出写本框 GOAL 文件。死循环保护:单轮失败不重试超过 3 次,记入日报。

## §4 验证闭环(协作不靠自觉)

- 函件 ack/deadline:已进 supervisor 牙齿(due<12h 未 ack→telegram)。本协议升级:**到期未回→升级函+telegram;再 2h 无回→按 L2 自决接管推进,原负责人被记 SLA 违约**。
- 派单验收:worker 回报必须带独立验证证据(沿用双门/判分纪律),无证据=未完成。
- 空转审计:退役评审例行化,**每月 1 次**(下次 9/30),L1 级自主执行。

## §5 用户接口 = 组织日报(每日一份)

```
【组织日报 2026-08-XX】
① 机器自决(L1):<N 件,每件一行:动作+效果数字>
② 自决待追认(L2):<动作+金额+理由,默认视为追认,否决请回复>
③ 待你拍板(L3):<问题+选项+建议+**反对理由**(重大 L3 必附,可退回)>
④ 红线/异常:<有则列,无则"无">
```

发布渠道:mailbox+驾驶舱。你的全部日常参与收敛为:读日报→拍 L3→否决 L2(可选)。
