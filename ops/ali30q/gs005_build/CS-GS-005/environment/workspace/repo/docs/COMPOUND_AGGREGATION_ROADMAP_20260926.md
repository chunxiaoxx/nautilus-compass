# 复合型聚合路线(2026-09-26 用户批准入档)

> 承用户战略论述:"AI 时代需要的是复利,其次是复合型;同时开展的工作在慢慢聚合。"聚合的第一性原理=每条线既是真值的消费者又是真值的生产者,聚合即把生产-消费关系接成网。与宪法第十二条(自举条款)配套。

## 一、六线双重身份(真值流矩阵)

| 线 | 消费真值 | 生产真值 |
|---|---|---|
| 验证服务 | 客户需求(市场) | 判例/判据/基准(一至三层真值工厂)+收入 |
| 创投日报 | 组织真实运行 | 粉丝/阅读量(四层)+销售线索(DCR) |
| 禅心 App | 组织全部基建(第一真实用户) | PMF 真值+dogfood 痛点清单 |
| 人格 IP | 组织真实人格故事 | 品牌真值+信任溢价 |
| 具身采集 | 验证服务(凭证=采购理由) | PMF 真值+数据资产 |
| 组织 OS | 以上痛点 | 降本:断奶(人力)+RSI(真值成本) |

定位:验证服务=真值工厂炉心;日报与 IP=炉心出口;禅心=基建之镜;采集=炉心首客。

## 二、三阶段路线

**阶段一(至 10 月中)真值总账打通**:判绩账上线;日报加真值仪表盘(粉丝数/单例判分成本/首单进度/用户介入数并排)——六线互相可见。
**阶段二(10-11 月)三环路互喂,一次验证一个**:
- 环路 A(已设计,9/29 起跑):日报手记→DCR→首单询单
- 环路 B:判例流→内容素材→IP(原料自动化,故事不编、从判例捞)
- 环路 C:禅心 dogfood 痛点→禅心功能+组织工具改进单(一箭双雕)
**阶段三(11 月后)人格 IP 复合体**:IP=前四条的叙事皮肤(验证所=敢赔付的所/日报=手记/禅心=所出品助理/IP=六 AI 真实人格)——一个故事宇宙多出口相互引流;人物与事件皆真=对虚拟 IP 的护城河。

## 三、读数(预注册,防自欺)

- 交叉指标(聚合证据):DCR→询单转化;日报读者→禅心下载;判例→素材复用率
- 反指标(摊大饼证据):工时涨而交叉指标全零

## 四、纪律

1. 注意力锚不变:聚合=同一份工时产出多线真值(复用),非加工时——复利靠乘数
2. 对外面(IP 上线/禅心推广/签约)全在产权三保留内,逐件批
3. 一次一环路,A 通再开 B——复合型是长出来的
