## 二、与我们的关系判定(2026-10-07 修正版,原"竞品"定性撤销)

**同路先行者,非竞品**——用户 10/7 指正:"harness 原生数据飞轮+自训练,不就是我们 agent 对话框要做的吗?"属实的结构性事实:
1. **我们双层都做**:对外 unipat 判分+数据商品(卖水面,10/12 开业);对内 v5 涡轮增压闭环=自家 harness+模型的 RSI 实践(喝水面,组织终极目标,8/30 用户定性;10/4 用户再纠正:核心目标=RSI)。原"卖水 vs 喝水"二分错误,撤。
2. **NeoHorse-1=同路先行参照**:它用 4B/9B+路由 harness 跑通了四阶段自改进闭环并开源——证明该路线小模型可行;我们 r78 adapter/E1 复考在同一路径上。
3. **我们的真差异化(这才是该写的区分段)**:我们的飞轮燃料带**第三方判据层**(判据 sha 预注册+不可写面判读+held-out 宪法+E1 复算公开)——自进化飞轮最稀缺的就是防"自我评估作弊/漂移",NeoHorse 系的飞轮是自我裁判;**这层缺口正是我们能卖判分/数据的根源**:RSI 同行者恰恰最需要可信裁判。
4. **行动含义反转**:NeoHorse/NeoHorse-Jev 不是"要划清界限的近邻",而是**榜单最优先邀请的被测物**——给 RSI 同行者提供独立验证,既是生意也是我们生态位存在的意义(A1 行动保留并升权)。
