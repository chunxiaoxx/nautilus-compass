## 09 合作入口

**标题**：合作从边界清晰、可验收的付费 POC 开始

**叙事任务**：把宏大叙事落到可购买的下一步。

**屏幕文案**：

POC 四步：

1. 选一个高价值、低歧义任务
2. 共拟任务协议和验收样例
3. 小批采集，暴露设备/动作/场景问题
4. 联合验收，决定扩量、改版或停止

POC 输出：任务规范 v1｜样本包｜拒收字典｜成本与节拍基线｜扩量方案

**视觉**：四个递进的实物“样本盒”，最后打开为一条规模化生产路径。  
**证据**：U02-U08/C03/C06  
**阶段**：【当前】可售入口。  
**禁用**：承诺固定周期、固定数量、固定模型收益。

## 10 交付链

**标题**：国曙把合作资源组织成一条端到端交付链

**叙事任务**：解释“我们没有全部自有能力，如何对结果负责”。

**屏幕文案**：

- 甲方需求：定义任务价值、格式与验收边界
- 国曙项目负责：方案、合同、调度、进度与交付总责
- 合作方支持：基地支持、指导培训与派单协同
- 国曙执行与质控：人员组织、现场执行、预检与复核
- 联合验收：样例对齐、问题归因、版本冻结

一句话：资源可以协作，责任不能外包。

**视觉**：责任链而非生态 Logo 圈；国曙为贯穿全链的橙色主线，各合作节点为灰蓝色可替换模块。  
**证据**：U03/U05/U07/U08  
**阶段**：【当前】责任模式；资源【可配置】。  
**禁用**：合作伙伴背书、未经授权名称/Logo。

## 11 Agent 控制层

**标题**：Agent 将成为生产网络的运营控制层

**叙事任务**：体现“自动化”的实际方向，同时不夸大现状。

**屏幕文案**：

- 采前：任务拆解、培训问答、设备与场景检查
- 采中：步骤引导、异常提醒、缺失检测、实时反馈
- 采后：片段切分、预标注、规则质检、拒收归因
- 运营：派单、排班、激励、版本管理、证据追溯

阶段路线：人工主导 → 工具辅助 → Agent 编排 → 自动化闭环

**视觉**：Agent 作为中央信号塔，四束控制信号连接采前/采中/采后/运营；底部清楚显示四阶段演进。  
**证据**：E03/E08/U10/C05  
**阶段**：【路线图】；首期强调人工主导、工具辅助。  
**禁用**：“全自动”“无人运营”“已上线”。

## 12 质量协议

**标题**：质量不是一个分数，而是一套可复跑的验收协议

**叙事任务**：把“高质量”从口号变成可谈判的技术合同。

**屏幕文案**：

六个验收维度：  
任务成功｜步骤完整｜时序同步｜动作可见｜环境合规｜数据可追溯

三层判定：  
硬门槛（必须通过）→ 质量标签（便于筛选）→ 任务表现（由客户验证）

关键机制：金样本、拒收字典、版本号、复跑记录、争议复核。

**视觉**：一个任务片段穿过六道检测光栅，右侧生成“Quality Passport v0.x”，明显标注“与客户共建”。  
**证据**：E05/E06/E08/U06/C06  
**阶段**：【当前】可在 POC 共拟协议；质量护照【路线图】。  
**禁用**：第三方认证、行业统一分数、模型效果保证。

## 13 商业闭环

**标题**：项目收费、数据权利与合作责任，形成完整商业闭环

**叙事任务**：讲清楚怎么赚钱、如何不陷入纯人头外包。

**屏幕文案**：

近期收入：任务设计/试采 POC｜合格数据交付｜现场与设备配置｜持续质量运营

合同核心：验收单位｜价格与拒收｜数据权利｜隐私与保密｜变更机制｜合作方责任

可选权利结构：客户独占｜限定领域许可｜经授权的可复用组件

原则：先按项目建立成本与质量基线，再形成标准产品。

**视觉**：现金流、数据权利流、责任流三条线形成闭环，避免价格表。  
**证据**：U03-U08/E08/C03/C08  
**阶段**：【当前】项目制；许可/复用【可配置】且须客户授权。  
**禁用**：固定价目、毛利率、默认二次销售客户数据。

## 14 飞轮

**标题**：每一单，都让下一单更快、更稳、成本更可控

**叙事任务**：解释为什么项目制可以积累为网络型业务。

**屏幕文案**：

订单 → 任务模板 → 训练与拒收字典 → 合格作业者/场景 → 设备与流程校准 → 质量证据 → 更快承接相邻任务 → 新订单

飞轮资产：不是客户原始数据，而是经授权可复用的协议、工具、组织经验与质量方法。

**视觉**：单一大型飞轮，每一环只放一个资产；中心是“合格任务片段”，外圈是订单扩展。  
**证据**：U04/U06-U12/C07  
**阶段**：【当前】从每个订单持续积累；网络效应【路线图】。
**禁用**：未经授权复用客户数据、承诺降本比例。

## 15 路线图

**标题**：从 1 到 10，再到数据质量与交易基础设施

**叙事任务**：把近期业务和远期平台梦想放在同一条可信路径上。

**屏幕文案**：

- 阶段 1｜协同基地启动：合作基地、人员组织与小批验收
- 阶段 2｜复制交付：扩到相邻任务/场景，形成稳定班组与任务模板
- 阶段 3｜网络运营：基地与分布式协同，Agent 辅助调度与质量闭环
- 阶段 4｜质量基础设施：质量护照、基准任务、可独立收费的验收服务
- 阶段 5｜数据资产运营：在权利清晰、需求稳定、效果可验证后建设数据市场

门槛：每阶段必须有客户付费、验收证据与合规闭环，才进入下一阶段。

**视觉**：五段逐步升高的“证据阶梯”，每级入口不是时间，而是验收门槛。  
**证据**：U02/U06/U09-U12/E05/C08  
**阶段**：阶段 1【当前】；其余【路线图】。  
**禁用**：给出未经验证的年份、收入、规模目标。

# 附录建议（按对象选择，不全部进入 16 页主叙事）

## A1 对标拆解：从公开模式中借鉴什么

- Shift：头戴式采集｜按验收结算｜隐私前置｜数据订阅
- Rayvo/未来眼线索：轻量设备｜分布式激励｜连接数据消费者
- EgoScale：大规模第一视角预训练 + 少量人机对齐的研究证据
- 国曙选择：订单驱动｜项目总责｜基地+分布式｜质量协议｜Agent 运营路线
- 明确不复制：Token 模式、未经核验的规模、自建平台先行、脱离客户任务囤数据。

证据：S01-S05。

## A2 基地 + 分布式运营 SOP

任务冻结 → 金样本 → 设备/场景准入 → 培训与试采 → 日常派单 → 自动预检/人工复核 → 拒收复训 → 批次交付 → 复盘封版。

阶段：运营设计基线，需项目验证。

## A3 数据权利、隐私与安全清单

场景与人员授权｜最小必要｜敏感信息识别｜本地预处理/去标识化｜访问权限｜加密传输与存储｜留存与销毁｜委托处理协议｜审计与事件处置。

证据：S03/S08/S09。
