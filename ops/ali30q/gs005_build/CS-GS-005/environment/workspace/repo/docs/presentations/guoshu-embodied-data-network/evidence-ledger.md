# 国曙具身数据生产网络：证据台账

标记：

- `CURRENT`：用户确认的当前事实，可直接写“我们现在”。
- `CONFIGURABLE`：具体项目可通过任务配置和合作资源实现，必须写“可按项目配置/联合组织”。
- `ROADMAP`：尚未具备或未验证，只能写“计划/目标/逐步形成”。
- `EXTERNAL`：公开研究或行业事实，不代表国曙能力。
- `REJECT`：不进入主叙事。

| ID | 主张 | 来源 | 状态与边界 |
