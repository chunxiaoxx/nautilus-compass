## 与7 pattern的关系

甲方三反说"上述截图提供了7个badpattern，每个pattern可出2题，共14题"——用户贴文确认的7 pattern是：
1. 口径理解错误 × D01.1后端
2. 交付形态或实现对象错位 × D08.0技能包
3. 明确需求或约束遗漏 × D05.0 SQL
4. 边界与异常处理缺陷 × D08.0技能包
5. 范围遗漏漏项 × D05.0 SQL
6. 范围遗漏漏项 × D01.1后端
7. 口径语义错位 × D05.0 SQL

这7条在30条体系中的对应：
- #1口径理解错误 → 30条#1(F01.02目标或口径理解错误·D01.1)
- #2交付形态错位 → 30条体系内无完全对应（近似#9 F01.01关键歧义）
- #3需求约束遗漏 → 30条#11(F01.04明确需求或约束遗漏·D05.0)
- #4边界异常缺陷 → 30条#15(F05.02边界与异常处理缺陷·D08.0)
- #5范围遗漏 → 30条#2(F01.03任务范围·D05.0变体)
- #6范围遗漏×D01.1 → 30条#2变体
- #7口径语义错位 → 30条#1变体

**结论：7 pattern是30条体系的子集/变体**——14题新单从中选pattern×领域组合。
