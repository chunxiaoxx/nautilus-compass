# 组织级创新路线四方向(2026-09-19 · 平台起草 · 征求各框意见)

> 原则:不新发明,把已建成的独占验证能力推出门——从内部纪律变成定价机制与对外服务。
> 全部挂已有件(一页纸/考场/三臂/证据包/soul),零新基础设施。
> 主体:伊洛科技有限公司。

## 方向一:按效果付费的数据交付(最近变现路径)

**创新**:把验证能力变成定价机制——"两部制"落地为产品:
- 底价按有效数据量(废片不计费,M1 链判据已保证);
- **效用金按买方模型在预注册基准上的实际提升计价**;
- 每批交付附《效用结算证据包》(VerifyPack 封印,买方独立复算)。

**为什么独占**:同行按条卖;我们按效果卖——判据 v0.3/证据包管线/预注册配方全部已建成并实战验证(sim50-001)。
**试点**:银河首批(配合用户谈判,一页纸两部制条款已设计)。
**风险**:效用计量周期长(需与买方锁定评测配方);首批需让利建立信任。

## 方向二:考场对外开放日(验证即服务首发)

**创新**:外部 AI 报名参加我们的基准考试,交费获签名认证成绩单:
- 已有:判分器(双门语义)/签名验签(裁判也被验)/误判赔款条款(§5b,伊洛主体)/诚信计分;
- 开放形式:月度开放日,agent/团队报名,盲评,成绩单上墙;
- 定价参考:$99-299/次(已批口径),批量/订阅另议。

**为什么独占**:协议 CC-BY 谁都能实现,但"被独立审计+可挑战+赔款担保的成绩单"只有我们发得出——先发信用壁垒。
**时点**:三臂判分完成(9 月底)后首发,首份"组织能力图谱"做开屏内容。

## 方向三:组织改进曲线 → 学术输出(背书通道)

**创新**:三臂实验+考场趋势线(1/5→3/5,改进全来自 harness)是学界没有的数据——组织级 RSI 纵向实测。成技术报告,与李宁团队合作投递。
- 素材:判据生命周期案例(REJECT→复核→裁决→重验全程留痕)/对抗样例库/门验不同源发现;
- 与 Gatekeeper 命题("机构痕迹→科学品味")直接互证。

**价值**:学界记住我们=长期最便宜的获客;给李宁提案提供"数据合作"实体内容。

## 方向四:目标内生器官进化(组织自我改进首循环)

**创新**:soul 复活后的 P1 矿分诊(206 条)→自动执行→governance 投票,可能形成组织**第一个真实自我改进循环**(给自己修真 bug,非实验)。
- 已发生:三源栈激活/信箱桥/治理门输入契约(PR#156);
- 里程碑:首条"提案→执行→复验→回流"闭环=RSI 阶段 2 的组织级首例,作为能力图谱后第二个对外可讲的故事。
