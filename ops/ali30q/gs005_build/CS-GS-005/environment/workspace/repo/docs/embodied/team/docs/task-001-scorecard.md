# 任务 001 选择清单与评分表

版本: 2026-07-23
用途: 只选出一个三天内能交付、能验收、能获得客户反馈的样板任务。它不是客户需求书的替代品，而是把“先做什么”从感觉变成团队共同可检查的判断。

## 一、先过硬门: 任意一项为否, 不立项

- [ ] 有明确的客户或合作方，能说清这批数据会被用于什么能力或验收。
- [ ] 单条 episode 的起点和终点清楚，时长通常在 10–60 秒。
- [ ] 仅用视频和元数据，就能判定成功、失败或需要返工。
- [ ] 场地、物品、操作者和授权可以在三天内重复获得。
- [ ] 至少能用 EGO 采集；需要动作线索时可加 UMI 或客户本体。
- [ ] 单次准备不会打断现场作业超过 15 分钟。
- [ ] 能保留失败和边界案例，而不是只录成功案例。
- [ ] 客户或合作方承诺给出书面反馈、POC 意向或明确拒收原因。

> 硬门的作用是阻止“拍了一堆视频再想怎么卖”。硬门没过，评分再高也不能开采。

## 二、100 分评分表

| 维度 | 上限 | 怎么打分 | 当前分 |
|---|---:|---|---:|
| 买方价值 | 20 | 是否直指客户的模型、机器人、运营或验收痛点 |  |
| 可判定性 | 15 | 成功/失败/返工能否由同一规则复跑判定 |  |
| 三天可做性 | 15 | 设备、场景、人员、授权能否在三天内到位 |  |
| 可重复采集 | 10 | 是否能稳定重复，且不依赖偶然的现场条件 |  |
| 多模态价值 | 10 | 能否同时提供第一视角、手部/夹爪、对象状态、语言或环境信息 |  |
| 失败样本价值 | 10 | 失败类型是否可解释、可复现、对世界模型或后训练有价值 |  |
| 授权与隐私可控 | 10 | 是否可以获得授权、脱敏并定义数据权属 |  |
| 后续扩展潜力 | 10 | 通过后能否扩展到更多物体、场景、采集员或本体 |  |
| **合计** | **100** |  |  |

## 三、决策规则

| 条件 | 结论 | 动作 |
|---|---|---|
| 硬门任一未过 | 不立项 | 补授权、判据或客户反馈路径；不能靠加设备解决 |
| 硬门全过，评分 80–100 | 立项 | 进入 Day 1，冻结范围，三天内不加第二个任务 |
| 硬门全过，评分 70–79 | 待补 | 优先补买方价值、可判定性或三天可做性后再评一次 |
| 硬门全过，评分低于 70 | 换题 | 选更短、可重复、可判的单步骤任务 |

## 四、建议候选任务(不是预先承诺)

| 候选任务 | 适合谁 | 推荐设备 | 预估分 | 为什么适合任务 001 |
|---|---|---|---:|---|
| 小件分拣入盒 | 世界模型、平台 | EGO + 可选 UMI | 86 | 边界清楚，成功/失败可见，物体和场景容易变体化 |
| 瓶盖拧开再盖回 | 灵巧手、本体 | UMI + EGO | 82 | 有接触、力控、失败模式，数据密度高 |
| 货架取放单件 | 本体、平台 | UMI/客户本体 + EGO | 78 | 可复用，但要先限定物体、货架与成功位置 |
| 后厨单一标准动作 | 世界模型、垂直行业 | 低打扰 EGO | 74 | 场景丰富，需先解决隐私、卫生和授权 |
| 客房整理单一步骤 | 垂直行业、平台 | EGO | 72 | 可做，但要避免变成长流程，先收窄到一个对象动作 |
| 全流程家务或洗碗 | 长期方向 | 多设备 | 58 | 时长、状态和授权过于复杂，不适合作为第一个样板 |

## 六、三天闭环的验收

1. **Day 1**: 任务卡冻结；试采 10 条；机位、时间同步、成功/失败判据各完成一次复核。
2. **Day 2**: 采集 30–50 条原始 episode；至少各有 10 条金样本、边界样本、失败样本；每条不合格都记录返工原因。
3. **Day 3**: 输出视频/轨迹、元数据、标签、授权记录、QC 报告、拒收字典、回放说明与 LeRobot/Parquet 格式说明；向客户索要书面反馈。

> 三天完成的是“一个任务的可验收样板”，不是对产能、泛化或基地复制的承诺。只有客户反馈进入台账，才算本轮闭环有外部信号。
