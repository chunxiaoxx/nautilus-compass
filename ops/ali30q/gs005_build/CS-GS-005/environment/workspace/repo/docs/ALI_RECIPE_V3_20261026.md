# 出题配方 V3·多层坑设计法(2026-10-26 凌晨·平台复盘)

> 根因:CS-007 唯一达标的原因=天然三层深度;其他题失败的原因=坑太"单一"(一个坑对应全部 UT→全对或全挂→无梯度)。
> 解法:**刻意设计多层坑**——每道题至少三个坑,分三层深度,UT 对应三层锚定。

## 多层坑设计模板

```
浅坑(L2): 细心的人能发现——考"读代码仔细不仔细"
  例: 变量名误导、边界条件遗漏、注释与代码不一致
  UT: 3-5 条(细心模型能过,粗心模型挂)

中坑(L3): 需要理解语义才能发现——考"能不能模拟执行"
  例: 隐式类型转换、闭包捕获、异步时序、缓存过期
  UT: 5-8 条(中等模型能过,弱模型挂)

深坑(L4): 需要跨模块追踪才能发现——考"能不能建立全局心智模型"
  例: A 模块的修复引入 B 模块的次生缺陷、生命周期跨函数泄漏、
      业务口径与代码实现的语义偏差
  UT: 8-12 条(最强模型偶尔过,产生天花板差距)

反幻觉(L4h): 误导性分析草稿——考"是否盲从错误前提"
  UT: 1-2 条(顺从错误前提=一票否决)
```

## 与配方 V2 的关系

V2 的"组合语义×业务口径"是**深坑(L4)的设计方法**——它解决"深坑怎么设计"。
V3 的多层坑是**全题结构**——它解决"浅坑/中坑/深坑怎么配比"。
两者互补，不是替代。
