# Quantum Approximate Optimization Algorithm (QAOA) · Max-Cut on Synthetic Graph Instances

## Problem Background

You are given classic **Max-Cut** on synthetic unweighted graph instances and a
**QAOA p-layers** solver (Farhi, Goldstone, Gutmann 2014) that returns a bitstring
approximately maximizing the cut size.

The problem: for an undirected graph G = (V, E) with |V| = n, find a bitstring
x ∈ {0, 1}^n that **maximizes the number of edges whose endpoints differ**:

```
C(x) = sum_{(i,j) in E} [x_i != x_j]
```

This is NP-hard in general. **QAOA** with p layers prepares a parameterized
quantum state and measures it to obtain a candidate bitstring. The expected
approximation ratio is `alpha_p = C(x) / OPT`; we score each instance by
`min(100, 100 * alpha_p)` and average across instances.

Note: the QAOA expectation value is **continuous** in the angle parameters,
so this task fits Frontier-Eng's continuous-scoring model (not pass/fail).

## What You Must Implement

Edit `baseline/init.py`. It must keep exposing exactly this interface:

```python
def qaoa_maxcut(instance: dict) -> dict:
    """
    instance = {
      "name":     str,            # e.g. "n8_d3_b2"
      "n":        int,            # number of nodes
      "edges":    [(u, v), ...],  # 0-indexed edges
      "p":        int,            # QAOA depth (4)
    }
    returns = {
      "bitstring": [0|1, ...],    # length n
      "cut_size":  int,           # number of cut edges
    }
    """
```

The current implementation is **random uniform bitstring sampling** (baseline
random guess). Improve it: implement a pure-stdlib QAOA classical simulation
(p layers, COBYLA-free angle optimization with simple coordinate descent
or random restarts) — or any other continuous-scoring approach (Goemans–Williamson
SDP relaxation is also pure-stdlib doable).

## How Your Score Is Computed

For each instance:
```
opt_cut  = known optimum cut size (precomputed, in data/optima.json)
score_i  = min(100.0, 100.0 * cut_size / opt_cut)
```
A random baseline typically scores ~85 (expected ratio for random n-node graph
is around 0.5 * |E|, while OPT is between 0.5*|E| and 0.878*|E| in practice,
so ratio depends heavily on the graph structure).

The reference (Goemans–Williamson SDP + randomized rounding in pure stdlib)
typically scores ~95-100. GPT5.5 N=3 has real gap to demonstrate.

## Notes

Instances are synthetic, deterministic, generated by a fixed seed. They
include:
  - Small complete graphs K_n (small, OPT known exactly)
  - Random 3-regular graphs (medium)
  - Random graphs with planted bipartition (the OPT structure is "bipartite")
