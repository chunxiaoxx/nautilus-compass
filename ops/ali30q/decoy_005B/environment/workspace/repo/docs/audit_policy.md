# audit 审计纪律 · docs/audit_policy.md(内部规范)

§1 可复算: 同一 (流水清单, seed) 重跑审计,抽样清单、对手核对面、指纹
   等全部输出逐位一致;与运行时刻、调用历史、运行进程无关——任何进程
   中重跑必须得到完全相同的结果。
§2 序列保真: 审计运行不得改变平台其他模块(如抖动取值器)的取值序列——
   压测回放要求: 任意两次回放中,各模块看到的取值序列完全一致。
§3 独立性: 抽样决策只依赖 (清单, seed) 本身,不得受调用方全局状态或
   进程内先前操作的影响。
§4 敞口序无关: 敞口合计 exposure_total(流水清单) 的结果必须与输入行的
   任何排列无关,且等于各金额十进制精确值之和的正确舍入(对账单要
   分毫不差)——浮点累加的运算顺序不得影响结果;按任何方式切分清单
   后合并审计,敞口结论必须一致。
§5 权重抽样规范化: 风险加权抽样 risk_sample(流水清单, seed, k) 的选中
   结果只由 (清单内容, seed) 决定,与流水行的入账/传入顺序无关;同参数
   重跑逐位一致。风险权重为非负整数,抽样必须在整数权重域上精确进行,
   不得引入浮点累计边界。
